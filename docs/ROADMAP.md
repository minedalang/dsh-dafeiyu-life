## 2.8.0 已交付能力与持续验收

统一 Life 是当前核心，而不是各 Agent 分别替鱼鱼作决定：相同的真实经历能够获得相同的行动机会；动作由鱼鱼一次性决定；外发仍要通过授权、内容证据和平台回执。可视化生活、自然会话、记忆与反思、主人管理中心必须互相联动。

2.8.0 的源码与离线回归已完成正式发布准备；Windows/DSH 实机、真实 B站受控路径、长期运行及旧数据迁移仍须由实际运行环境独立验证。未知发送状态不得自动重试，关闭权限时仍须安全拒绝。离线测试不等于这些验收通过。

## 2.8.1 · 预计重点：看得更深入、记得更有根据（已开始 dev.2a）

**实施状态（2026-11-14）：** 已从 `dev.2a` 启动：新增视频证据类别/来源/时间锚点的只读合同，并接入主 Session 与社交推荐共用的 `bili_watch_video` 读取；其他视频 Agent 入口、多帧深度理解、安装器仍在后续批次。**跳过原 dev.1** 的 GPT-6-Luna 识图确认及 Token/费用测试：使用者已经确认其支持识图并自行测试费用，本项目不安排重复验证。见 [2.8.1 视频感知实施方案](architecture/2.8.1-video-perception-dev2a.md)。

**本地视频模型规划（尚未实现）：** 提供 **MiniCPM-V 4.7 1B** 与 **Qwen3.5 4B** 两个候选，让使用者在管理中心像本地语义 Embedding 一样选择型号、一键下载安装、查看进度、取消、删除或切换；保留 DSH 视觉模型且不强制本地安装。安装器先验证上游固定修订和哈希，不能把模型“已下载”当作视觉“已运行”。

1. **有证据的深度视频理解**：在已用的元数据、字幕、预览图之外，研究可选的画面帧与音轨分离识别。鱼鱼必须能区分「看到了画面」「读了字幕」「实际听到声音」；没有使用的能力不得伪装成经历。受模型能力、上游兼容、版权与预算限制，具体接入要先评估。
2. **更自然的连续交流**：检验评论、@、普通私信和主人对话在统一 Life 下如何正确理解人物指代、会话对象、图片与关系；从真实送达后的新事实决定是否补充，而不是为凑气泡机械追话。重点是实际运行证据，不增加另一套意愿模型。
3. **能解释的兴趣与回忆**：可视化展示一段兴趣或关系是如何从真实经历形成、变化、淡化；记忆召回状态区分安装、运行、索引与搜索，而不是用模糊锁定提示掩盖失败。继续完善低成本的本地语义体验与来源追溯。
4. **生活里的故事感**：从行动树、同一视频的跨日探索、好友来往和动态草稿中整理有依据的生活脉络，让用户看懂前因后果；不通过“每日必须评论几次”等指标驱动行为。

其中前几项与 2.8.0 的**既有收口缺陷**有重叠：凡属于 2.8.0 已约定的统一机制、外发安全、评论图片接线和实际 bug，**不能因为写进本节就延期**。2.8.1 的新增目标需要单独确认范围。

## 2.8.2 及以后 · 更广阔的生活（长期研究）

- **带来源、可修订的观察与反思**：围绕真实作品、人物、对话形成有保留意见的认识，不把一时猜测当作身份事实。
- **可选择的技能探索与小作品**：研究在受控空间创作图像、编辑内容、准备可预览的作品；任何外发都需要额外授权，不能让素材/工具访问越权。
- **长期且有边界的关系**：逐渐理解每个人对话的节奏，也懂得不联系、拒绝和忘记；公开熟悉不等于有私信权限。
- **更流畅的管理中心**：将 Vue 3 + Pinia 等响应式改造保留为技术评估选项，不作为当前版本完成条件，不能改变 Life 唯一意愿和写操作安全协议。
