# P6 后续计划（2.6.1 正式版暂不实施）

- **B站登录账号可更换/迁移**：必须将角色身份、记忆、交互账号和对外联系人授权分离，先备份、核验账号归属，再按原隐私域重绑定；不应直接替换当前 UID 导致关系或人生记录错挂。
- **待办完成回访诊断**：增加 pending 的阻塞原因、下一次允许发送的预计时间和审计状态；未来由鱼鱼自主决定是否表达，不强制套固定模板。
- **P6-A/B 自主续聊**：自然连续回复、延迟补充、沉默感知与自主续聊，需独立的频率与授权控制，主 Session 需宿主原生消息适配。
- **P6-C/D 自主社交**：情绪回忆、关系回访与跨渠道协调；不因对方沉默或熟悉度提高而自动获授权。

2.6.1 正式版**仅**恢复基于真实入选视频、好友明确画像与主动授权的私信兴趣推荐，不恢复前述功能。
