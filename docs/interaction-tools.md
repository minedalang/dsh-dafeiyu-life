# 交互场景与工具能力指南

适用：2.8.3-dev.39 收口候选。以下描述已接线能力与限制，不保证每次模型都选择工具；实际使用取决于已登录账号、主 Session 绑定、能力开关、模型、预算和独立授权。

## 主人交流入口

| 能力 | 主 Session | B站主人私信 | 好友私信 / 陌生人 / 评论 |
|---|---|---|---|
| 真实经历和长期记忆 | 显式 `dafeiyu_life_recall`、`dafeiyu_memory_recall` | 自主 `memory` 按需读取 | 现有场景范围内；不得跨联系人披露私密经历 |
| 视觉回忆/历史补看 | `visual_query`、`detail_bvid`、`bili_video_revisit_moment` | 按需回忆及核验后的公开历史复访 | 授权好友受限复访；陌生人和评论不获补看权限 |
| 新视频观察 | `bili_watch_video` | `shared_link` / `shared_video`：核验来信分享目标后自主选择 | 授权好友受信分享；其余保持受限 |
| 最近观察清单 | `dafeiyu_recent_observations` | `recent_observations`：主人专属按需菜单 | 不开放 |
| 保存重要事实 | `dafeiyu_remember` | `ownerMemoryProposal`：当前来信原文核验、现有身份记忆额度 | 不新增身份记忆写入能力 |
| 探索建议与待办 | `bili_life_consider_video`、`dafeiyu_todo_list/add/update/execute` | 原自愿待办建议与按需待办读取 | 原受限建议规则；不新增管理权 |
| 公开资料 | 原 `bili_search`、`bili_comments`、`bili_subtitle` 等 | 既有按需公开菜单 | 原场景权限及预算 |
| 图片内容和外发 | 本批未接通缓存图片附件 | 本批未接通缓存图片私信 | 不开放 |

主人私信的事实保存是本轮新增的有限写入：必须是当前核验主人来信，模型主动选择，引用当前消息连续原文并经过原身份记忆写入检查；返回真实结果再组织回复。不是任意删除、编辑全部历史记忆的接口，也不是自动记录每条私信。旧聊天及任务保留现有机制。

## 怎样使用

- “你最近看过什么？能说说有哪几张分镜吗？” —— 鱼鱼可以自行选择查看近期观察清单，返回当前账号 12 小时缓存中的视频标识、采样时间和分镜编号（最多四条，私信目前最多三条）。清单不包含图片字节、不确认图片仍可发送。
- “你还记得那只小动物的动作吗？” —— 鱼鱼可选择相似画面回忆，只有仍然有效的实际观察可作为证据。
- “有空看看这个视频吧。” —— 可按已有意愿流程接受、拒绝、延期，或进入受信分享的观察；待办入账不等于已经观看。
- “我更喜欢短视频，你可以记住。” —— 可选择记下当前明确事实，保存成功以实际回执为准。

## 意愿、权限与回执

所有角色自主读取也应经过统一意愿边界。已选主 Session 的实际工具调用、社交模型明确选择的按需菜单作为本轮自愿读取决定；读取前后复核身份、代际与范围。可以不选择、拒绝、延期或缩小范围，不为每次读取额外启动模型投票。读到历史内容不等于必须告诉对方；本批通过模型指引与已有权限边界处理表达，并未建立独立的披露凭据。主动行动及外发仍使用原意愿与授权检查；关闭互动回复不得借工具外发。必要的当前对话、身份线索及系统统计、备份、索引、遗忘维护不属于角色主动工具使用。

自动记忆上下文与待办提示仍提供能力入口，不直接附上完整历史正文。旧的社交全量上下文偏好保留配置，生产模型交互按需展开。后台其他自动唤起与反思路径尚未全面统一；不能把本批声称为所有读取入口均已迁移。

## 当前限制

真正读取缓存图像并经宿主附件或 B站私信发送、完整主人渠道工具对等、单独披露回执仍待后续实现和真实宿主核验；不得用文件路径、缓存编号或文字描述代替成功发图。陌生人和评论不因此获得新的读取、写入或外发授权。真实模型是否选对入口及实际视频观察结果需宿主短时验收。
