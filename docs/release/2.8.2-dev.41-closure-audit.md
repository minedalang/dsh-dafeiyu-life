## dev.41 修改与安全边界

- 现有 ASR 固定 CPU int8，改为 CUDA 可用时尝试 GPU float16（若加载不支持，再试 GPU int8）；仅根据实际模型加载/推理设备返回明确枚举；加载与懒生成迭代出错会整体回退 CPU，不能把失败时部分 GPU 结果混入成功回执。
- 平台内容仍被当成不可信输入；共享读取预算、私信30分钟核查、账号隔离、Life 独立决定、社交授权和外发结果门禁均无变更。
- README/首次引导更简短；三张桌宠开放平台图明确未来规划，不把预告当成可连接功能。
