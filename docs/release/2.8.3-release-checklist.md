## 本轮缺陷与决议

- Host Schema 十个默认值与现行新装运行时不一致。按现行推荐值对齐；旧配置缺键继续保守值，账号授权/发送门禁不变。真实配置读取测试必须覆盖 Host Schema materialization 与旧配置。
- 原生设置页仍显示 2.8.2；更新为 2.8.3 五项亮点。管理中心旧宣传弹窗已经移除，不新增；引导修订号不变。
- 旧启动日志“评论默认关闭”与现行新装建议不符；日志记录实际加载版本及按当前权限运行；实时诊断追加严格白名单版本、主人定向检查及实际间隔，旧接口或非法版本记为未知；不保证实时状态捕获成功。
- 历史视频文案断言不再适用；改为验证真实观察方式及非强制观看，保留行为测试。历史文档中互斥模式、整盘冷备份、未实现 Embedding 等不作为当前规格。
- 未经真实宿主验证的能力不得声明正式通过；历史用户日志没有可靠当前版本证据。没有扩大记忆架构或新建执行路径。

原锁定路线、统一 Agent 与局部视觉等未完成项统一登记于 [开发债务台账](2.8.3-development-debt.md)。放行前逐项核对实现/测试/实机证据或维护者明确延期，不能仅以版本号顺延删除。

### dev.38 运行总控、日志与分享视频

- 顶部自主生活开关与生活方案共用 `lifeAgentMode`/`autonomousPlannerEnabled`；保留原节奏，暂停自动人生反思，不影响显式手动回忆/反思和独立互动回复。互动回复开关暂停后台私信（含主人优先检测）、评论及 @ 回复；现有各渠道授权保持，重新开启不产生新授权。插件内手动私信、评论回复也受此暂停，独立原创主评论不因这个开关直接授予或撤销授权；共享 Life 发送通道暂停期间不出站。已提交平台请求仍按真实回执收口，未知结果不能自动重试。
- 日志页提供固定四个本机日志的有界分类摘要、错误筛选及 JSON 导出（每文件最多 8 MiB，最多 20,000 条导出；不含原始正文）。完整错误溯源使用现有 `tools/导出B站日志.bat`，日报 Markdown 及内部归档保留。日志分类不是完整错误审计，缺失/轮转/超限明确展示。
- 神经回忆场仅保留六类节点筛选，情绪依据活体证据；桌面画布/容器高度 1.5 倍，窄屏适配。
- 主 Session 已有 `bili_watch_video`（standard/deep 依能力）；主人/授权好友私信经 `shared_link` 真实元数据核验后可在同一轮自主选择 `shared_video`，仅对已验证同账号同联系人目标，复用共享读预算、视觉租约、标准感知。只交付实际验证的代表画面和/或字幕文字，非完整播放。历史画面仍可经现有记忆工具按需回忆，陌生人/评论仅保留原受限菜单。真实宿主工具注册、视觉及平台外发需短时验收。

### dev.39 自愿读取与主人交互收口

角色自主读取以模型明确选择为依据，执行前后复核当前范围；自动记忆/待办上下文改为能力提示，社交生产读取采用按需模式。管理维护不经角色意愿投票。主人私信可选择当前账号真实观察清单、按证据保存当前主人明确事实，复用原身份记忆及额度；缓存清单不含图片字节。保留现有授权和意愿执行门禁。业务恢复字段级选择（依赖组合原子化），运行日志事件归并并提供安全诊断分类。旧备份格式不变。完整图片发送、全渠道工具对等及网页完整诊断包仍待实现；真实宿主验收未完成。详见 [交互场景与工具能力指南](../interaction-tools.md)。

### dev.40 主人观察图片与待办

真实观察清单/精确 JPEG 核验不等于披露。主 Session 绑定实际主人轮次和账号，通过宿主附件服务返回图片块（准备回执而非显示成功）；主人私信需自主选择清单、精确分镜及独立图片发送，复用原 Life 意愿、发送事务、Python 暂停与平台 msg_key；仅当前主人和真实缓存，未知结果冻结，不扩大其他场景授权。两个主人入口共享当前账号待办查询、开放待办延期/放弃；不能伪造完成。实际宿主和平台图片传输、账号切换、暂停、过期/缺图的实机验收仍需执行。普通文字独立披露、全后台读取迁移、完整工具对等及网页完整诊断 ZIP 尚未完成。见[交互工具指南](../interaction-tools.md)。

### 运行日志级别与展示（dev.41）

运行日志按真实事件级别、退出码和诊断计数展示卡片；零错误统计不计为错误，重试或首次配置锁定显示警告，最终失败仍显示错误。读取范围、历史无时间输出及省略数量明确展示。网页仍只导出安全摘要，原始诊断使用原导出工具；未知事件不推断具体原因。正式版前需在 Windows 核对真实日志。
