# 2.8.2 正式版发布 · Windows PowerShell（维护者）

> **发布门禁必须先全绿。** 本文提供发布步骤，不代表已执行 GitHub、npm 或 DSHMarket 上线。请先阅读交付包顶层的 `RELEASE_GATE_2.8.2.md`。本轮离线首次全量检查仍有失败，不能跳过验收直接推稳定 Tag。

## 1. 确认源码和全量回归

在仓库根目录执行。请保留已有配置、日志和工作区修改，不使用 `git reset --hard`、不清空用户数据：

```powershell
$ErrorActionPreference = 'Stop'
git branch --show-current
git status --short
node -p "require('./package.json').name + '@' + require('./package.json').version"
git diff --check
npm ci --ignore-scripts
npm run check:test-governance
npm run check:context-budget
npm run check:life-architecture
npm run check:video-tool-contract
node selfcheck.mjs
node --test test/*.test.mjs
python -m unittest discover -s test -p 'test*.py'
.\run-tests.ps1 -Mode full
npm pack --dry-run --ignore-scripts
```

必须确认最后一条测试 **0 failure**，并在普通与管理员权限环境下核查 Windows DSH 设置页、老用户升级与资料保全、Ollama 开关与模型失败提示、主人真实局部 10/15/20/30 秒验收、Life 自主选择/跳过与证据归属、ASR CUDA 与 CPU 回退；检查账号切换、私信/评论权限和 `-509` 限流。**没有完成以上验收就停在此处。**

## 3. 合入 main 后创建唯一稳定 Tag

GitHub `release.yml` 要求版本与 Tag 严格匹配，且稳定 Tag 必须是 `origin/main` 的祖先。开始前先确认 Git 与 npm 上不存在同名版本：

```powershell
git switch main
git pull --ff-only origin main
git status --short
node -p "require('./package.json').version"     # 必须严格等于 2.8.2
git tag -l v2.8.2
git ls-remote --tags origin refs/tags/v2.8.2
npm view dsh-dafeiyu-life@2.8.2 version --registry=https://registry.npmjs.org/
```

必须确认 `git status` 干净、版本为 `2.8.2`、远程没有 `v2.8.2`、npm 没有现成 `2.8.2`。在 CI 与 Windows 实机均绿后：

```powershell
git tag -a v2.8.2 -m "大肥鱼 2.8.2 · 视频感知体验优化"
git push origin v2.8.2
```

推送 Tag 会触发 GitHub Actions 自动构建六个平台的 `.tgz` 并发布 GitHub Release；**不会自动执行 npm publish**。确认 `release.yml` 所有 Job 成功，GitHub Release 包含六个平台包与 `SHA256SUMS.txt`，发布说明为正式版。失败时先修复原因，不手动补一个假成功的 Release。

## 4. npm 正式发布

只有在 Release 全绿、包名与 Git Tag 匹配、打包清单正确、npm 版本未被占用并且有 npm 权限时：

```powershell
npm whoami --registry=https://registry.npmjs.org/
npm view dsh-dafeiyu-life version --registry=https://registry.npmjs.org/
npm publish --dry-run --ignore-scripts --access public --registry=https://registry.npmjs.org/
# 再检查要发布的是 main 上 v2.8.2 对应的内容后执行：
npm publish --ignore-scripts --access public --registry=https://registry.npmjs.org/
npm view dsh-dafeiyu-life@2.8.2 version --registry=https://registry.npmjs.org/
npm view dsh-dafeiyu-life dist-tags --json --registry=https://registry.npmjs.org/
```

npm 若要求登录或双因素认证，请使用官方交互流程；不要将 token、`.npmrc` 或任何密钥写进 Git。若版本已存在，不得重复发布或覆盖。
