# 大肥鱼 2.8.3 · 正式版功能说明

**让经历成为记忆，让生活成为连贯的自主行动。** 本说明定义 2.8.3 正式版范围；不是发布完成证明。实际发布以渠道版本及[验收门禁](2.8.3-release-checklist.md)为准。

## 主要变化

- **底层统一 Life Agent 重构（核心架构升级）：** 以一个 Life 主体贯通已接线的自主意愿、工具选择、作用域核验、执行回执、视频感知、活体记忆、反思和后续生活候选；原主 Session 宿主循环与专业 Video Agent 保留分工，不另建调度器或事实库。主人/好友/陌生人私信、评论及后台共享人格与权限契约；已接线能力互通，剩余通用循环、全工具授权和真实宿主验收见[开发台账](2.8.3-development-debt.md)。
- **自然表达与技术回执分离：** 普通聊天和所有 B站角色场景用真实意愿与执行事实组织自然表达，不将技术失败冒充自主拒绝。可信私下主人可明确追问脱敏技术事实，非主人和公开渠道隔离私密技术数据；真实主人主 Session `work:` 可采用工作呈现；候选版精确主人自身私信委托可跳过角色意愿，仍遵守账号、范围、预算及证据保护。第三方披露、外部写入和 B站工作命令不因此开放。

- **自然语义优先（逐步迁移）：** 已接线的主人私信理解、情绪、待办、人格反思和部分语义回忆减少固定词表与句式判断，复用原模型、真实经历和证据；不增加权限，保留必要的身份、隐私及执行核验。其余历史语言规则仍待迁移。
- **真实视频观察：** 分镜、单帧、局部补看与时间码回放。先了解全貌，再由鱼鱼自主决定是否细看；模型失败、缓存复用、字幕和画面分别记录，不声称看过未采样画面。视频与语音均为可选能力。
- **可衰减的深浅记忆：** 同一视频可有多次独立观察，按需打开仍有效的细节；支持词法、本地语义、画面查询、完整 BV 精确匹配，遗忘与账号权限贯穿。3200 个逻辑经历容量，优先回收遗忘占位，长期记忆独立。
- **自主联想与反思：** 真实候选与模型确认分别记录，长期关系需证据核验；支持独立认识、有限暂停候选恢复、有界强化。不强制生成关系，不把查询当成采用，不从永久档案恢复遗忘。
- **记忆工作区：** 顶部折叠记忆设置、独立记忆预设、统一搜索、神经回忆场、紧凑人生经历与长期记忆、健康面板及七日实际变动。无旧历史统计时不补造。
- **一个 Life、独立能力：** B站、自主生活、人格、自动记忆与经历桥可分别控制；本地记忆不要求 B站登录，原 Session 可以继续使用；跨场景补看与私人经历读取继续受原权限约束。主人任务回写与经历桥独立。
- **更清晰的配置：** 模型同步验证优先，新用户反思与 AI 记忆检索沿用默认模型；本地语义回忆是首次配置必需项，由插件安装 llama.cpp CPU 运行时及约639 MB Qwen3-Embedding 模型，无需 Ollama/Python 或 B站登录；词法回忆保留。Ollama 仅是可选视觉路线的依赖，需用户先安装。Ollama 2B/4B 已安装识别、下载成功回执、固定原图验收与明确启用。鱼鱼导览采用独立演示数据，可跳过及重看，结束清理状态。
- **更及时的交流：** 主人定向私信默认日常60秒、活跃30秒，普通联系人仍使用原哨兵和自适应检查。检测不保证回复，不绕过拒联、限流、账号及外发门禁。
- **稳定性与数据管理：** 后台 Headless 使用子进程临时会话配置，不续用主人 Session；旧会话不自动删除。V2 统一迁移 Whisper/Embedding 大模型，核心运行时和 Life 不随之迁移；失败临时目录仅在核验所有权后回收。自动业务备份保留最近两日，手动及记忆备份独立；业务备份按分类预览设置差异与记忆概况，明确选择后恢复常用偏好、符合当前准入的生活方案及已验证模型，授权与总开关保持当前值；记忆缺失附件可独立核验修复，核心历史记录不覆盖；完整诊断覆盖记忆和 SQLite 快照，排除可重建大型资源和认证文件。

## 兼容性与限制

旧用户的显式设置、人格、经历、账户授权不因升级重置；旧缺键的保守社交值保留。新装推荐值不是外发授权。无需重建索引、删除旧环境或旧聊天来升级。旧整盘冷备份和互斥模式不是现行产品功能。桌宠真实接入、自由工作台、通用跨类型联想仍属后续规划。

实际模型能否自然选择视觉工具、主动联想或在未来生活中采用关系，不以必须产生次数承诺。后台会话隔离依赖宿主实际支持，Windows/DSH 验收须通过。详见[升级指南](2.8.3-user-upgrade-guide.md)、[现行架构](../architecture/2.8.3-current-architecture.md)。

### dev.38 运行总控、日志与分享视频

- 顶部自主生活开关与生活方案共用 `lifeAgentMode`/`autonomousPlannerEnabled`；保留原节奏，暂停自动人生反思，不影响显式手动回忆/反思和独立互动回复。互动回复开关暂停后台私信（含主人优先检测）、评论及 @ 回复；现有各渠道授权保持，重新开启不产生新授权。插件内手动私信、评论回复也受此暂停，独立原创主评论不因这个开关直接授予或撤销授权；共享 Life 发送通道暂停期间不出站。已提交平台请求仍按真实回执收口，未知结果不能自动重试。
- 日志页提供固定四个本机日志的有界分类摘要、错误筛选及 JSON 导出（每文件最多 8 MiB，最多 20,000 条导出；不含原始正文）。完整错误溯源使用现有 `tools/导出B站日志.bat`，日报 Markdown 及内部归档保留。日志分类不是完整错误审计，缺失/轮转/超限明确展示。
- 神经回忆场仅保留六类节点筛选，情绪依据活体证据；桌面画布/容器高度 1.5 倍，窄屏适配。
- 主 Session 已有 `bili_watch_video`（standard/deep 依能力）；主人/授权好友私信经 `shared_link` 真实元数据核验后可在同一轮自主选择 `shared_video`，仅对已验证同账号同联系人目标，复用共享读预算、视觉租约、标准感知。只交付实际验证的代表画面和/或字幕文字，非完整播放。历史画面仍可经现有记忆工具按需回忆，陌生人/评论仅保留原受限菜单。真实宿主工具注册、视觉及平台外发需短时验收。

### dev.39 自愿读取与主人交互收口

角色自主读取以模型明确选择为依据，执行前后复核当前范围；自动记忆/待办上下文改为能力提示，社交生产读取采用按需模式。管理维护不经角色意愿投票。主人私信可选择当前账号真实观察清单、按证据保存当前主人明确事实，复用原身份记忆及额度；缓存清单不含图片字节。保留现有授权和意愿执行门禁。业务恢复字段级选择（依赖组合原子化），运行日志事件归并并提供安全诊断分类。旧备份格式不变。完整图片发送、全渠道工具对等及网页完整诊断包仍待实现；真实宿主验收未完成。详见 [交互场景与工具能力指南](../interaction-tools.md)。

### dev.40 主人交互补充

主人主 Session 与私信可自主核验最近观察的真实缓存分镜，并独立选择分享；主 Session 使用宿主附件准备回执，B站使用内部图片私信适配器并要求真实平台回执。两渠道共享当前账号待办查询、延期与放弃。实际宿主附件与图片投递尚待短时验证；普通文字独立披露凭据、完整渠道对等与网页完整诊断包仍待完善。

### 运行日志级别与展示（dev.41）

运行日志按真实事件级别、退出码和诊断计数展示卡片；零错误统计不计为错误，重试或首次配置锁定显示警告，最终失败仍显示错误。读取范围、历史无时间输出及省略数量明确展示。网页仍只导出安全摘要，原始诊断使用原导出工具；未知事件不推断具体原因。正式版前需在 Windows 核对真实日志。


### dev.42 主人观察与定向检查

主人定向检查以请求开始计时，保留串行、退避与最短完成后缓冲；诊断增加真实日常/活跃间隔与耗时。当前账号的已核验主人新观察可进入原相册，缺失原图不补造。主人私信独立文字记忆披露、主 Session 同轮真实分镜读取后才可分享。运行日志页经本机主人确认复用 Windows 原诊断收集器，内存快照不触发调度，私密数据须人工核对。真实图片投递、宿主附件展示、Windows 实际导出、全部后台读取与主人渠道对等仍待验收或完善；不放行正式发布。

### 自然语义优先（dev.87 候选进展）

统一 Agent 的已接线私信路径将人物身份定位、语义理解、自主意愿及真实执行分离，减少用户必须学习固定句式的负担。主人私信诊断追问复用原社交模型；非主人数据隔离仍有效。交流情绪不再由入站关键词直接写入，主人私信待办不再从固定句式或口头承诺猜测任务；复用原模型与证据门禁。确认回复不再按措辞自动增加表达、耐心、边界分数；原反思与真实行为观察保留。社交异步语义回忆的相关公开视频不再被固定词表二次否决。主人已确认回复不再按感想关键词重复写入私密经历，由原模型低频提炼；短主题词法回退不再依赖固定话题词或中文长度。主人普通回复、已确认回访与探索统一进入原语义提炼；近期行动由模型自主选择，检索不再用话题词扩展查询或猜测当前视频。全插件历史自然语言规则迁移与真实模型验收尚未完成。

历史主人私信固定命令解析器已退役；现行模型、提案与权限不变。开放人格兼容与运行契约解耦留至 2.9.x 及以后，不列为本版新功能。
