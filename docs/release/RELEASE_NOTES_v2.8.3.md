# 大肥鱼 2.8.3 · 正式版功能说明

**让经历成为记忆。** 本说明定义 2.8.3 正式版范围；不是发布完成证明。实际发布以渠道版本及[验收门禁](2.8.3-release-checklist.md)为准。

## 主要变化

- **真实视频观察：** 分镜、单帧、局部补看与时间码回放。先了解全貌，再由鱼鱼自主决定是否细看；模型失败、缓存复用、字幕和画面分别记录，不声称看过未采样画面。视频与语音均为可选能力。
- **可衰减的深浅记忆：** 同一视频可有多次独立观察，按需打开仍有效的细节；支持词法、本地语义、画面查询、完整 BV 精确匹配，遗忘与账号权限贯穿。3200 个逻辑经历容量，优先回收遗忘占位，长期记忆独立。
- **自主联想与反思：** 真实候选与模型确认分别记录，长期关系需证据核验；支持独立认识、有限暂停候选恢复、有界强化。不强制生成关系，不把查询当成采用，不从永久档案恢复遗忘。
- **记忆工作区：** 顶部折叠记忆设置、独立记忆预设、统一搜索、神经回忆场、紧凑人生经历与长期记忆、健康面板及七日实际变动。无旧历史统计时不补造。
- **一个 Life、独立能力：** B站、自主生活、人格、自动记忆与经历桥可分别控制；本地记忆不要求 B站登录，原 Session 可以继续使用；跨场景补看与私人经历读取继续受原权限约束。主人任务回写与经历桥独立。
- **更清晰的配置：** 模型同步验证优先，新用户反思与 AI 记忆检索沿用默认模型；本地语义回忆是首次配置必需项。Ollama 2B/4B 已安装识别、下载成功回执、固定原图验收与明确启用。鱼鱼导览采用独立演示数据，可跳过及重看，结束清理状态。
- **更及时的交流：** 主人定向私信默认日常150秒、活跃30秒，普通联系人仍使用原哨兵和自适应检查。检测不保证回复，不绕过拒联、限流、账号及外发门禁。
- **稳定性与数据管理：** 后台 Headless 使用子进程临时会话配置，不续用主人 Session；旧会话不自动删除。V2 统一迁移 Whisper/Embedding 大模型，核心运行时和 Life 不随之迁移；失败临时目录仅在核验所有权后回收。自动业务备份保留最近两日，手动及记忆备份独立；完整诊断覆盖记忆和 SQLite 快照，排除可重建大型资源和认证文件。

## 兼容性与限制

旧用户的显式设置、人格、经历、账户授权不因升级重置；旧缺键的保守社交值保留。新装推荐值不是外发授权。无需重建索引、删除旧环境或旧聊天来升级。旧整盘冷备份和互斥模式不是现行产品功能。桌宠真实接入、自由工作台、通用跨类型联想仍属后续规划。

实际模型能否自然选择视觉工具、主动联想或在未来生活中采用关系，不以必须产生次数承诺。后台会话隔离依赖宿主实际支持，Windows/DSH 验收须通过。详见[升级指南](2.8.3-user-upgrade-guide.md)、[现行架构](../architecture/2.8.3-current-architecture.md)。
