# 大肥鱼 2.8.3 · 使用与升级指南

## 已有用户

1. 在当前版本创建业务备份，确认角色、账号、实际数据路径及可用空间；大型模型与运行环境不属于业务备份。必要时另备份实际模型目录。不要删除旧数据、索引或会话。
2. 从可信渠道安装实际目标版本，完全退出 DSH Desktop 后重新启动。从原生设置 → 大肥鱼重新打开管理中心（端口可能变化）。已有配置按实际状态保留，不要求重新选预设或重新安装已就绪模型。未完成引导可继续。
3. 检查能力开关、原 Session、模型连接、账号授权、记忆和生活时间线；已有用户明确关闭的权限与检索配置不应改变。快速设置可重看教程，不重置配置。
4. 如升级异常，停止运行，保留当前数据与日志。按[发布验收](2.8.3-release-checklist.md)核对兼容性后回退代码；不要直接用旧程序覆盖新格式数据，不盲目删除迁移目录或重发未知结果的消息。

## 新用户

- 自主生活：按快速设置完成运行依赖、B站登录；提示重启时从 DSH 重新打开管理中心，再确认登录。先同步并验证文字模型，再配置默认与反思模型；AI 辅助检索默认使用默认模型。
- 绑定原在线主 Session，安装必需的本地语义回忆，等待真实服务与索引就绪。只想使用本地记忆可退出平台引导，关闭 B站和自主生活，保存并重启，再走本地记忆配置；不需要 B站登录。
- 视频画面理解、语音识别可选。Ollama 已装 Qwen3.5 2B/4B 时先检测；未装才下载，必须图片验收和认可后启用。保存当前设置再继续，不把选中模型当成生效。
- 完成配置后由鱼鱼介绍行动树、神经回忆场、健康面板、模型管理和快速方案。演示为虚拟数据，不会写入记忆或授权；只能通过教程导航或跳过退出。之后在快速设置「重新看教程」。

## 日常使用

- 「鱼鱼正在做」看实际行为及结果，分镜和补看只展示真实观察；「鱼鱼想做」管理意愿与待办。
- 「鱼的记忆」顶部设置可独立修改遗忘、召回、反思方案；搜索紧邻神经场，完整 BV 只返回该视频的清晰有效经历。长期记忆展开后可查看来源和删除；健康统计不等于历史容量增长。
- 「AI 模型」同步、验证与分配用途；模型验证失效时按提示恢复，费用与模型选择独立于记忆方案。
- 主人私信的定向检查位于消息感知设置。默认60秒/活跃30秒；平台限流、预算、休息或模型忙碌可延期，不保证每次立即回复。
- 模型分盘只迁移 V2 的 Whisper/Embedding 大模型，Ollama 自己管理模型；停机后按界面检查迁移及回读。原副本不是必然垃圾，核实当前路径后再处理。不要移除正在使用的 Python 环境。
- 在「从备份恢复」选择文件，点击「预览与恢复」。弹窗显示当前与备份的记忆条数、最后记录时间和设置分类差异；默认不选任何分类。勾选并确认后才写入，确认前或配置已变化时不会应用。生活开启需要当前准入，文字模型、Whisper 需要现有环境验证；登录、授权、历史任务及未知旧参数不覆盖。兼容旧业务 schema 1/2（缺角色标记的旧包另行确认），原 SHA-256 不伪造。人生记忆恢复入口支持现有双层备份或同角色完整业务备份，仅补回可核验的缺失深层附件，不恢复缺失主账本或已忘记的记录。
- 诊断导出不是恢复备份。完整日志可能含私密生活数据，勿公开上传。旧 Ungrouped 会话应经宿主核验归属后处理，插件不按标题批量删除。

### dev.38 运行总控、日志与分享视频

- 顶部自主生活开关与生活方案共用 `lifeAgentMode`/`autonomousPlannerEnabled`；保留原节奏，暂停自动人生反思，不影响显式手动回忆/反思和独立互动回复。互动回复开关暂停后台私信（含主人优先检测）、评论及 @ 回复；现有各渠道授权保持，重新开启不产生新授权。插件内手动私信、评论回复也受此暂停，独立原创主评论不因这个开关直接授予或撤销授权；共享 Life 发送通道暂停期间不出站。已提交平台请求仍按真实回执收口，未知结果不能自动重试。
- 日志页提供固定四个本机日志的有界分类摘要、错误筛选及 JSON 导出（每文件最多 8 MiB，最多 20,000 条导出；不含原始正文）。完整错误溯源使用现有 `tools/导出B站日志.bat`，日报 Markdown 及内部归档保留。日志分类不是完整错误审计，缺失/轮转/超限明确展示。
- 神经回忆场仅保留六类节点筛选，情绪依据活体证据；桌面画布/容器高度 1.5 倍，窄屏适配。
- 主 Session 已有 `bili_watch_video`（standard/deep 依能力）；主人/授权好友私信经 `shared_link` 真实元数据核验后可在同一轮自主选择 `shared_video`，仅对已验证同账号同联系人目标，复用共享读预算、视觉租约、标准感知。只交付实际验证的代表画面和/或字幕文字，非完整播放。历史画面仍可经现有记忆工具按需回忆，陌生人/评论仅保留原受限菜单。真实宿主工具注册、视觉及平台外发需短时验收。

### dev.39 自愿读取与主人交互收口

角色自主读取以模型明确选择为依据，执行前后复核当前范围；自动记忆/待办上下文改为能力提示，社交生产读取采用按需模式。管理维护不经角色意愿投票。主人私信可选择当前账号真实观察清单、按证据保存当前主人明确事实，复用原身份记忆及额度；缓存清单不含图片字节。保留现有授权和意愿执行门禁。业务恢复字段级选择（依赖组合原子化），运行日志事件归并并提供安全诊断分类。旧备份格式不变。完整图片发送、全渠道工具对等及网页完整诊断包仍待实现；真实宿主验收未完成。详见 [交互场景与工具能力指南](../interaction-tools.md)。

### dev.40 主人观察图片与待办

真实观察清单/精确 JPEG 核验不等于披露。主 Session 绑定实际主人轮次和账号，通过宿主附件服务返回图片块（准备回执而非显示成功）；主人私信需自主选择清单、精确分镜及独立图片发送，复用原 Life 意愿、发送事务、Python 暂停与平台 msg_key；仅当前主人和真实缓存，未知结果冻结，不扩大其他场景授权。两个主人入口共享当前账号待办查询、开放待办延期/放弃；不能伪造完成。实际宿主和平台图片传输、账号切换、暂停、过期/缺图的实机验收仍需执行。普通文字独立披露、全后台读取迁移、完整工具对等及网页完整诊断 ZIP 尚未完成。见[交互工具指南](../interaction-tools.md)。

### 运行日志级别与展示（dev.41）

运行日志按真实事件级别、退出码和诊断计数展示卡片；零错误统计不计为错误，重试或首次配置锁定显示警告，最终失败仍显示错误。读取范围、历史无时间输出及省略数量明确展示。网页仍只导出安全摘要，原始诊断使用原导出工具；未知事件不推断具体原因。正式版前需在 Windows 核对真实日志。


### dev.42 主人观察与定向检查

主人定向检查以请求开始计时，保留串行、退避与最短完成后缓冲；诊断增加真实日常/活跃间隔与耗时。当前账号的已核验主人新观察可进入原相册，缺失原图不补造。主人私信独立文字记忆披露、主 Session 同轮真实分镜读取后才可分享。运行日志页经本机主人确认复用 Windows 原诊断收集器，内存快照不触发调度，私密数据须人工核对。真实图片投递、宿主附件展示、Windows 实际导出、全部后台读取与主人渠道对等仍待验收或完善；不放行正式发布。
