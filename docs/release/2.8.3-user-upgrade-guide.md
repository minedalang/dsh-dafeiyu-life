# 大肥鱼 2.8.3 · 使用与升级指南

## 已有用户

1. 在当前版本创建业务备份，确认角色、账号、实际数据路径及可用空间；大型模型与运行环境不属于业务备份。必要时另备份实际模型目录。不要删除旧数据、索引或会话。
2. 从可信渠道安装实际目标版本，完全退出 DSH Desktop 后重新启动。从原生设置 → 大肥鱼重新打开管理中心（端口可能变化）。已有配置按实际状态保留，不要求重新选预设或重新安装已就绪模型。未完成引导可继续。
3. 检查能力开关、原 Session、模型连接、账号授权、记忆和生活时间线；已有用户明确关闭的权限与检索配置不应改变。快速设置可重看教程，不重置配置。
4. 如升级异常，停止运行，保留当前数据与日志。按[发布验收](2.8.3-release-checklist.md)核对兼容性后回退代码；不要直接用旧程序覆盖新格式数据，不盲目删除迁移目录或重发未知结果的消息。

## 新用户

- 自主生活：按快速设置完成运行依赖、B站登录；提示重启时从 DSH 重新打开管理中心，再确认登录。先同步并验证文字模型，再配置默认与反思模型；AI 辅助检索默认使用默认模型。
- 绑定原在线主 Session，安装必需的本地语义回忆，等待真实服务与索引就绪。只想使用本地记忆可退出平台引导，关闭 B站和自主生活，保存并重启，再走本地记忆配置；不需要 B站登录。
- 视频画面理解、语音识别可选。Ollama 已装 Qwen3.5 2B/4B 时先检测；未装才下载，必须图片验收和认可后启用。保存当前设置再继续，不把选中模型当成生效。
- 完成配置后由鱼鱼介绍行动树、神经回忆场、健康面板、模型管理和快速方案。演示为虚拟数据，不会写入记忆或授权；只能通过教程导航或跳过退出。之后在快速设置「重新看教程」。

## 日常使用

- 「鱼鱼正在做」看实际行为及结果，分镜和补看只展示真实观察；「鱼鱼想做」管理意愿与待办。
- 「鱼的记忆」顶部设置可独立修改遗忘、召回、反思方案；搜索紧邻神经场，完整 BV 只返回该视频的清晰有效经历。长期记忆展开后可查看来源和删除；健康统计不等于历史容量增长。
- 「AI 模型」同步、验证与分配用途；模型验证失效时按提示恢复，费用与模型选择独立于记忆方案。
- 主人私信的定向检查位于消息感知设置。默认150秒/活跃30秒；平台限流、预算、休息或模型忙碌可延期，不保证每次立即回复。
- 模型分盘只迁移 V2 的 Whisper/Embedding 大模型，Ollama 自己管理模型；停机后按界面检查迁移及回读。原副本不是必然垃圾，核实当前路径后再处理。不要移除正在使用的 Python 环境。
- 业务恢复默认仅安全设置与规则；若同角色完整校验备份的生活方案不同，可勾选「同时恢复备份中的自主生活方案」，核对差异并确认。开启方案需要当前总开关、平台与自主能力、登录及模型均可用；不会恢复旧授权或总开关。未选或不可恢复时明确保留当前状态。恢复后按提示重启核对。
- 诊断导出不是恢复备份。完整日志可能含私密生活数据，勿公开上传。旧 Ungrouped 会话应经宿主核验归属后处理，插件不按标题批量删除。
