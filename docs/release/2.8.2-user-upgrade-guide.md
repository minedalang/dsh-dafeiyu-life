# 大肥鱼 Plus 2.8.2 · 使用与升级指南

> 当前源码 `2.8.2-dev.31` 为正式发布前的开发候选版；请以实际发布公告与 npm 版本为准。

## 开始使用

在 DSH 插件市场找到大肥鱼，或通过已支持的 npm 安装途径升级，并重启 DSH。打开 **大肥鱼设置 → 管理中心 → 快速设置**，检查 B站登录及 Headless 文字模型的真实连接；已通过配置不需要重新安装。视频视觉、FFmpeg 和 Whisper 都是可选增强功能，默认不能绕过 Life 自主意愿。

## 了解新的视频感知

在 **管理中心 → 视频探索** 选择轻量 / 均衡 / 详查档。Life 可先理解全局分镜，再自主决定是否对一个或多个可信时间点进行真实视频局部复查。所有局部窗口共享本次视频经历的执行额度，候选不因第一批复查完成而被自动清空。

全局官方低清 videoshot 时间码来自 B站采样索引；**视觉模型写出的「这个时刻发生了什么」是未经人工逐帧确认的模型判断**，即使时间码确实存在也可能把某个动作错配到邻近格子。请在 **运行诊断 → 🎞️ 视频感知全链路 · Life 最终输入 Debug** 中，放大每张实际输入的 JPEG，检查分镜对应时刻、模型逐张回执及是否完整。如果模型只分析了部分分镜或回答中途截断，不会算作完整视觉观察。

## Whisper 模型

在 **AI 模型 → 视觉识别模型** 按需配置本地转写。依赖安装、模型权重下载和校验分别显示，模型页会自动更新日志。安装成功不等于完成真实转写；需要查看实际音轨转写回执。替换 small 为 tiny 后，可在已安装模型列表中确认删除不再使用的插件缓存；正在使用及外部模型目录不可直接删除。

## 权限与成本

视觉模型调用可能计费，按档位和剩余预算采样；低清预览不等于真实原视频复查，采样分镜不等于完整视频播放。查看视频不会自动赋予评论、点赞、关注或私信权限。既有数据与生活记忆不因打开快速设置被重置。

## 遇到问题

先检查模型是否实际支持图片、分镜是否完整到达、视觉结果状态是否为 `analyzed` 或 `cached`，再核对视频来源与时间标签。报告问题时可提供去隐私化的诊断结果；不要公开 B站登录凭证和私人消息。
