## 二、实质修复及验收

1. **Mermaid/GitHub CI（已离线复现并修复）**：生成器统一 LF，`.gitattributes` 固定预览文件 `text eol=lf`，校验行尾归一化但真实图内容漂移依然失败。测试既验证 Windows CRLF checkout 也验证修改图内容必须拒绝。执行 `npm run write:life-architecture-view` 并把生成文件一起提交。
2. **退避账本迁移（生产缺陷修复）**：旧 40 分钟 DM 网络退避仅在内存迁移且可能在重启后重复，现经账户锁将一次性迁移持久化，继续使用真实 dm-list 恢复回执；未放宽 -509 退避。
3. **主人私信推荐偏好（生产连线修复）**：Owner DM 认证入口在统一 Life 流程中遗漏对 `observeAuthenticatedOwnerDmPreferences` 的调用，已补回在可信输入处（仅 owner、账号未阻断、当前消息身份和时效检查），禁止模型自行发放权限。
4. **管理中心重复 DOM ID（UI 生产缺陷）**：网络退避状态和历史补录状态曾复用 `dm-recovery-status`，现将前者更名 `dm-network-recovery-status`；恢复单次显式操作的 **S0/S1 匿名、只读发布验收快照**，服务端继续 `releaseReady=false`，不会执行平台写入或改变调度状态。
5. **测试夹具修复**：新五分钟双通知计数哨兵取代旧每轮 DM/@/评论直接读列表模拟；Windows Headless 假 EXE 使用复制 Node 的可执行程序，不再用 Unix shebang 文本伪造 `.exe`；Python Node 测试尊重 `PYTHON` 变量；动态评论 Python Mock 补齐 `_gate_read` 真实签名；改进 owner、视觉、版本和只读接口断言。
