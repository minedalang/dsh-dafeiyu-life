# 2.8.1 用户升级与视频感知配置说明（发布前草案）

> 适用于从 2.8.0 升级及首次安装的用户。2.8.1 是否正式发布以正式 Tag / 发行渠道为准。**本文不表示已通过所有 Windows 生产视频视觉验收。**

## 升级后先查看一次新版快速设置

打开 DSH Desktop → 大肥鱼 → 管理中心，首次进入会自动展示 **🚀 快速设置**。请核对原有登录/模型/生活方案，阅读新增视频视觉引导，点击「我已查看本版快速设置」。已完成设置的旧用户**不用重装运行环境、重新扫码或重新保存生活设置**；后台 Life 也不会因这个阅读提示自动暂停。初次安装用户仍须实际完成 B站登录验证与至少一个 Headless 文字模型连接验证。

## 想使用视频画面识别

1. 在快速设置的 **「03 新版设置检查」** 入口可直接定位绿色高亮的 **02B · 视频视觉感知**；点击「配置视觉模型并进行图片验收」。
2. 在「AI 模型 → 视觉识别模型」的折叠标题处**手动启用视觉推拉开关**，模型配置区自动展开。关闭时不能展开；尚未保存前不改变实际运行授权。选择 DSH 多模态模型或本地 Ollama 视觉模型。DSH 自定义 Provider 先检查 Headless 是否同步、连接验证是否有效；仅文字模型或 `input: image` 声明不能证明真的会识图。
3. **仅环境异常时**点击「自动修复视觉运行环境」。健康的原有 Python 不需要修复；**不要求安装 Conda**，不会默认提权或改系统 TEMP。
4. 用管理页固定原图执行真实识图，确认得到图片工具回执、模型最终回答，并亲自认可结果。没有真实回答不能当作成功。
5. 在视觉模型页面确认开关已开启并**显式保存**。之后可再选择 12/24/48 个采样时刻的预算方案，以及可选 FFmpeg、Whisper；这不会强迫 Life 观看或授予发评论权限。

视频视觉功能是可选的。不使用时保持开关关闭，仍能使用适用的文字资料能力。真实视频理解需要 B站可访问公开内容、受预算约束的取帧和对应视觉模型能力。低清 videoshot 不是实际视频解码，字幕、转写、OCR 的时间邻接也不是音画语义验证。

## 常见区别

| 提示 | 代表什么 | 应该做什么 |
|---|---|---|
| 文字 Headless 验证通过 | 文本连接有实际结果 | 若需图片，再测试视觉模型 |
| 视觉 Python 环境健康 | 依赖、读写具备执行基础 | 不必再修环境；继续图片验收 |
| MCP 图片回执 verified | 固定图片工具回执确实存在 | 继续检查模型实际回答 |
| 模型返回答案 awaiting_review | 已得到文字输出 | 亲自核对图片内容并认可 |
| 视频感知启用但尚无可信观看回执 | 设置已经开启，不代表生产视频实际完成 | 查看视频 Debug/生产回执；失败时不要宣称看过 |

## 发布前特殊说明

目前 Node 宿主已经在 Windows **手动固定图片验收**中取得实际识图结果，独立生产视频 Agent 的 DSH 子会话还没有切换到同一受控宿主机制。正式发布前必须完成生产视频视觉回归；开发版请勿将手动测试的成功误认为所有视频都能识图。

**跳转定位提示：** 管理中心跨页按钮和快速设置进度入口到达对应设置后，会显示短暂绿色定位高亮；启用系统减少动态效果时以静态轮廓提示。
