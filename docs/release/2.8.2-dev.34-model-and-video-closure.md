# 2.8.2-dev.34 · 模型双栏、视频分镜与诊断收口（开发候选）

## 本次实际行为

- 低清视频视觉仍遵守 12 / 24 / 48 帧总采样额度，**每张固定 12 格（4 列×3 行）**。旧版已保存的 4/6 格值会回退到 12，管理中心不再提供分镜格数输入框。改变视频档位只走独立 `video-vision/plan` 设置，不提交私信自主关注字段。
- Headless 页面展示实际 Headless 已有模型；每个自定义模型可以先预览、再确认「取消同步」，只删除 Headless 对应路由，保留 Desktop/Web 来源、其他 Headless 模型、Ollama 本地权重；删除前生成 YAML 备份。已验证状态与路由指纹相关，路径变更需重新验证。
- Desktop/Web **来源模型**的「补充图片与思考能力」只增补原始模型声明，使用带指纹的确认、备份与回读，不会隐式推送至 Headless。用户必须确认模型本身确实支持相关能力，文字连接通过不代表图片输入通过。
- MiniCPM-V 4.7 1B 的**已有安装**仍可选用与删除，新安装由前端和服务端共同拒绝；所有允许型号可见删除入口。删除的是共享 Ollama 权重，可能影响其他使用者应用，必须二次确认。
- 「运行诊断」的 BV 输入仅用于诊断，不属于待保存插件设置，不能弹出全局脏状态提示。
- 导览将「真实观察」具体化为可检查的分镜来源、时间码、模型回执；Life 可以选多个真实候选，也可停止，不会把取帧等同于完整看完或写入长期记忆。

## 兼容性与权限边界

- 保留旧视频格数配置字段用于旧数据兼容，但是运行时和新增保存接口统一钳制为12格；不清理用户账号或记忆。
- Headless 逐模型取消同步不会触发 Ollama 模型删除，不修改 Desktop/Web 自定义模型配置，不改变 DSH 全局共享 Profile。
- 视觉识图有文字回执并不等于视觉内容准确；上传的 GTA 视频中，Qwen3.5 2B 仍可能把03:31室内通道描述成客舱。
- ASR 本轮仅从已授权的本地复用缓存返回：`cacheHit=true`，不是在数百毫秒内重新转写五分钟音轨。
