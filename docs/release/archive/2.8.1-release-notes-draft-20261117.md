# 大肥鱼 2.8.1 更新说明（草稿，暂不发布）

**本版重点**：用户可选择让鱼鱼在受控预算内观察公开视频画面，结合真实字幕、可选语音转写、OCR 及公开讨论形成有来源的理解；鱼鱼仍可以自己决定是否探索、复查、表达或休息。

**新版快速设置**：升级用户首次打开管理中心时会再次进入 2.8.1 快速设置，核对原有配置即可，不强制重装。新增独立视频视觉引导，在视觉模型页选择 DSH 或本地 Ollama、按需修复环境、进行固定图片验收、人工认可，再自行启用。视频视觉、FFmpeg、Whisper 均可选。

**视频感知与记忆**：区分真实解码画面与官方低清预览；多时刻取样、有限窗口复查及字幕/ASR/OCR 时间线均保留来源和可信度，不能把取样说成看完或听过完整视频。神经回忆场支持右键平移和五类组合筛选。

**Life 与可靠性**：保留私信统一 Life 决策、有证据的机会和行动、跨重启技术续办、平台读取预算与未知写入冻结。新增进程内模型/读取/视频/视觉协调，但不承诺所有独立 Python/DSH 跨进程原子排队。

**模型管理**：Headless 官方已注册模型可直接验证；自定义 Provider 用预览与确认同步，能力声明与真实文字/图片验证分离。视觉模型环境可按需受控修复，不要求 Conda。

> **发布门禁**：当前只在 Windows 上验证了手动固定图片的 DSH Node 宿主方案。生产 Life 视频视觉仍在旧 Python 子进程链路上；发布前必须修复并完成实机回归。本草稿不得宣传所有视频视觉已完成验收。
