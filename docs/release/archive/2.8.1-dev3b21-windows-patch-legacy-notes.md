# 2.8.1 开发阶段 Windows Patch 历史提醒（归档）

> 仅供历史追溯。正式用户安装不需要应用开发版 Git Patch。

## 2.8.1-dev.3b.33.21 · Windows Patch 路径与实时调度日志导出

- 从 `.19` 代码升级使用 `.19→.21` **累计 UTF-8 Git Patch**。旧 `.19→.20` Patch 曾把 `tools/#U...` 伪名误当成已有文件名，在真实中文文件名 checkout 上会失败；这次不需要重命名本地文件。也提供修复后的 `.19→.20` Patch 供单独复核。
- 保留 `tools/导出B站日志.bat`，双击运行时粘贴当前本机 DSH 管理中心的完整网址（`http://127.0.0.1:实际端口/api/bili-duty/manage`），并保持 DSH 正在运行。可使用 `--no-pause --status-url` 非交互导出。
- 检查 `_diagnostics/live-status-availability.json` 的 `captured`，成功后看 `_diagnostics/live-status-snapshot.json` 的 `scheduler.running`、`scheduler.schedulerPulse.stale`、最近检查时间与下一次预计决策。未捕获时，不要根据持久化设置推断定时器正在运行。
- 日志脚本仅读本机固定接口，不会触发 Life 决策、不访问 B站、不触发模型、不写账号状态。所有原账户配置、队列、记忆、限流与发送未知账本保留。
- **不要直接公开分享导出 ZIP**，其中原始历史日志与账号文件可能有个人敏感信息。Windows PowerShell、实际 DSH Web 端口及运行时调度器需你本机最后验证。
