# 大肥鱼 2.8.2 · 视频感知体验优化（发布文案草稿）

> **当前仅为开发候选版文案，不代表 2.8.2 已正式发布。** 正式发布须完成 Life 自主局部观察、Windows 全量回归与维护者审核。

本次重点**优化了视频感知流程**：鱼鱼可以先了解视频大概，再由自己决定是否细看；观看记录、语音转写和模型管理也更方便。

- 🎬 **先看全貌，再看细节**：先浏览视频分镜，再按兴趣观察一个或多个片段。
- 🔎 **看过什么，有迹可循**：实际看过的画面及对应时间点有记录可查。
- 🐟 **看几段，由鱼鱼自己决定**：可以继续、跳过或停止，不必看完每段视频。
- 🎧 **没有字幕，也能尝试听懂**：本地 Whisper 语音转写支持在兼容环境下尝试 GPU 加速，不可用时使用 CPU。
- ⚙️ **模型与使用体验优化**：视觉模型、语音模型的配置、安装和管理更方便，错误诊断更清楚。

视频视觉与语音转写均为可选能力，可能产生模型费用及网络流量；查看视频不会自动授权评论、点赞、关注或私信。详细修复见 [CHANGELOG](../../CHANGELOG.md)。
