# 大肥鱼 2.6.1-dev.4 开发预览：主 Session 与 B站私信的双向生活联动

> 开发测试版；不代表 npm、DSHMarket 或 GitHub Release 已发布。

## 新增

- **主 Session 真实聊天反馈**：仅对选定的主人 Session 监听真实用户回合，排除插件自身注入的提醒、私信摘要等消息。已有模拟情绪、长期记忆与人格成长仍按各自配置注入提示词；当新聊天明确表达对鱼鱼的感谢、夸赞或需要陪伴等信号时，可温和影响可衰减的模拟情绪。
- **可选同轮自主情绪**：`dafeiyu_feel` 工具让鱼鱼在当前回复时自己选择是否记录一次短期情绪变化；不会额外调用模型，不要求每次更新，强度及本轮次数受限，不照搬用户的情绪。
- **主 Session 经历候选**：经隐私筛选的真实主人聊天可以变成不含原文的私有生活候选，继续经已有 LifeMemoryCoordinator、LifeReflection 及人格证据门槛管理；稳定身份事实仍走 `dafeiyu_remember` 而非自动套写。
- **主人 B站私信完整回路**：主人私信 Agent 读取当前模拟情绪、人格、授权范围内的长期记忆；真实收信触发受限情绪及经历回写；原有模型响应可带可选情绪标签，只有私信发送回执确认为成功才提交该标签。
- **普通好友 B站私信**：每位 UID 的 DM 模型输入分别携带当前角色情绪与抽象成长人格，只能检索与该 UID 及社交权限相符的记录；好友收信的弱情绪信号进入同一个可衰减的状态，不跨 UID 公开私密信息。
- **安全及兼容**：新增无原文、带盐哈希事件账本防重复；控制每日事件上限，尊重关停情绪系统与主人指定会话。未增加自动外发、陌生人私信、主动回访或独立 AI 请求。

## 不在本版内

P5-B 完整的执行前意愿复核和公平调度、P6 自然连发/主动续聊、所有主 Session 回复在宿主最终送达后的统一回执，以及真实平台端到端验证。

## 验收建议

选择主 Session，确保总开关、情绪与长期记忆配置生效。聊天中向鱼鱼自然表达感谢，再核对管理中心「模拟情绪」变化；讨论敏感信息或普通查询不应自动增加新记忆。使用测试 B站账号分别验证主人/好友 DM 的权限分域、重复收信和停用开关。不要将这次本地代码通过等同于平台实机测试通过。
