## 这次鱼鱼多了什么？

- **连续人生记忆**：公开视频、互动与有来源证明的主 Session / 私密交流进入不同可见域的可衰减记忆。保留自然遗忘与隐私隔离，无法通过审计档案取回失去的精确细节。
- **人生反思与长期认识**：有质量门槛的分域反思，允许产生 0 条有效认识；新增诊断区分证据不足、质量拒绝与持久化未采纳，技术失败仍有退避重试。
- **人格成长实验**：可选、默认关闭。真实人格变化必须依靠仍可用的、跨日期可验证证据；独立模拟沙盒不影响真实数据。
- **B站动态评论**：主 Session 在主人明确确认后，可以对真实文字和图文动态评论回复；从动态详情验证 `oid/type` 和 `rpid`，沿用额度、去重与不确定回执不重发约束。
- **B站自主兴趣与收藏**：新建收藏夹的命名按公开兴趣与人设语气变化；原有收藏夹和主人手动名称不被自动覆盖。自发行为受授权和平台约束。
- **DSH Mobile 与电脑管理**：已配对手机通过同源网关进入管理页，受限写操作在手机端只读禁用并提示回电脑；Headless 首次设置强调“同步配置≠验证成功”。
- **鱼鱼活动播报**：电脑和移动管理中心展示安全、只读的活动轮播，提供已认证的本地轮询接口，为未来桌宠预留接入点。
- **外部角色卡**：支持自选大肥鱼素材站人设文本并提示预算与跨平台工具差异；没有捆绑任何第三方卡片内容。

## 升级注意

1. 建议先完成业务备份，私密人生记忆需使用独立备份方式，备份文件不要公开上传。
2. 更新后查看首次启动状态：**B站登录有效**及**Headless 至少一个真实验证通过**缺一不可。配置同步结束后还要点验证。
3. 老安装保留此前配置；可按需在「人生记忆」「次数与额度」使用推荐值，仍需点击保存。更新不会额外开启公开写入。
4. DSH Mobile 通过网关远程连接电脑端 DSH，不需要手机本地运行插件；扫码、模型验证和保存仍在电脑端处理。
5. 人格成长默认关闭；单次反思没产生新认识是允许的，并不等于人格升级失败。

## 安全原则

禁止公开使用私密记忆、跨用户召回、从永久档案复活遗忘细节或未经许可发布评论与动态；新接口不公开敏感 UID、正文、密钥；第三方卡片的工具语句不能变为实际权限。
