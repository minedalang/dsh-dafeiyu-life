# 大肥鱼 · DSH 生活系统 `2.6.0-dev.7`

## 本次功能

1. **人生反思产出诊断**：模型正常返回但没有长期认识时，区分 `model-no-insight`、`quality-rejected`、`not-committed` 和 `created`，记录提出/过滤/实际保存数；失败仍按原技术重试策略，零产出不强制重做或伪造记忆。
2. **人格成长路线图改为「2.6.0 实验版」**：真实时间线不再误写“下一段虚构经历”；沙盒明确标记模拟，不参与真实成长或写盘。新安装默认开启人格成长，已有显式关闭仍保留；所有成长仍受跨日期证据、权限与遗忘约束。
3. **电脑与 DSH Mobile 活动播报**：管理页滚动显示由系统实际完成动作产生的固定类别活动摘要。新增只读轮询 `GET /api/bili-duty/activity-feed`，12 秒刷新，48 小时保留，最多 80 条，供未来桌宠接入；无额外端口，不含账号、私密文本及模型内容。
4. **收藏夹命名更有鱼味**：自动新建收藏夹按真实公开兴趣与人设风格变化，已有同主题收藏夹优先复用；手动命名不改动，原授权、额度和去重机制不变。
5. **外部人设卡兼容提醒**：可从 <https://aigengtu.com/persona> 自选提示词卡并粘贴到自定义人设；最多保存 18,000 字符，部分实际任务限额 8,000 字符（其他任务可能更低）；提示来源工具命令不可在本插件执行。**不重新分发卡片原文。**
6. **README 与 2.6.0 发布材料**：README 改按用户体验组织，不逐个罗列 dev patch；新增正式版 Release 草案、验收门槛及新版 B站置顶动态文稿。

## 验证口径与限制

- 自动化测试覆盖数据隔离、活动事件、人格沙盒、反思零产出、命名样式和现有回归。**测试结果以实际执行日志为准**。
- 未在真实 B站账号执行公开动态评论；未对所有 DSH Mobile 安卓版本、cpolar 网关或所有第三方角色卡做端到端测试。桌宠**尚未完成客户端接入**，仅提供可复用的只读活动接口。
- `2.6.0-dev.7` 不是 `2.6.0` 的正式发布声明，不自动改变旧配置或清空生活数据；人格功能仍属可关闭的实验能力。

## dev.7 发布前修补

- 总开关不会再把已完成一次性引导的用户重新带回 First Start；真实的登录或 Headless 验证失效仍严格阻止受保护业务操作。
- 人生记忆页增加快捷索引，兴趣与熟人区域移至长时间线之前。
- Python MCP 版本不符时，允许在电脑端管理中心明确确认：安全备份旧文件并恢复当前安装包受审脚本。绝不自动执行自定义/不匹配的 Python 文件。
- 活动播报支持经现有已授权状态接口回退读取；移动网关不放行独立播报路径时也有机会显示真实事件。
- 人格成长对全新安装默认启用，保留既有明确关闭设置；无证据时不会虚构成长。
- 私信页面将陌生人额度与主人或白名单通道分开解释，避免历史多轮对话被误判为额度超限。
- README 恢复双域意愿、模拟情绪、兴趣及原有能力的完整产品介绍。
- 本修补保持 `2.6.0-dev.7`，不调整原有测试运行器。

## dev.7 互动与人生记忆界面补丁

- 后台评论「每次检查最多发送回复」上限扩展至 1000，实际发送仍受到每日、单人、24 小时和全局硬额度限制。
- 明确热评数量与私信对话上下文推荐值的作用；人设页移除外部素材站链接。
- 人生记忆页整合为一套有效跳转入口，先展示心情、兴趣、逐渐熟悉的人，记忆流转示意按需展开。
- 不再要求自己发布的动态必须存在本地发布草稿收据；以 B站核验的真实作者身份为准。别人的动态下只有确认来信直接回复鱼鱼的评论，才会进入自动接话流程。
- 不会自动追补此前已被旧规则过滤的评论；公开写入仍遵守各项授权、去重和回执规则。
- 未修改仓库的测试文件与测试脚本。

## dev.7 最终体验补充：情绪来源、主动回访暂停

- 情绪历史添加短小、灰色的既有上下文参考。评论只展示已收到的文本及本轮生成的候选回复，不会冒充已发出；私信原文仅留在当前进程中临时展示，不持久化到情绪历史或备份。人生反思复用同次模型返回的简短 note；**不会增加 AI 调用或额外 API 请求**。
- 主动回访当前能力与期望的主动视频分享、主人/好友情绪联系仍有差距，**2.6.0 暂停开放**。页面禁用并折叠旧版配置；后台统一禁止生成或发送。计划在 **2.6.1** 重构。已有草稿和设置保留，普通评论、私信收件与情绪系统不受影响。

### 发布前功能边界补充

- 已核验主人的私信由**现有 AI 同轮**可选返回待办字段，经原话证据和只读白名单核验后入库；不再靠固定歌手正则，也不增加独立 AI 提取调用或把私信全文放进公开记忆。
- 有明确来源的搜索任务可生成最多 3 条真实 BV 视频候选，由自主计划员择机查看。搜索成功不等于看过，读取视频资料也不等于听过音乐。
- 增加独立的「任务进度回访」授权（默认关闭）：仅对本人建议且实际成功读取视频资料的任务给主人回一条进度，24 小时最多一次、安静时段暂停、退订后禁止，回执不确定时绝不自动重试。未授权期间已完成的任务不会留作以后补发。
- 旧版情绪随机分享、自动好友回访继续暂停；2.6.0 的新增路径仅涵盖**主人任务进度**，广义双向主动联系仍待后续设计。
- 新安装默认启用主人私信受限 Agent 和独立 B站能力；主 Session 近期对话读取默认关闭。旧安装的权限设置不会因升级覆盖。
- 情绪驱动的旧版主动分享已在 2.6.0 暂停运行，诊断和配置保留，计划 2.6.1 重构。
