# 大肥鱼 · DSH 生活系统 `2.6.1-dev.1`

这是 **2.6.1 开发版**，并非 2.6.0 正式版的替代发布。

## 新增 · 鱼鱼可以整理自己的收藏夹

- 允许鱼鱼根据想分享的内容，自主选择新创建收藏夹是否公开。管理中心也可设为始终隐藏或始终公开；默认由鱼鱼决定。
- 允许鱼鱼删除自己创建的主题收藏夹（默认开启，每天最多一次）；仅限本插件真实创建账本和当前 B站账号双方核对成功的收藏夹，不会删除原有收藏夹、默认收藏夹或只凭名称推断的收藏夹。
- 创建和删除仍受总开关、B站登录、独立收藏/删除权限以及工具白名单保护。自主收藏总开关对旧用户仍默认关闭。

## 后续 · P4 统一待办

多来源提议、独立接受决策、任务优先级及自然遗忘仍在方案讨论阶段，不属于 dev.1 已实现功能。

本版涉及外部写入和不可逆删除，务必在测试账号验证 B站实际 API 回执。未经真实 B站端到端验证，不应声称已经在生产中执行成功。
