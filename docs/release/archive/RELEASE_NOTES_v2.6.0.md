# 🐟 大肥鱼 · DSH 生活系统 2.6.0

> 本说明对应 `v2.6.0`。GitHub Release、npm、DSHMarket 并非同步发布，安装时请核对实际版本。完整功能介绍见 [README](../../../README.md)。

**这次最重要的变化：鱼鱼可以从与任何真实用户的相遇中自然建立友情，并根据关系远近，渐渐记住或忘记共同经历。** 同时完善人生记忆、情绪生活、动态互动与管理中心，让日常使用更容易理解。

## 🆕 本版新增

- **自由结识朋友**：通过真实的 B站公开互动积累熟悉度，跨天自然交流可能发展为关系意义上的好友；普通陌生人不会被创建永久人物画像。原白名单保留特殊操作权限，但**友情不等于授权**。
- **按关系自然遗忘**：新产生的公开社交经历会参考双方熟悉程度采用不同衰减周期。六档基准参数可配置；一面之缘可能很快模糊，已遗忘的细节不从审计档案或备份复活。
- **独立的「逐渐熟悉的人」页面**：从拥挤的记忆页面移到「生活与成长」，支持 UID 搜索、按熟悉度分页、公开昵称按需读取、成长阶段与记忆衰减参考值。
- **更丰富的 B站生活记录**：文字/图文动态的评论互动纳入现有身份、授权及回执校验；新增隐私受限的生活活动播报，供桌面与 DSH Mobile 查看。
- **实验性人格成长**：从有证据且仍可访问的经历中观察长期行为倾向，提供独立模拟沙盒；不凭空生成成长，也不保证每次反思都会发生变化。

## ✨ 体验升级与修复

- **记忆与回忆**：可衰减人生经历、公开/私密权限分域、反思及可选检索更一致；跨用户私密内容不能混入公开场景，遗忘不可逆。
- **模拟心情和双域意愿**：真实互动可使角色模拟状态发生变化，影响生活域回复风格与是否沉默；主 Session 的任务边界和外部操作权限不受模拟情绪影响。
- **模型配置更直观**：任务默认自动继承，按需从真实 Provider/模型列表指定；修复下游继承提示与未保存预览混淆，去除容易误导的一键模型填入。
- **管理页与兼容性**：将「人生记忆」简化为「记忆与回忆」，关系管理独立；修复 Windows 环境中 SQLite 初始化导致的临时目录占用；DSH Mobile 保持已配对网关查看模式。
- **安全与可靠性**：外发仍执行 UID 身份、独立授权、额度、退订、去重和真实发送回执检查，不确定结果不自动重发。

## 🚀 安装

选择任意一种方式：

1. **命令行**：`dsh plugin --profile desktop add dsh-dafeiyu-life`
2. **DSH 内插件市场**：在 `dshmarket` 中搜索 `dsh-dafeiyu-life`。
3. **插件市场网站**：访问 [DSHMarket](https://dshmarket.com/zh/)，搜索 `dsh-dafeiyu-life`。

安装或升级后确认插件显示 **2.6.0**，重启 DSH Desktop，按首次设置指引检查 B站登录和 Headless 模型连接。

## 升级须知

- **先备份**：原业务数据、人生记忆及私密数据应按各自备份功能处理，切勿公开上传敏感备份。
- **保留旧权限**：升级不自行修改主人 UID、白名单、模型或外发授权；新的关系成长不会赋予陌生人私信、@ 或工具权限。
- **记忆不倒退**：关系敏感衰减适用于新产生的公开经历；原有记录保留先前策略，已遗忘细节不能恢复。
- **运行环境**：遵循 `package.json` 的 DSH/Node 版本约束；使用内置 SQLite 关系索引时，Node.js 需要 22.16 或兼容的更新版本。实际 DSH Desktop、B站与 DSH Mobile 环境仍建议安装后验收。
- **模型验证**：自动继承可以减少配置，但不跳过实际连接验证，也不自动授权对外操作。
