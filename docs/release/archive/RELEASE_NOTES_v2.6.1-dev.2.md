# 大肥鱼 · DSH 生活系统 `2.6.1-dev.2`

这是 **2.6.1 开发测试版**，不是 2.6.0 稳定版的替代发布。

## P4 · 自然成长关系影响意愿及自主待办

- `DualContextAgency` 现从 `SocialRelationshipIndex` 获取已核实的自然关系阶段与熟悉度；自然交到的朋友在意愿评分中可获得适度关注优势，**但不会得到白名单或写操作权限**。若关系索引不可用，维持原好友关系兼容回退。
- 对真实 UID、消息 ID 的 B站评论和私信视频邀请复用原意愿账本；**只有决定允许的邀请才能成为正式只读待办**。拒绝、犹豫和单纯分享 BV 仍可作为有时间限制的选片素材，但不会自动列为承诺。
- 同一消息重复轮询不多次决策；换一条真实新消息才可以重新考虑。对方多次推荐相同 BV，只在一个任务里合并来源。未接受的视频线索在候选区最多留 48 小时，已接受任务不会因为线索过期而消失。
- 主人评论“有空看看”、AI 提出的主人私信未来待办也复用当轮已有意愿判断；已拒绝或单纯推迟不再强制写入任务。
- 自主计划器从已接受的只读任务中结合时间和**实时关系熟悉度**安排考虑顺序；仍由模型决定执行、推迟、放弃或跳过，**不会增加外部写入或主动回访权限**。

## 自主收藏 · 记录有界动机

- `bili_video_collect` 新增可选 `motivation` 分类：`interest / rewatch / curiosity / memory / social / other`。在当次原有模型动作调用中附带自述动机，不增加一次生成；Python MCP 校验枚举，并与原有原因一起写入操作账本和回执。
- 动机属于模型当时的**自述选择记录**，不是已验证的记忆事实、真实感情或成功收藏证明。真正执行依然由工具配额、权限与 B站回执决定；没有把原因字段当成权限。

## 继承 dev.1 的安全边界

收藏夹可见性与自主删除仍使用 dev.1 的独立授权；删除仅限本插件真实创建并核实归属的主题夹。主 Session 正常工作权限不受社交意愿影响，普通自然朋友也不会由此获得陌生人私信外发权限。

## 仍未在 dev.2 开放

P4 中任意外部任务类型的统一接受、跨渠道大规模候选 SQLite、全套分页与任务遗忘管理界面，以及 P6 的自主主动回访，都留待后续版本。旧任务保留兼容，不自动重判或删除；需要在真实 B站测试账号完成社交接收和收藏动机的端到端验证。
