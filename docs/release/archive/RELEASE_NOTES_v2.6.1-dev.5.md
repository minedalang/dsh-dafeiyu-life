# 大肥鱼 2.6.1-dev.5 · P5-B 执行前意愿与公平调度

此版本从 **2.6.1-dev.4** 升级；不修改本地数据结构，不自动开启新的对外通信权限。

- **执行前意愿复核**：只读自主待办经过模型挑选后、执行前，重新读取当前模拟情绪及自然好友熟悉度。当鱼鱼极度疲乏且缺乏探索意愿时可选择暂缓，保留原始承诺与可衰减状态，不自动放弃任务；禁用情绪系统时不施加情绪门槛。
- **关系公平调度**：老任务得到有限等待补偿；候选窗口优先覆盖不同真实发起人，再按原优先级补足，避免某一位好友长期占满候选位。
- **真实生活状态**：自主计划模型获知有界的能量、好奇心、社交意愿及情绪基调；原社交私信、身份、原话和隐私事实均不注入此规划上下文。
- **只读边界不变**：自动计划器仍仅能执行已接受的只读待办，主 Session 的即时主人工作命令不经过这里的情绪复核；陌生人不能借关系成长获得发送权限。
- **完整任务重新校验**：模型选择之后重新检查任务类型、状态与计划时间。对外结果不确定仍不自动重试。

P6 的自然连发、沉默续聊、自主回访尚未开放。本版并未创建“私信全文 AI 压缩记忆”：主 Session 长期事实、私信短期上下文和可衰减人生反思继续按照原有隐私边界运作。
