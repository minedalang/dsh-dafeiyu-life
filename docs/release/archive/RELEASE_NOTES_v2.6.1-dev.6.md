# 大肥鱼 2.6.1-dev.6 · 主体性与人格成长修复

从 **2.6.1-dev.5** 最终交付源码升级。不会自动打开新社交权限，不迁移或清除本地数据。

## 1. 鱼鱼想做的事：提醒而非命令

管理中心取消每条任务的「现在执行」，对应旧的管理 HTTP `action=run` 已拒绝。新增全局「提醒鱼鱼考虑待办」：使用 `AutonomousPlanner.tick({force:true,todosOnly:true})` 启动**一轮**已有只读候选选择。允许跳过、延期、放弃或按当前意愿执行；不能选择指定 ID 强制执行，禁止自主点赞、收藏、关注、评论、私信等写入。保持 `masterEnabled`、每日模型额度、候选范围、任务即时状态复核、意愿复核与平台回执。允许自动调度关闭但主人明确手动提醒，不绕过每日模型预算。独立调度状态新增 `nextDecisionAt`，尊重本地活跃时段和调用间隔，页面明确是预计下一次检查而非行动保证。

## 2. 自主关注机会与现状诊断

关注开关仍**默认关闭**。启用后，鱼鱼在实际选中视频后独立思考是否真想继续看该 UP 的未来作品，只有在形成具体理由时才考虑现有 `bili_follow_creator`；真实 BV、当日入选、未关注过、每日额度、当前 UID 和平台校验不变。B站聊天／朋友推荐仅是视频探索素材，不因收到“关注我”就关注。设置页新显示当前开关与本地当天真实入选数；两者只是必要条件，不能推断最终肯定关注或 B站 API 操作已成功。

## 3. 反思与人格成长拆分：长期认识 ≠ 轻量行为证据

长期记忆 `memories` 仍要求真正认知转变，普通 18 条经历形成 0 条认识也可能合理；`trait_proposals` 在模型提示词中独立判断，可以在 `memories:[]` 下提出严格可核验的候选。另增加无需额外模型调用的客观弱观察：仅当前仍清晰存在的真实自选视频（每自然日最多一次）与已确认发送回复的陌生人互动（每人每天最多一次）可以提供极低权重人格证据。未回复、模糊/遗忘、主人/私密互动及未真正选中视频都不在此路径中。既有的人格阶段要求仍保留多日、独立行为及不同陌生人的约束，不能把单次行为称为稳定变化。

修复 ISO 日期字符串在人格证据日归一化时可能触发 `Invalid time value` 的问题。反思面板新增「人格模型候选、采纳」和「真实弱行为观察」分项，方便定位是没有提议还是安全校验拒绝。

## 暂未包含

P6-A 自然多气泡连发、沉默续聊、自主回访及陌生人主动私信均未开启。真实 B站账号关注和 DSH Desktop 管理页仍需本机端到端验收。测试环境不等于线上成功。


## 增量修正：兴趣视频私信推荐（不改变 dev.6 版本号）

- 修复白名单好友虽选中「私信优先」，后台主动视频推荐却被旧 `paused:true` 全部阻断的问题。只恢复新入选公开视频与好友画像兴趣匹配后的**私信推荐草稿**。
- 旧版配置保存过启用状态也不能自动恢复：需在管理中心重新明确授权；自动发送仍单独关闭，首次建议先查看草稿。
- 仅新入选视频触发；按 UID 隔离画像，遵守好友的拒收意愿、冷却和额度，模型可以选择不联系。
- 待办完成回访、情绪主动联系及跨渠道公开 @ 均未恢复，账号更换与回访诊断列入 P6。
