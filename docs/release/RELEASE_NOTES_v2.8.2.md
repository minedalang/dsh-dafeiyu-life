# 大肥鱼 2.8.2 · 视频感知体验优化

本次重点**优化视频感知流程**：鱼鱼可以先了解视频大概，再自主决定是否细看有兴趣的部分；同时改善观看记录、语音转写、模型管理与运行诊断。

- 🎬 **先看全貌，再看细节**：先浏览全局分镜，再自主决定是否观察一个或多个片段。
- 🔎 **看过什么，有迹可循**：记录实际采样的画面来源、时间点和验收状态；模型描述不等于人工确认事实。
- 🐟 **看几段，由鱼鱼自己决定**：可以继续、跳过、延期或停下，不为了凑数强迫观看。视频局部观察按只读探索权衡兴趣与资源。
- 🎧 **没字幕，也能尝试听懂**：可选本地 Whisper 转写，兼容设备优先尝试 CUDA，不兼容时回退 CPU。
- ⚙️ **模型与诊断更方便**：本地 Ollama 未运行时明确提示；识图失败和证据校验失败分开说明；模型下载/删除等维护操作折叠展示。主人私信不再展示重复的旧 Agent 独立模型入口，仍由 Life 自主意愿和社交互动模型协作处理。
- 🔒 **账号与授权边界不变**：不会因阅读视频而获得评论、点赞、私信、关注等公开操作权限，也不会把失败或模型猜测写成真实 Life 经历。

视频视觉、Whisper、FFmpeg 和本地模型依赖均按需配置。低清分镜不是完整视频播放；视频转写是机器估计，具体设备支持与模型实际效果以运行检查为准。
