# 大肥鱼 2.8.2 · 视频感知体验优化

**正式版更新说明** · 本次重点**优化视频感知流程**，同时完善自然探索与运行可靠性。发布源代码和发布渠道是两件事：GitHub Release、npm 和 DSHMarket 是否已经上线，以实际发布记录为准。

## 本版新特性

- 🎬 **优化鱼鱼看视频的行为**：选片仍只需一次判断，同时参考标题、UP、播放/点赞等热度、时长和简介；**在选中前不提前获取字幕、ASR、画面描述或评论正文**。选中后自由选择看视频、看评论、互动、换视频或休息。
- 🎞️ **看视频是一个自然动作**：视频 Agent 调用统一观看工具时同时尝试画面与字幕，必要时使用已启用的 Whisper ASR；两类证据独立核验。字幕缺失或视觉失败都不伪称完整观看，也不强迫观看。
- 🔎 **先看全局，再按兴趣细看**：支持 B站低清分镜采样、有界原视频局部取帧，记录可信的采样来源、窗口和时间码；模型识别并不等于人工核验所有语义。
- 🧠 **AI 生成的视觉记忆摘要**：全局观察随原识图得到初步摘要；新局部证据成功后，可由既有视频 Agent 文字模型无工具整合全局与局部笔记。沿用原有可衰减 Life 记忆，不创建绕过遗忘的新仓库。
- 🐟 **自由行动与真实生活时间线**：Life 可以继续、跳过、休息或选择其他行为；核验视频资料后的续行状态区分继续探索、自主结束、被系统阻断和 Episode 完成。只有真实视频来源和观看回执才会显示为有效观看。
- 🎧 **更易用的语音与本地模型**：可选 Whisper，兼容时尝试 CUDA、必要时 CPU 回退；支持本地 Ollama 视觉检查和明确的失败诊断，改进新老用户快速设置。
- 🛠️ **可靠性与隐私修复**：防止已关闭 SQLite 关系索引引发重复异常，强化异常退避、跨账号证据隔离、生活记录来源与工具回执诊断。

## 升级须知

已有用户的登录、Life 记忆、个人设置和公开互动授权不会因为进入快速设置页面而自动重置或扩权。视频感知、Whisper、FFmpeg 与 Ollama 均为按需配置；阅读视频不会自动获得评论、点赞、关注或私信权限。升级前建议备份并完成插件与 DSH 重启。

**不包含在 2.8.2 的计划：** 2.8.3 的“任何时候因证据不足有理由补看”和视频浅／深双层记忆，及 2.9.0 的角色认知和关系成长仍为后续开发方向。
