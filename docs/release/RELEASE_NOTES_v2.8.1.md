# 大肥鱼 2.8.1 · 正式版更新说明

> **坚持鱼的自由发展。** 2.8.1 以真实视频感知、连续生活、模型可用性和安全稳定为主线。这份文档按正式版发布格式编写；实际发布需要维护者完成下列发布门禁并核实 GitHub / npm / DSHMarket 上线状态。

## 本版重点

- **更真实的视频理解**：区分字幕、语音转写、OCR、视频画面和公开评论，各自保留来源与实际采样范围。真实解码不可用时，可使用有明确标注的官方低清分镜作为受限证据，不能声称完整观看。
- **可选的 DSH / Ollama 图片视觉**：统一模型设置页，提供 Python 环境自动检查、必要时自助修复、固定原图识别与人工认可。模型配置可随时展开；仅自主视频观察有内页独立开关，评论和私信图片／表情包识别另受互动权限控制；原来关闭的用户不会因升级自动产生额外模型调用。
- **2.8.1 首次设置复查**：升级用户需要至少看一次新版设置，管理中心在本版首次进入时展示图文新功能导览，随后可跳转绿色「02B · 视频视觉感知」。保留历史账号、记忆、权限和后台 Life 的已有可用状态。
- **Life 的连续自主探索**：真实读取和观看分别记录，探索、续行和社交行为依旧由 Life 自主决定；不因为增加视觉模型而强制发表评论。
- **统一宿主资源协调**：新增同一 Node 进程内的模型、读取、视频、视觉资源槽及任务优先级协调；跨进程仍由原有持久化准入、资源预算和回执保护约束。
- **更易查找的管理界面**：原生 DSH 插件设置标题下分绿色 2.8.1 新版亮点与长期核心能力两张说明卡，管理中心初次进入展示功能卡片；设置跳转后目标短暂高亮；神经回忆场支持右键平移、缩放、五类多选筛选，避免重复图例。

## 主要新功能

### 🎬 视频理解与证据链

Life 自主进入视频时，可在实际授权和资源预算内选择采样画面，并结合字幕、评论、可选 ASR 与 OCR 获得更多上下文。低清官方分镜、真实 FFmpeg 解码、文字理解和完整视频观看不能混为一谈；原图片与模型全量回复不作为无限期私人记忆保存。

### 🧠 模型管理、Headless 同步与视觉验收

官方已注册模型与自定义 Provider 采用不同流程：自定义配置先预览差异、确认同步，再实际验证文字连接。视觉模型必须另行完成固定图片识别和人工认可。环境修复仅在用户明确点击时安装，普通用户不要求 Conda、管理员权限或修改系统 TEMP。

### 💬 统一 Life 决策与稳定性

获授权私信都进入统一 Life 决策入口；只有当前账号有真实证据并通过明确的行为授权，才可发起平台写操作。持久化私信接收与技术续办、-509 限流退避、共享读取预算、未知外发冻结继续生效；无法证明送达时不自动重发。

### 🌳 关系记忆与可视化

三维记忆神经场支持左键旋转、右键平移、滚轮缩放和五类筛选；后天兴趣、人物互动、事实认识与情绪线索都受已有证据与可见权限约束。

### 🧭 首页漫游与兴趣探索、私信可靠续办

新版将首页漫游和兴趣驱动搜索清晰区分；已发生的公开搜索如果能与同一 Life 好奇线索精确关联，行动日记会显示具体兴趣或临时好奇的话题。不具备证据时继续使用通用说明。

收到私信后如遇短暂 Life 准入繁忙，会进行最多 6 秒的受控只读等待；仍然繁忙时保留技术延期，稍后安全复查。不改变 B站 `-509` 持久冷却，也不会自动补发结果未知的私信。持续高负载下的公平性和真实回执仍需发布前实机验证。

## 📦 从 2.8.0 升级

升级后重启 DSH，进入管理中心的新版快速设置并确认一次；已有登录凭据、模型、Life 配置、账号账本和长期记忆不自动重置。02B 视频视觉为可选步骤；只有环境异常才需点击「自动修复视觉运行环境」，视觉模型仍须真实图片验收后主动启用。

有关详细步骤见 [升级指南](2.8.1-user-upgrade-guide.md)。

## 🔒 兼容与安全边界

平台写入遵循原有权限、额度、反重复及回执门禁。限流时不能通过提高轮询频率解除 B站 `-509`。资源协调是当前宿主进程内的受控队列，不宣称跨多个独立进程精确一次执行。

**正式发布前必须通过的门禁：** 目前管理页手动固定图片 DSH 识图已有 Windows 实机成功结果，但生产 Life 独立视频 DSH 路径尚未完成同一 Node 宿主迁移和真实视频验收。此外，需完成依赖完整的 Node/Python 回归、旧用户升级及无 Conda 环境检查、私信限流恢复验证。未关闭前应保留候选版本标识，不应声称已稳定正式发布。参见 [2.8.1 发布检查单](2.8.1-release-checklist.md)。
