# 2.8.2-dev.42 · 版本文案及重复弹窗清理

当前仍是开发候选，非正式发布。

## 本轮变更

- DSH 原生设置页保留唯一「2.8.2 版本亮点」，明确本次是**视频感知体验优化**，包括观看方式、可核对的观看记录、自主选择、语音转写与模型管理。
- README 及用户升级指南从「优化了什么」切入。管理中心 02B 视觉设置、视频感知档位改成简短可操作的说明；帧数和工具诊断细节仍可从设置卡片、运行诊断和升级指南了解。
- 完整移除管理中心重复的 2.8.2 宣传弹窗（HTML、CSS、启动回调和 sessionStorage 状态）。**没有移除**首次设置引导，也没有自动确认 `quickSetupSeen` 或启用视频视觉。
- 没有修改 Life 自主视频决策、证据验证、社交授权、私信30分钟兜底或 B站外发；架构接线未变。

## 维护者验收

1. 升级 dev.42 并重启 DSH；在原生大肥鱼设置页确认「2.8.2 版本亮点 · 视频感知体验优化」只显示一次。
2. 进入管理中心，确认不会再弹「2.8.2 新版本导览」宣传窗。
3. 未完成快速设置的账号依然进入快速设置检查；已完成的旧账号不应被要求重置账号/模型/授权。
4. 确认快速设置 02B 与视频感知档位说明精简，主动点击设置仍要求明确测试、认可和保存；不自动开启视频识别。
5. Windows 全量测试、真实 DSH 首次安装及权限回归仍需维护者执行；本轮仅完成相关离线 Node 回归和代码检查。
