## 处理方式

- 保留原有权限、账号隔离、只读预算、真实外发回执、视觉图片证明、Headless 授权及跨语言事务的安全保障。
- 测试仍检查旧函数名、旧预加载顺序或旧文案时，替换为针对当前架构和真实接口的行为/合同检查。
- 直接识别的生产缺陷：Life 时间线将内部“读取回执”术语显示给用户；一次性 MCP 调用在 Windows 上需等待子进程 stdio 关闭后再删除临时文件。
- Python Windows 测试夹具：虚拟环境路径采用 `.venv-asr/Scripts/python.exe`，受限视觉 fake DSH 用 `sys.executable` 作为跨平台绝对路径。
