## 日志证据边界与剩余风险

- 新近 `duty.log` 包含 95 次 `getaddrinfo failed` 字面命中、126 次 `ENOTFOUND`、160 次 `timeout`（不区分大小写）；这些是**字符串出现次数**，不是经过归并的独立请求数。
- 历史轮转 `duty.log.1` 还包含大量 DNS / 超时记录以及 `-509` 限流记录，说明故障并非单次 Life 意愿选择。新版本退避能减少无意义的定时重试，**不能修复本机 DNS、代理、网络链路、B站上游或模型服务**。
- 历史轮转日志有 `statement has been finalized` SQLite 警告。本批没有在缺少可复现数据库生命周期现场的情况下贸然更改该存储层；后续需用维护者本地脱敏复现、独立关闭/并发测试处理。
- 日志中模型称“已发布”的文本不能代替平台证明；需以只读平台复核和现有真实发送回执为准。未知外发仍冻结，禁止自动重发。
- 原有独立视觉脚本安全拒绝不可凭日志推断为功能故障，不为排除此拒绝放宽授权、调用身份或预算。

## 兼容与发布风险

- 缺失可信账号来源的旧 `public-event` 经历现在不能进入公开素材。这是有意的 fail-closed 兼容行为；不删除用户历史记忆，主人主 Session 仍可在原访问策略下使用符合旧规则的历史经历。
- 桌宠开放平台仅保留 `dev.9` 静态预告页和现有 SVG，归档原方案至 `docs/open-platform/DAFEIYU_LIFE_OPEN_PLATFORM_PLAN.md` 并链接 `docs/ROADMAP.md`。没有新增监听端口、真实 API、设备凭据、SDK、授权或外发权限；真实开放能力在 2.9.0 之后另行评审。
