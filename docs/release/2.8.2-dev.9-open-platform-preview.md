# 2.8.2-dev.9 · 桌宠开放生态预告页（开发候选）

**状态：开发中。仅为静态生态预告，尚未开放任何第三方接入 API。**

## 实际改动

- 在管理中心「角色与系统」增加「🧩 桌宠开放平台（开发中）」标签页，复用现有导航、主题和路由选择机制。
- 展示官方桌宠「鱼鱼在场」的未来规划、社区桌宠自由接入愿景、引擎无关的运行时协议草案，以及 2.9.0 之后逐步开放的路线图。
- README 新增面向普通用户和潜在社区创作者的介绍，新增三张 SVG：生态总览、未来 3D 世界、路线图。已有特色、首次使用指南、未来规划紧邻致谢及上游致谢均保留。
- 新增 `docs/open-platform/README.md`，明确预览 API 为未实现提案，不表示可调用或已经开放授权。
- 开发版本从 `2.8.2-dev.8` 递增至 `2.8.2-dev.9`，同步包元数据和 README 版本提示。
- 针对上传基线中已失败的 `v281-readme-user-facing-contract.test.mjs` 固定 2.8.1 版本断言，改为检查 `package.json` 当前版本与明确的未发布提示；保留用户首页长期特色与未来规划位置的原有断言，并在治理目录登记旧断言替换。

## 统一层归属检查

| 项 | 本次定义 |
|---|---|
| 行为主体 | 管理中心只读预告内容；不会产生 Life 或桌宠运行决策 |
| 唯一事实来源 | Life 原有人格、记忆、情绪、活动与会话模块；本次没有新增事实来源 |
| 账号与隐私作用域 | 不读取或外发真实账号、私信、记忆、凭据；仅静态公开文本与 SVG |
| 权限来源 | 不新增接口、设备配对、访问令牌、写入授权或远程监听 |
| 生命周期 | 随管理中心页面加载；切换标签后只呈现静态内容 |
| 失败与恢复 | 页面静态显示、不调用模型或平台，不影响已有 Life 运行；删除该新增页与静态资源即可回滚 |
| 复用 | 复用现有 management-console 标签切换与 CSS 变量；未增加第二套控制或状态 |

**架构接线未变。** 无新增运行时路由、存储、调度器、模型输入或授权职责，因此不修改四张 Life Mermaid 架构源图。

## 展示而非上线的未来方向

- 统一 Life 状态快照、实时 SSE、互动回传和统一聊天入口；
- 可接入 PySide6、Godot、Unity、Unreal、Live2D、Spine、网页及其他终端；
- 未来 3D 场景观察、空间动作意图、可信结果反馈、多端共存。

这些能力目前没有在本次变更中实现。预计在 **2.9.0 之后**再评估真实开放范围，不承诺具体日期。

## 发布限制

- 需在维护者 Windows 普通权限和管理员环境分别完成全量回归，并在真实 DSH Desktop 检查导航、主题、移动布局和刷新链接。
- 本次不应被标记为正式 `2.8.2`，不得仅凭静态页面或定向测试宣称 API 已开放。
