# 2.8.2-dev.8 · Life 意愿与执行结果的只读解释

> 状态：PR-5 第一轮已接线，**非正式发布**。仅 Linux/Node 定向回归；Windows/DSH/B站真实外发及未知事务长期恢复尚待实机验收。

## 统一层归属与事实来源

| 维度 | 当前归属 | 本批不做的事 |
| --- | --- | --- |
| Life 意愿 | `AutonomousPlanner` 与 `LifeWillingness` 真实模型决策 | 不替 Life 选择或重新投票 |
| 执行和权限 | 原社交、视频、读取门禁及平台事务 | 不重试、解锁或新授权 |
| 诊断事实 | `life-decision-trace.mjs` 的当前账号、有限步骤 | 不从模型自由文本推断动机；不新增记忆/事实账本 |
| UI | 管理中心已有只读 `/life-agent/decision-traces` | 不增加任意文件/URL 读取，不调用模型或 B站 |
| 生命周期 | 原 7 天、60 轮、96 步、账号隔离、脱敏和原子写入 | 不保留永久解释，不跨账号关联 |

## 实际接线

- `lifeTraceExplanation(row, at)` 仅对已有脱敏步骤派生有限枚举：`phase/category/actor/proof`、有无选择与执行回执、评论选项提供情况、Life 主动填写的安全休息类别。
- `createLifeDecisionTrace.list()` 和 `get()` 返回派生解释；**不修改原有 JSON 格式或持久化内容**。历史仍在 7 天内的旧记录也可解释，缺失证据显示未知。
- 管理中心在每轮原始匿名步骤之前展示一句人类可读的状态；生活行动树复用同一投影，避免把无效 `skip` 当自主休息、把执行计划当平台成功。

## 解释等级与典型情况

| 归类 | 必要依据 | 不得声称 |
| --- | --- | --- |
| 自主休息／延期 | 有效模型选择 + 同轮未发送回执 | 读取了对方内容或平台已执行 |
| 无可执行机会 | 明确的 `no-actionable-options` 结果 | Life 不感兴趣 |
| 模型无效／故障 | 解析校验失败、模型错误或退避 | Life 主动沉默 |
| 授权／预算／网络／平台限制 | 现有门禁的枚举拒绝 | Life 自主拒绝或确定恢复时刻 |
| 委派／主会话排队 | `delegated` 或 `host-queued-not-delivered` | 平台发送成功、主人已看到 |
| 动作已核验 | `execution-result: verified` | 若没有 `platform-confirmed`，不能称平台已送达 |
| 平台核验成功 | 同轮 `result=verified` **且** `delivery=platform-confirmed` | 模型的选择本身是发送回执 |
| 回执未知／批准超时 | `uncertain`、`outcome-unknown` 或未结算批准 | 可以安全自动重发 |
| 仅本地结果／证据缺失 | 只有本地分类、候选或模型选择 | 已发生平台动作 |

同一轮出现多个动作时，以最新的选择和对应结果为解释对象；若最后行动结果与执行回执不一致，保守归为结果未知。没有模型原始思维链，也不能由日志倒推出内在因果。`commentNotOfferedCode` 是独立的“本轮有没有提供评论机会”维度，不得代替最终 Life 选择。

## 安全与测试

- 诊断不会保存提示词、私信正文、BV、UID、平台凭据或任意自由理由；新增字段只含有限枚举。Life 可选的 `restReasonCode` 只当作**模型本轮提供的类别**，不是独立心理证据。
- 账号切换仍由原 `getAccountTag` 作用域阻断，诊断窗口和文件安全检查保持不变。此投影不改变事件账本、记忆、平台发送状态、幂等与未知冻结。
- 定向测试 `test/v282-dev8-life-decision-explanation.test.mjs` 覆盖真实 Planner/Willingness、无模型二次调用、平台回执双条件、跨账号隔离、匿名性、多个动作结果冲突和 UI 安全提示。
- 待验：Windows 普通/管理员 full；DSH 实际长时批准待回执、切号、授权撤销、B站失败/未知事务核对。未来通用浅深记忆仍仅为规划。
