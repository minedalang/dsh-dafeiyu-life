# 2.8.1-dev.3b.13 · 视觉运行与 ASR 诊断、记忆统计、验收入口

## 运行状态

`vendor/bilibili-mcp/mcp_server.py` 仅在非主人 Debug 的生产路径实际返回 `analyzed`、本地识图失败或者独立 DSH 视觉进程失败状态时，原子更新 DSH 数据目录中的 `vision-production-last.json`。记录固定版本、毫秒 UTC 时间、成功标志、固定模式和限长模型名／固定状态代码。禁存 BV、提示、图片、回答、身份、错误正文。缓存命中不制造新调用状态。`lib/vision-production-status.mjs` 只读且不执行网络请求；管理端 `systemHealthSnapshot` 六小时后把旧成功显示为「待观察」。

## 语音识别诊断

Whisper small 安装测试并不意味着真实音轨可取；原实现 Python 非零退出均映射为「本地语音转写未成功」。现在从本地子进程的固定阶段标记、有限的错误类型特征中**仅提取安全类别**；不记录原始 stderr 或字幕文本。分类如 `audio-access-denied`、`audio-download-failed`、`model-load-failed`、`inference-failed`。没有有效转写文字时不制造语音证据。视频是否具有语音、音轨是否可获取、模型是否能处理需要分别验证。

## 记忆统计与 UI

`lifeMemory.status()` 在仅经真实可衰减副本的读写路径计算三项数据：`total`、`todayAdded`、`todayForgotten`。`forgottenAt` 仅在由非 `forgotten` 真实转换时填写，旧数据不虚构遗忘发生日。展示计数不同于神经回忆场图形投影和永久档案，不读取任何私密详情。Ollama 未认可且本地模型已安装时以同一行紧邻的红字 + 红色跳转按钮提供统一验收入口；模型内容／版本摘要与原验收规则不变。

## 验收边界

离线测试只模拟可信的工具回执和状态，不证明用户 Windows B站视频已经完成实际音轨下载或模型调用。若用户提供了明确的 `asr_failed.reasonCode`，再针对真实网络/代理/媒体问题开展修复，不绕过既有账号安全与隐私保护。
