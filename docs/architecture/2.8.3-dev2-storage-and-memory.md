# 2.8.3-dev.2 · 存储位置管理与浅／深记忆内核（开发候选）

> 本文说明已实现的内核边界。真实视频详细视觉证据自动入库、自然聊天展开和自主补看**尚未启用**，计划后续 dev.3～dev.5 分批实现。2.8.2 仍是正式稳定版本。

## 1. 统一层归属

- **行为主体**：Life 在现有 Life 调度中决定是否观察/回忆。本批不新增模型行为或看视频意愿门禁。
- **记忆事实源**：`lib/life-memory-gateway.mjs` 的现有 `life-memory/episodic.json`；深层附件仅附属于当前清晰的主记忆，不替代记忆 ID 或单调衰减。审计档案仍是运行时不可检索的永久记录。
- **附件存储**：`lib/life-memory-details.mjs` 的 `life-memory/details/v1/<accountTag>/<memoryId>.json`，带父记忆指纹、公开来源、时间锚点、实际来源引用、模型不确定性。默认生产写入不开放，只有可信内部适配器将来可显式接入。
- **安全撤销**：主记忆进入 fuzzy/trace/forgotten 时立即失去读权，附件被清理；`detail-protection/revocations-v1.json` 存独立的撤销记录，专项备份恢复时只合并不清零。主记忆被逐出和备份恢复后对孤儿附件做受控清扫。
- **存储根目录**：`lib/state.mjs` 继续以宿主 `dshHomePath('bili-duty')` 为默认根；只有停机工具校验完源数据并写入 `.dsh/.bili-duty-location-v1.json` 后才切到新根。指针或身份凭据异常时拒绝从空目录重新启动。
- **权限来源**：当前账号、public-event、已核验视觉来源；深层详细数据无单独对外权限，不接入常规上下文或 B站公开写入。

## 2. 数据路径与管理 UI

管理中心「数据备份」页新增「存储位置」卡片，显示当前目录、AI 运行环境／记忆／临时缓存分类占用，允许输入新的空本机路径进行**只读安全预检**，并生成准确的离线迁移命令供复制。HTTP 无搬迁端点，不自动删除旧数据。迁移必须完全停止 DSH Desktop、Headless、Python 子进程，然后在 PowerShell 执行 `node '<插件安装目录>\scripts\migrate-bili-duty-storage.mjs' --from '<当前bili-duty目录>' --to '<目标空目录>' --confirm-stopped`；命令仅在主动确认进程全部退出时使用。

停机工具拒绝 UNC/设备路径、磁盘根、同源和嵌套路径、已存在的非空目标目录，以及符号链接和特殊文件；跨卷在新盘临时目录内复制，逐文件 SHA-256 比对后写身份标记并原子切换启动指针。**原目录保留**，不会自动清理。重启须实机验证账号、角色 ID、记忆数量、观看历史、凭证使用和模型依赖。某些 Python 虚拟环境/ASR/Embedding 的内部绝对路径可能需要重建；本批不自动重装，也不支持在运行中移动缓存。

管理端 GET `/storage/location`、POST `/storage/check` 仅允许电脑本机同源访问；后者只读检查，不写入用户数据。用户无须新增独立菜单。

## 3. 深层详情契约

- 原始 `episodic.json` 仍为版本 1，不迁移旧主记忆数据。
- 单片段 UTF-8 最多 32 KiB，每条主记忆最多 64 片、总计 256 KiB；只接受 `observed-scene` / `focused-observation` 等有界来源类型。读取仅返回最多 16 KiB，默认 8 KiB；深层不自动加入 Embedding。
- 片段的来源引用是**证据索引，不是新读写授权**。视觉模型的描述即使来自成功采样，仍是“model-observation”，不能当作独立事实证明。
- 深层详情以已保存的、当前账号下的清晰 `watch/public-event` 记忆为父。真实写入所需的 `admitMemoryDetails` 可信适配器目前默认返回 false，防止单靠 `verified:true` 伪造入库；后续 dev.3 复用 v14 视觉回执时才接线。
- `expandMemoryDetail()` 必须再次经 Gateway 检查当前账号与主记忆阶段；记忆不存在、已衰减、没有合法视觉回执或不匹配，均拒绝。单纯读取详情不延长记忆寿命。
- 该方案只针对公开视频做首个有界落地；其他更敏感类型要经独立评审后才启用。

## 4. 备份与恢复

- 便携业务备份与明确确认的专项人生记忆备份支持有效的清晰公开视频详情文件和遗忘撤销记录（结构校验、文件白名单与 SHA-256）。不允许携带不匹配、已模糊或未知归属的附件。
- 旧格式备份保持兼容；恢复合并当前遗忘阶段与撤销标记，恢复后校验并清理已不属于清晰主记忆的附件。
- 原设备正常恢复旧备份可拒绝已撤销内容。**完整磁盘镜像回滚或删除所有保护记录并非软件能单独保障的删除边界。**
- 管理中心的便携备份并不是完整 DSH 快照；进行整目录跨盘迁移时必须使用冷迁移工具并保留旧目录。
