# dev.44 · 主人联系权限、自然续聊、断网恢复及原生总开关

## 事实源与模块职责

| 功能 | 唯一事实源/执行器 | 本轮变更 | 边界 |
|---|---|---|---|
| 主人交流权限与额度 | `lib/owner-contact-policy.mjs`，`main-session-memory.json` 主 Session Bridge | 卡片预设和自定义活动小时/冷却/每日上限/沉默时间；主 Session 和主人 B站 DM 共用额度 | 权限不是模型必须发言的命令，发送回执分别核验 |
| 主 Session 沉默续聊 | `lib/main-session-bridge.mjs` + 原 Life `AutonomousPlanner` | 只观察已绑定在线 Session 的用户入站与 assistant 事件；有确认的最后发言，达到阈值后添加 `owner-silence` 候选；模型仍可选择 `skip` | 不抓磁盘会话，不启用单独陪伴 Agent；只有宿主 followup 排队回执 |
| 主人 B站私信沉默续聊 | `lib/owner-dm-agent.mjs` | 以原主人已核验入站和已确认的回复为触发；先查真实新来信、模型自己选 skip/reply；逐气泡再次查权限和新来信 | 复用 `message-burst.mjs`；同一来信只考虑一次；B站结果未知不重试 |
| Life 调度 | `lib/autonomous-planner.mjs` | `schedulerPulse` 独立统计每次廉价 tick、最近跳过和最近模型轮；管理中心显示 | 记录 heartbeat 不代表模型实际完成决策；provider timeout/backoff 仍生效 |
| B站只读轮询 | `lib/interaction-scheduler.mjs` + `lib/network-poll-backoff.mjs` | DM/评论独立车道记录 -509、DNS、超时/重置阶梯退避，当前账号持久保存，重启恢复 | 轮询次数减少不等于网络自动修复、发送完成或平台授权成功；写入权限不变化 |
| 总开关 | 插件 `config.json`，`index.js` 与 `client.js` | 原生宿主设置没有可写表单时，插件本地配置读回通过即报告成功 | 不再把不支持的可选宿主镜像当成插件保存失败 |

## 主人配置卡片

- **安静陪伴**：10:00–20:00，冷却 12 小时，每日 1 次，主人沉默 120 分钟后才有资格考虑续聊。
- **自然相处**（默认）：09:00–22:00，冷却 8 小时，每日 2 次，沉默 45 分钟。
- **积极交流**：08:00–23:00，冷却 3 小时，每日 4 次，沉默 20 分钟。
- **自定义**：开始 0–23、结束 0–24（允许跨午夜）、冷却 30–10080 分钟、每日 1–24 次、沉默 5–1440 分钟。开始和结束不能相同。

在管理中心主 Session 选择页配置，主动交流总授权和两个渠道的沉默续聊授权独立开关，默认关闭。改变预设不改变 Life Voice 和人格；长时间沉默也不强制必须续聊。

## 断网诊断

用户 2026-11-09 `duty.log` 显示 -509、DNS ENOTFOUND、provider-unavailable、timeout，且断网前后 Life 的「最近正式决策」时间可能停滞。原 `tick()` 会主动丢弃常规的 `cooldown` / `model-backoff` / `quota` 调试记录；新增 `schedulerPulse` 避免将它们误认为定时器不再运行。若心跳 >150 秒而后台配置仍应运行，应检查 DSH 插件进程生命周期；`provider-unavailable` 归模型服务，而非 B站频率门禁。对于 -509 与 DNS，持久退避在原账号下生效；只有 API 真正成功后才能重置。
