# 2.8.3-dev.24 统一能力架构 · 方案 C

状态：维护者已同意产品方向；本文件是实施规格，不是已实现声明。基线为 dev.24 mode-workspace 增量后的源码。保持 dev.24，不提前进入 dev.25；公开 npm dev.14 冻结、main 公告不变。

## 1. 产品决定

- 大肥鱼本身是统一记忆与认知基座；取消自主生活/记忆基座互斥的全局产品模式。只有一套管理中心、同一 Life 身份及既有记忆事实源。
- 默认推荐自主生活与 B站平台接入开启：当前自主生活仅以 B站为活动平台。新用户须完成实际登录、模型验证和必要确认才进入有效运行状态。未准备好时不执行平台任务，不影响本地记忆。接入平台不等于授权任何外发，不自动安装可选依赖或调用收费模型。
- 原用户既有明确开关、账号、授权、模型、绑定、人格与记忆保持；默认值不能覆盖显式关闭。当前 `lifeAgentMode` 默认 `off`，产品默认开启必须通过首次设置的显式配置与就绪检查落地，不能直接把所有未登录用户的实际调度改为 active。
- 主 Session 绑定、人格/表达介入、自动记忆上下文分别配置；关闭介入不取消显式记忆工具。是否自动上下文、人格默认值及现有自动桥接的细粒度归属，以原配置兼容及下述验收为准，不默认接管既有 Session。
- 可提供“一键仅使用记忆”配置快捷操作，但它只批量设置独立能力，不产生新的持久模式枚举或专属页面体系；须预览实际改动并由主人确认。

## 2. 当前源码审计与目标职责

`index.js` 当前创建 `createHostSessionIntegration`，以 `memoryFoundation()` 决定本地记忆独立准入、模型和备份部分逻辑；`lib/session-integration-policy.mjs` 管理 `session-integration-v1.json`、代际、重启事务及 AsyncLocalStorage；`long-term-memory.mjs` 将人格、表达、自动上下文、待办提示与显式工具集中在挂载内；`main-session-bridge.mjs` 及自主调度器目前消费同一模式。`life-settings-control.mjs` 的旧 Life 开关只约束自主视频/计划部分，不能等价于全部独立社交与主 Session 自动介入。管理中心仍按模式投影导航。不能通过删掉这些模式判断完成重构。

| 职责 | 目标 |
| --- | --- |
| 基础记忆 | 既有本地记忆、权限、分类记录、显式检索、遗忘；不依赖 B站登录 |
| Session | 现有绑定与记忆开关；人格/消息表达、自动上下文、经历桥各自归属，未授权 Session 不挂载 |
| 自主生活 | 统一自主派发许可，复用旧 Life 设置及具体调度开关；暂停新自主工作不影响已发生事实结算 |
| B站 | 独立平台可用性与当前账号核验；平台工具依旧受原准入，外发需原对象、意愿、授权、额度及回执 |
| 基座维护 | 已核验回执、遗忘、必要索引、缓存与合法备份独立于自主生活；凝练/远程模型需原独立验证与权限 |
| UI | 同一导航及事实源，按能力就绪/启用条件组织；必需设置可达，停用的生活活动不展示为正在运行 |

## 3. 安全事务和迁移

保留并泛化可信配置代际，覆盖自主活动关闭、Session 重新绑定、人格/上下文切换和平台权限变化等真正影响任务的变更。实现前逐条映射现有 mode 消费者及 Node/Python/MCP 子进程协议；可在过渡期保留内部兼容适配，但最终不得存在两个互斥产品模式决定全部能力。旧异步结果不得借重新开启而复活。已开始平台操作按原真实回执结算，未知冻结；不伪造取消或盲目重试。跨进程无法证明安全热更新的配置继续明确要求退出重启，不能承诺全部即时生效。

正式旧版无模式文件时使用原显式配置和新用户初始化规则。若开发测试环境存在 `session-integration-v1.json`，须保守转换：原自主生活保留原设置；原记忆基座应保持自主派发、人格和自动介入的暂停效果，不因删除枚举自动恢复活动。待重启、损坏、未知版本或旧进程仍存活时安全拒绝，保留原文件以供回滚；不从业务备份隐式恢复授权。迁移须幂等，实际字段/版本在生产改动时确定并测试。

## 4. 统一管理中心

快速设置优先展示记忆核心状态、B站接入及自主生活开关、主 Session 绑定及独立介入配置。保留可复制 Session 使用指南，解释工具权限来自宿主而非提示词。原有记忆管理、历史记忆与联想、存储备份按实际本地权限开放，不以平台登录充当通用能力门禁。原生活行动树只显示实际 Life 行为；停止时可显示历史或真实暂停原因，不冒充任意 Session 工作轨迹。未来通用活动树仍需可信宿主事件流，不在本轮伪造。

遵守 AGENTS.md：先保存现有生产页面基线，修改真实 HTML/CSS/JS，所有受导航影响的页签进行浅色/深色、桌面/窄屏实际浏览器巡检，检查启用、停用、未登录、模型未验证、保存失败、待重启、旧链接和搜索；保持 Android 只读与原功能权限。交付真实截图与可复跑脚本，不用聊天示意代替。
