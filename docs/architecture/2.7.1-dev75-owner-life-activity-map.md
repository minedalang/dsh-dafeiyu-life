## 二、各类真实动作的职责与状态边界

| 页面/行动 | 代码入口及可信源 | 使用者可确信什么 | 禁止误读 |
|---|---|---|---|
| 生活线索 | `life-opportunities` 与生活线索/意愿候选读取 | 供 Life 考虑的提示、兴趣或方向 | 有线索 ≠ 已决定去做 |
| 生活契机 | 原 `life-opportunities` 候选及 `inspect_opportunity` | 经筛选的可选行动机会 | 契机出现 ≠ 已核验作品 |
| 已接纳待办 | 原 `owner-todos` 数据及 `execute_read` | 按原权限触发实际只读待办核验 | 待办存在 ≠ 已执行；工具返回 ≠ 实质观看 |
| 浏览首页 | `browse_home` → 原视频 Agent | 代理已启动或获得明确只读证据 | 启动 ≠ 看过/入选/评论 |
| 查看创作者 | `inspect_creator_space` | 特定已选视频作者主页的受控只读核实 | 不是任意用户主页漫游 |
| 了解公开交流对象 | `inspect_public_person` | 经 UID/长期公开互动核验后读取其公开投稿清单 | 只读投稿列表 ≠ 打开并看完其视频，亦不授予私信 |
| 生活关注社交 | `consider_social` | 注意到值得考虑的互动信号 | 只读关注 ≠ 回复已发 |
| 视频主评论 | 专业视频 Agent → Life `video_comment` 意愿 → 既有发送器 | 先有意愿和许可，再有实际事务 | `approval-only` ≠ 成功，`not-sent` 是未发送 |

当前 `AutonomousPlanner` 的动作菜单以 `lib/autonomous-planner.mjs` 为准；公开评论、私信等由专业 Agent 协同，不能仅据动作树认为 Life 直接拥有所有平台工具。`SocialPolicyGate`、账号校验、模型意愿、去重、额度、未知回执冻结继续独立生效。
