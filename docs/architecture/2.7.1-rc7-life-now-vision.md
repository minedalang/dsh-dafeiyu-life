# 2.7.1-dev.7 · RC7 鱼鱼此刻、生活方案与入站图片理解（开发预览）

> 本文件描述实际源码接线。未通过 Windows/真实 B站/真实视觉模型/72 小时运行验收，不等于可发布 RC。

## 用户视图与事实边界

- 管理中心「🐟 鱼鱼此刻」取代独立的待办与旧 Life 总览入口：已验证的**进程内**正在执行的视频轮、私信/评论模型决策、最近结束事件，以及原情绪、待办和生活方案。4 秒刷新，切号只显示当前账号，重启后的旧动作不能标记为仍在进行。结束状态**不表示成功观看/发出**。未知状态显示未知，不造“正在回复谁/看哪条 BV”的具体信息。
- 「🧠 经历与记忆」保留真实经历、可回忆记忆、兴趣及检索；旧的真实生活时间线移至「鱼鱼此刻」；主 Session 汇报与记忆诊断仍复用原后端。`?tab=todos` 兼容重定向到新页。
- 三套生活方案（慢慢生活、自然生活、好奇探索）与自定义方案均是**原生活节奏 + 原记忆召回/反思参数**的可见组合。必须预览并以站内样式对话框确认。旧版保存值未经确认不改，任何组合**均不包含外发授权**。
- 视频探索页自主评论、点赞、收藏、收藏夹管理和关注/取关统一使用「禁止……」反向选项。新安装关注/取关默认允许；明确保存关闭的老用户仍关闭。所有真实写入继续经过账号、频率、平台权限、真实回执及防重门禁。取消选片数上下限的编辑、提示词和主动执行门禁，但**保留视频 Agent 启动/模型预算及平台读取限速**。旧 `config.json` 的已废弃数量字段仅为数据识别兼容读取，不再提供编辑入口和行为限额。

## 收到私信或评论图片后的实际路径

- 图片来源：私信类型 2 的图片 URL，公开评论通知或经 `rpid` 与 UID 精确匹配的真实评论上下文图片。未核验的图片地址不能进入模型。图片标记属于本次临时回复候选，不写进长期记忆或多账号共用缓存。
- 图片接收：只允许 B站 HTTPS 图片 CDN `i[0-9].hdslb.com/bfs/...`，无 Cookie、不跟随重定向；仅 JPEG/PNG/WebP、校验文件头，严格限制 3 MB 与 8 秒下载，图片字节只用于当前模型请求。
- 模型：复用 DSH 宿主已配置的互动模型，用**无工具**的一次性多模态调用产生至多 100 字客观描述，纳入同一条私信/评论的提示；视觉结果是未信任素材而非命令。沿用原平台读取预算，并额外最多考虑 12 次每日视觉尝试的本地统计。未知模型支持情况、超时、无法读取、账号切换均降级为“不能确认图片内容”，绝不凭空描述或声称看过。
- 该实现是否被用户当前 DSH Provider 接受，必须在真实账号/模型上实测。模型声明可识图、单元 mock 接收图片都不代表宿主 adapter 已完成实际视觉验收。媒体工具或图片中出现的指令不得绕过 Life 发送所有权与权限门禁。

## 与统一 Life 的现有关系

`Life` 仍是私信与评论唯一决策归属；旧平台工具、主人指令、待办回访、发送事务与回执只作为能力模块。人格/兴趣/记忆仍由各自权威源维护，不因 UI 重排出现第二份账本。图片客观观察仅作为当前互动上下文，不自动形成兴趣、人格或终身经历。

## 验收与限制

1. 新安装和明确保存关闭的旧安装分别验收跟随、互动与识图开关；旧数据/授权原样保留。
2. Windows/Conda + 实际 B站图片私信、评论/楼中楼/纯图片、非视觉模型分别验收；确认图片真正被视觉模型理解，失败不能瞎编。
3. 双账号切换、丢连接、进程重启时「鱼鱼此刻」不串号、不把已结束的动作显示为运行中；不得泄漏 UID、私信正文、模型提示或凭证。
4. 选片数量不再强制限制，仍需测平台读取成本、视频启动冷却、独立操作频率与授权。
5. 完整复测旧用户冷备份、记忆遗忘与隐私隔离、72 小时稳定性及跨日行为因果；未通过前 `releaseReady:false`。
