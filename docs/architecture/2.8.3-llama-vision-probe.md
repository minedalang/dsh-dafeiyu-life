# 2.8.3 llama.cpp 视觉独立技术验证（dev.89，非生产能力）

维护者批准先验证，不变更现有生产视觉 provider、模型默认值、安装流程、存储迁移或 Life 运行。生产仍使用原 Ollama / DSH；本地 Embedding 仍由 `embedding-runtime-manager.mjs` 管理。开放人格留 2.9.x。此实验不进入 npm 普通用户包、不访问 B站、不写任何真实记忆。

## 单一事实源及安全边界

`tools/llama-vision-probe.py`（仅源码维护者运行）以合成形状/颜色采样调用 `preview_vision.py` 的原 `_make_preview_boards`、`_call_local_ollama` 的请求预算/提示与响应验证，以及 `_analyze_local_storyboards` 原批次、补救、时刻绑定及局部回执。显式 Python callable 仅由实验入口提供，不是配置、MCP、Session 或网络可控制参数。以 llama.cpp OpenAI 兼容 `/v1/chat/completions` 接口传入原 JPEG data URL，归一化可见 `message.content`、finish reason、completion token；不把 reasoning 当成描述。服务故障继续使用原受限错误分类以复用停止条件（`ollama_*` 是历史分类名，在本报告中不代表 Ollama 被实际调用）。

显式给定可信本地二进制和配对权重，独立环回端口、随机临时 API key、无 shell、无代理/跳转、请求及响应沿用原限额；仅结束自己创建的子进程。不使用生产配置或账号、也不向原 Embedding 服务发送图像。共享二进制文件可以试验，但不共享模型进程或自动启动服务。进程清理在正常返回及可捕获异常中执行，强制杀死父进程/断电等异常仍须验收。日志只含合成图测试，但可能含本机路径或临时 API key，分享前检查。没有增加用于理解自然语言的规则；技术约束仅为本次获准的独立环回实验，不能作为新的生产授权规则。

## 上游参考

- [llama.cpp server](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md)：多模态 `image_url`、chat template kwargs。
- [现行 Embedding 固定版本 b12110](https://github.com/ggml-org/llama.cpp/releases/tag/b12110)，下载必须匹配本机架构与所选 CPU/GPU 构建并核对上游哈希。现有本地 Embedding 的 CPU 版可先测试，但不能据此证明 GPU 版可用。
- [Qwen3.5 2B GGUF](https://huggingface.co/unsloth/Qwen3.5-2B-GGUF/tree/main)、[Qwen3.5 4B GGUF](https://huggingface.co/unsloth/Qwen3.5-4B-GGUF/tree/main)：分别选择对应量化 GGUF 和同仓库配套 mmproj（例如 BF16）。
- [MiniCPM-V 4.7 1B GGUF](https://huggingface.co/openbmb/MiniCPM-V-4.7-1B-gguf)：上游示例使用 `MiniCPM-V-4_7-1B-Q4_K_M.gguf` + `mmproj-model-f16.gguf`。

实验暂不提供自动下载。手动确认来源、版本、量化、配对和哈希；不要直接将 Ollama 的 blob 文件重命名为 GGUF。发布接线前需固定每个资源版本/校验、许可证、下载恢复、存储域及安装取消机制，复用原本地运行时管理基础。

## 本机验收与结论判定

见本批 TESTING.md。合成 12/24/48 格仅用于检查图像内容和空间定位的初步能力；`completedBoards`、`structurallyParsedCells` 只反映结构解析，不能代表语义正确。人工逐格核对 `ground-truth.json` 与 report 中原模型描述，记录色彩/形状、漏格、错位、臆测；继而使用合法、脱敏真实分镜做后续实机比较。对照 Ollama 保持相同采样、提示、思考关闭、批次及上下文条件（量化、模板、实际上下文可能不同，须记录）。2B 单图策略保持。记录冷启动和推理时间、CPU/GPU实际卸载、峰值内存/显存、失败后进程退出及并行 Embedding 是否仍能服务。GPU layers 仅请求参数，不是卸载证据。没有真实模型性能或资源数据前，不能宣布比 Ollama 更快或将内置后端设默认。

当前环境无 llama-server/视觉 GGUF/GPU，Hugging Face DNS 失败；实际验证限本机模拟 HTTP 线协议、原解析、子进程清理与原生产回归。所有原发布门禁继续开放。生产架构接线未变，Life 四图不需要新增实验节点。
