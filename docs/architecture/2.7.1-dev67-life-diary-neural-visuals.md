# 2.7.1-dev.67：生活日记与神经回忆点阵显示修复（未发布）

## 用户需求与症状

- 「大肥鱼的一天」每隔数分钟展示“暂时没有合适行动 / 这轮没有找到可执行的生活机会”，形成重复的技术事件列表。该消息源自 `AutonomousPlanner` 的 `no-actionable-options` 结果，而非鱼鱼真的做了一件事，也非模型主动选择休息。
- 截图中神经回忆场密集节点像被纵向拉长，边缘观感模糊。密集 Canvas 原使用独立的 `width/1000` 与 `height/570` 缩放，而 SVG 的相同逻辑坐标系默认等比缩放，两者不一致；Canvas 圆点变椭圆，查询光束位置与节点也可能错位。Canvas 模式还将作为点击承载层的 SVG 设为 `visibility:hidden`，且点击后备分支检查了错误的类名。

## 统一归属检查

| 层 | 原事实与本轮改动 |
|---|---|
| Life 决策与诊断 | 原 `AutonomousPlanner` 与 `LifeAgentEvents` 继续记录空轮询、拒绝、模型返回等数据；不删除、不合并、不改变调度额度。管理中心「诊断 → 鱼鱼的决策全过程」仍可查看。 |
| 主人生活日记 | `buildLifeTimeline()` 仅调整已有来源数据的只读**展示投影**：保留真实探索、核验阅读、互动、自主休息，省略无候选技术轮询与主评论内部诊断枚举。不会将没有发生的外部动作包装成已完成。 |
| 神经回忆场 | `memoryRetriever`、Life Memory、Embedding PCA 坐标、真实来源连线和记忆清晰阶段完全不变；只改 `management-console.html/js` 的绘制、等比画布适配与点击换算。 |
| 隐私与授权 | 仍不展示未经核验的私信或评论正文，不扩展 B站写入权限，不触发额外模型调用。 |

## 可观察合同

1. 多轮 `no-actionable-options` 仍存在于原决策事件账本／诊断中，但在「大肥鱼的一天」里**不生成任何生活卡片**。有明确 `voluntary-rest` 的模型选择可以展示简短“自主休息”，且不能伪称外发。
2. 「连续的生活片段」保留同源轮次绑定的开始、结束和真实选片；未能绑定的独立片段单独展示，不因界面简化而伪造连接。评论审核具体技术分类移至原决策日志／高级诊断；真实评论单独依赖公开平台回执。
3. 对于任意实际视口，Canvas 节点按 `min(width/1000, height/570)` 等比缩放并居中，与 SVG 和语义光束保持一致；设备像素比最高 3 倍采样，节点使用小半径、清晰描边和局部高光。清晰／模糊／印象的透明度仍仅取原记忆阶段。
4. 高密度 Canvas 模式 SVG 仅透明、不丢失鼠标与键盘命中；按同一等比几何将指针映射回 1000×570，原全屏、旋转、缩放、筛选、详情和证据连线继续工作。
5. `AGENTS.md` 提供以后各 dev 版本持续有效的完整交付包及中文 Conventional Commit 规则，不把每版详细改动流水账堆在规范里。

## 验证与边界

- 覆盖空轮询不出现在日记、真实休息保留、评论技术诊断不污染生活卡片、宽高比和命中换算、交付规范的专项 Node 回归。
- 未在用户 Windows DSH 管理中心、真实 B站账号、不同 DPI/缩放/全屏和 10k 个真实节点下完成实机验收。仍为开发预览；不能据此宣称新的自主行动或评论成功。
