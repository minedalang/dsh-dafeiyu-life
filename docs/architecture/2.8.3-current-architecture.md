# 大肥鱼 2.8.3 · 当前系统设计

本页是 2.8.3 功能范围的当前入口。源代码版本以 package.json 为准，发布状态以独立渠道及验收记录为准。旧 dev 文档是历史快照。

## 统一 Life 及执行约束

一个角色、一个 Life 调度所有者；机会、意愿、已接受任务和真实执行结果分别记录。`index.js` 负责接线，`lib/autonomous-planner.mjs`、`lib/life-willingness.mjs` 决策，`lib/interaction-scheduler.mjs` 与原平台执行层共享预算、账号代际、拒联及去重。成功必须有真实平台回执，未知发送结果不能盲重发。主人私信定向150/30秒，普通哨兵与自适应检查不变。新装建议不等于外发许可，旧缺键保守、换号授权重新核验。

## 观察、记忆与成长

真实视频事件 → 核验观察与时间码 → 浅层经历 + 有界深层视觉附件 → 当前活体网关 → 合法检索/实际交付 → 自主选择、反思或原文采用 → 有证据的认识/联想/有限强化。永久档案是管理与备份数据，不进入日常 AI。容量3200（组内观察计入），优先淘汰遗忘占位、兼顾重要度/证据/时间；遗忘撤销深层与向量。新记录不从历史档案恢复。长期记忆与分类自述独立，私密域不进入公开社交/联想。

`life-memory-gateway.mjs` 是活体证据边界，`memory-retriever.mjs` 管理词法/本地向量/有界候选，`life-reflection.mjs` 与 `life-memory-associations.mjs` 验证独立认识和关系；图谱是投影，不是第二事实库。完整 BV 严格匹配，`visual_query` 反查画面，`detail_bvid` 读取现有附件不联网；新补看是独立真实观察。当前有界强化只覆盖已核验公开即时联想、深层反思有效续答及主 Session 已提交回复的原文采用。每条每日一次、累计最多20；非引用释义、其他普通渠道不普遍强化。自动反思成功最多恢复同域两条暂停候选，各一次补救、12小时退避。七日变动仅真实计数，不补历史。

## 能力与模型

B站、自主生活、人格、自动记忆、经历桥独立配置，保存重启按代际生效，旧在途按回执结算；本地记忆可无 B站使用。模型实际验证和能力门禁独立。无工具调用优先直接模型路由；后台 Headless overlay 禁用宿主已知会话持久化/投影，禁止续用正常聊天，不触碰全局配置或历史 Session。实际宿主兼容性需实测。

## 存储与诊断

V2 只迁移 Whisper/Embedding 大模型，核心 Python/uv、Life 数据和临时缓存不随大型模型迁移，Ollama 独立。原件保留、校验后切换；仅回收本次独占创建、未发布且确认失败的临时目录。旧 V1 仅兼容维护，整盘冷备份不属于本版。业务备份、记忆备份、完整诊断分别管理；自动业务备份先核验同角色文件才轮换最近两日。SQLite 一致性快照不等于跨库原子快照。实时诊断记录插件实际报告的版本与主人定向检查的非身份聚合状态；无实际加载版本/实时状态证据时不把旧副本当当前版本。

## 管理界面及新老用户

能力配置与首次引导共享真实准入，不靠 UI 隐藏绕过。新用户需语义就绪；显式旧值不被升级覆盖。教程使用原 dafeiyu 形象与隔离演示 DOM，不写数据，完成/跳过清理状态；普通切页锁定，可重看。管理中心不新增版本宣传弹窗；原生设置页展示版本亮点。记忆方案独立于 Life 活跃度及模型。
