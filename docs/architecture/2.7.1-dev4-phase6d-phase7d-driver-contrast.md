## 行为与费用

- **不自动执行模型对照。** 只有当前账号已核验、生活模式是 `shadow` 或 `active`、已有 48 小时内真实成功只读类别、原日预算至少剩下两次且用户在管理中心明确确认，才能触发。
- 预留两次模型决策额度后分别调用**当前配置的同一个真实模型**。即使模型失败、返回非法格式或在第一通后切换账号，也不退还已经预留的两个额度；避免错误地认为请求未计费。没有新建模型预算或独立调度器。
- 两份提示除 `recentVerifiedReadEvidence` 的枚举及时距以外相同，不传任何真实任务、人、私信、BV、记忆原文、外发内容；模型只可选 `pause`、`continue_read`、`reflect`，这些是**倾向类别**，不是已经执行的任务，也不是待办指令。
- 模型返回不同，只能说明这两次合成诊断的输出不同：还可能受到采样随机性影响；**不证明在完整真实 Life Agent 决策中发生因果改变，更不证明人格已成长**。返回相同也不能证明经历无价值。以后若做真正成长研究，需要受控重放、跨日实测、长期状态读写一致性审计。
- 模拟验收使用 OS 临时目录与假模型，零真实调用、零网络、零外发；真实 DEBUG **会花费模型额度**，但不会访问 B站或发送信息。

## 数据及旧用户安全

`lifeDriverOwnership` 是纯函数，不写入磁盘；配置和七天匿名生活事件的格式不变。旧用户已有的设置不会自动迁移，旧时段数据、人格/记忆、关系、待办、回执、安全冻结与账号绑定均保持原状。恢复旧配置不会通过诊断操作扩大社交写入。`shadow` 或 `active` 仍由旧时段视频执行门禁抑制老定时器；系统内仍保留旧 Planner/社交决策器的兼容逻辑，**本轮没有物理删除它们**。
