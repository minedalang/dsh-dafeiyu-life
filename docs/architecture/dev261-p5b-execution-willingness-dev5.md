# 2.6.1-dev.5 · P5-B 现有接口审计

## 目标

1. 仅对自动规划器处理的、原本已接受的只读 B站待办实施执行前意愿复核。
2. 保留主人主 Session 即时请求的可靠工作模式；不把模拟情绪当作工具权限。
3. 在背景计划候选窗口中提升等待较久的任务，并按原真实 UID 尽量多样化呈现，避免单一熟人占满 8 个模型候选。
4. 当前状态给模型的是 0~100 的受限数字，且不包含任何私信原文、姓名、完整 UID、秘密或假定心理状态。

## 接线

- `lib/dual-context-agency.mjs`：新增无副作用的 `assessReadExecution(task)`，仅验证只读类型、活跃状态、真实模拟情绪和有界关系加分；情绪极端低时只延期不放弃。
- `lib/autonomous-planner.mjs`：按最新库存展示最多 8 条已接受只读任务，长等待有限加权，来源多样化；模型选中后重新读任务并校验状态/到期，再用执行前意愿决定执行还是延期。
- `index.js`：将原有 `DualContextAgency` 与 `EmotionalState` 注入计划器。没有增加定时器、权限开关、外发入口、模型调用或持久化数据库。

## 保持的边界

- 关系加分不授权点赞、收藏、评论、主动私信或回访。
- 已接受任务不会因为暂时低精力自动遗忘；模型原有明确 dismiss 选择仍合法。
- 对确定失败和平台回执不明的任务，继续遵守 `owner-todos` 安全恢复规则。
- 本版没有变更私聊历史摘要算法；旧 `dm-autoreply-state.json`、`owner-dm-agent.json`、`long-term-memory/` 原样沿用。
