## 调度器偶发停止

`AutonomousPlanner.start()` 幂等创建原有 interval，`ensureStarted()` 仅当总开关、`autonomousPlannerEnabled`、Life 模式同时允许时恢复意外消失的 timer；管理 API 读取与主人手动考虑会经过检查。此操作**不触发模型决策**；运行租约、模型退避、账号/权限/额度依然保留。旧日志没有完整证据证明所有卡住都是 interval 丢失，其他原因继续通过心跳与阻断码诊断。

## 行动日记

已核验作者空间可关联选定 BV 和该作者公开投稿；只在同一意愿账本里允许关联。普通评论回复的 UID 只有在真实平台回复记录含 `recipientUid` 时显示；没有确认视频的轮次不生成 BV。图片标题、AI 语义相似不构成身份来源。旧日志中没有存 UID 的行动不能回填 UID。

## 神经场

`fading-life-episode` 的 `stage='trace'` 表示历史已衰减成印象；不代表新产生的记录，不参与搜索结果，仍可在全景背景中显示。食物偏好查询不再让所有视频兴趣汇总都命中；关键词词组与真实 Embedding cosine 合并排序，线段强度仍以真实高维 cosine 为准。

## 梗学习

`Day 0`、`Day 1`、`Day N`、`经验开源` 等标题前缀保留为待核实线索，但禁止直接入梗知识。纯标题至少需三个不同 BV 且名称非通用标记；字幕、评论、弹幕等内容证据至少两个 BV。旧版待核实标题-only 标记可降级但保留来源；不会降级人工已核验知识。
