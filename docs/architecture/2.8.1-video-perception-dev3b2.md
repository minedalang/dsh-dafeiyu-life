# 2.8.1-dev.3b.2 · 受控帧 OCR / 本地 Whisper 时间分段（开发增量）

> 基线：dev.3b.1。仅声明离线可验证的实现；真实 B站、Windows、DSH / Ollama / Tesseract / faster-whisper 端到端另行测试。

## 1. 鱼鱼意愿及来源

- Life 先决定是否看，再自主决定 `skim/standard/deep`：`skim` 不调用视觉，`standard` 最多12帧，`deep` 由用户卡片设置12/24/48个时刻上限。本批不新增视觉模型请求，也不提高视觉额度。
- B站官方字幕：明确 `from/to` 秒的 `timed_segments`，属于官方字幕数据，不证明实际听到了音频。
- 本地 Whisper ASR：仅已启用 `transcribe` 且字幕不存在时，原有 `bili_transcribe_safe` 限定 BV 后调用固定 `.venv-asr` / `asr.py --json`；从 `faster-whisper` 的 `segment.start/end` 得到明确秒数（最多160段），错误不会当成功正文。依旧可能通过现有 yt-dlp 下载音轨，非“完全离线媒体获取”；新增的结构化模式不接收任意网址。模型语音识别可能出错，不是亲耳听过，更不是官方字幕。
- 本机 Tesseract OCR：只在 `perception_source=adaptive` 的公开单段视频真实 FFmpeg 解码成功后，对最多12个分散时刻尝试 OCR；没有本机 `tesseract` 可执行文件或缺对应语言包便跳过，不会自动安装下载，不会对 videoshot 或图像模型猜测生成 OCR 回执。中国语言文字推荐自行安装 `chi_sim` 语言数据。识别信度筛选不能保证 OCR 正确，更不能代表整片视频文字。

## 2. 数据与安全

- `lib/frame_ocr.py`：Pillow 放大灰度处理→通过 stdin 将 PNG 送入本机 Tesseract 固定参数 `--psm 11 tsv`→筛选置信度≥60 的词→单帧文字≤120字符，最多12帧，每次最多3秒；无需额外 OCR 图片临时文件。OCR 出错不导致原视频取帧失效。
- OCR 只在实际解码采样结果中传递：`adaptive_video.py → preview_vision.py → [vision_dsh.py/独立 Ollama] → MCP → index.js → video-evidence-bundle.mjs → video-perception-timeline.mjs`，同 BV、采样来源、时刻、OCR 引擎全部校验。低清回退不能借用 OCR 结果。视觉缓存会按原既有机制包含这份有限 OCR 机器摘录；不写入新的永久事实库或外发授权。
- 视频证据包只记录 OCR 的来源、状态、时刻/条数，**不保存 OCR 原文**；Life 只读 `perceptionTimeline` 才返回有界的 `frameOcr` 摘录。原有视觉模型文本属于模型看图结论，与 OCR 引擎结果分开。
- ASR 段使用 `nearbyAsr`，字幕使用 `nearbyCaptions`，OCR 使用 `frameOcr`。同一时间上出现不等于它们含义一致；统一 `alignment=time-proximity-only`，不推出人物身份、音画因果、情节真实性；任何识别到的外部文字都是不可信数据/不得按其执行工具命令。
- 既有 24 MiB B站公开单段 DURL、最多45分钟视频、实际解码累计≤120秒及低清回退限制保持不变。不额外下载原视频、Cookie、不添加写入权限。

## 3. 修复与限度

- 修复聚焦时间窗口检验引用未赋值 `windows[0]` 引发的 Python 异常；现在直接验证所选起止秒数与真实视频时长。不能取到公开流时仍按原有回退/停止规则处理。
- DSH 第三方视觉 Provider、PowerShell Ollama 启动、视觉能力助手与 README 矢量双图不变。本批没有语义跨源一致性判断；后续 dev.3b.3 再研究局部疑点及冲突核查。
- 真实 Tesseract 识字质量（尤其是 192×108 的中文文字）和 Windows `.venv-asr` 输出需用户端验收；英文语言包不等于具备中文 OCR。

## 4. 验收

运行 `node --test test/v281-dev3b2-ocr-asr-provenance.test.mjs`，`python -m unittest discover -s test -p 'test_dev3b2_timed_asr_ocr.py'`、既有视频/ Life 回归、`npm run check:video-tool-contract`、`npm run check:life-architecture` 与 npm pack dry-run。重点检验没有 Tesseract/语言包或没有字幕时的降级，以及不同 BV/帧来源/时间戳不串用。离线模拟不等于 Windows 实机验收。
