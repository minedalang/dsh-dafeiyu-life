## 状态、生命周期和信任级别

- **`SocialPortraitGateway` 准入理由：** 原 `SocialRelationshipIndex` 只保存熟悉度元数据；`friend-learning` 只保存自述兴趣／推荐同意，不应该顺便承担交流风格、可撤销证据与私密域治理。新层具有跨私信与公开评论两个入口，以及独立按账号/UID/证据/隐私域的生命周期；不承载人格、情绪、发送权限、真实人生经历或任务执行事实。
- **唯一可写来源：** 两个真实已验证入站入口的确定性提取和同源管理员确认的纠正/撤回。当前只识别有限且明确的交流偏好（简短／详细／温和）与公开 @、主动私信边界，不推测性格、政治、疾病、亲密关系等敏感属性。样本重复跨日出现后才标记为重复明确证据；相互冲突时最新明确表达优先。
- **证据字段：** `id`（只含加密哈希摘要）、`uid`、`source=dm|comment|owner-review`、`scope=friend-private|public`、`code`（白名单枚举）、`at`、`event`（哈希）；无原文、摘要、昵称、手机号、其他人内容。文件大小与条数受限，禁止符号链接，原子替换。过期 180 天后停止模型读取；明确撤回立即失效，UID 清除删除证据行及关联撤回记录；跨账号不迁移。
- **旧数据：** 不从已有 `friend-learning` 或普通记忆自动倒灌建档。以前的兴趣自述继续由旧层独立读取；新画像升级时仅由新增入站事件开始累积，无跨账号回填。旧用户名册变更后，不在名单的 UID 画像不再可读取或修改，数据不会变为陌生人档案。
- **开放兴趣：** `curiosityCandidates` 是 `life-memory/interests.json` 中向后兼容的新可选数组，只表示近期接触的未知主题，记录 `{topic,bvid,at}`，14 天只读过期；**不是** `entries` 中经过累计证据的长期喜好，也不进入 `interestMemoryRows` 或 `personaPrompt`。词表 `TOPICS` 匹配的稳定兴趣维持老证据门槛；未匹配也不代表不喜欢。来源为真实可信的 `watch` 且质量标记为 `selected/值得看/可以看`，标题中的潜在指令与隐私字样会拒绝提取。陌生人发送标题不会直接变成长久兴趣。
- **下一阶段：** 更丰富的对话风格、确实来自多次互动的主题递进、低风险人工回顾、兴趣的模型主动提问尚未生产化；不能把当前窄范围枚举自述称为“已经理解好友全部性格”。如果未来允许模型提炼必须增加明确审核、证据回链和同样的个人信息过滤。跨渠道频控只管理 dev.2 已列的自动发送路径，画像不会扩大覆盖。

## 失败和回滚

- 画像文件损坏或过大：读取/修改抛错，当前回复保持原有授权门禁，不会使用旧的私密原文重建；生产回调记录诊断并跳过画像，**不影响已核实普通来信的原有单次回复路径**。
- 账号切换：存储在当前登录账号的 runtime；冻结期间不产生新画像，新的账号目录无法读取旧账号画像。手动删除 `social-portrait/evidence-v1.json` 只是清掉新线索，不恢复任何此前已遗忘的私信内容。
- 好奇候选存储异常：沿用现有 `selectionInterests` 捕获异常的旧兜底；没有新外发许可。删除兴趣存档中的可选 `curiosityCandidates` 不影响原有 `entries` 的后天兴趣。

## 真实验收边界

单元测试覆盖确定性提取、私密域、幂等、失败关闭、清除/纠正、选片低权重与源码接线，并拦截实际 `InteractionBatcher` 送往模型的消息字段，验证私信/公开 `portraitContext` 分域和 Life Voice 只注入一次；但 **Windows DSH Desktop UI 点击流程、真实 B站通知 UID/来源、真实视频标题质量来源及平台远端模型行为仍需本机/平台端到端验收**。未执行任何真实 B站写入。
