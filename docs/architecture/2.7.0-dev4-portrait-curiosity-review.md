## 数据与生命周期

- `SocialPortraitGateway` 仍是**明确交流自述**的唯一存储源。新增枚举 `style:ask-first`、`style:no-spoilers`、`boundary:no-followup`；原 `style:brief/detailed/gentle`、`boundary:no-dm/no-public-mention` 不变。明确边界只能否决 P6 的**无新消息延期行为**，不能赋予新发送权限、强制模型沉默所有新来信，或绕过其他更严格的退订机制。撤回证据或 180 天衰减后，不再影响延期；每次到期必须重新检查。
- 对公私域：DM 续聊可使用当前 UID 的公开和私信证据；公开评论/@ 续聊只检查公开证据。**不能把私信画像文字带进公开模型提示。** 画像读取失败时只取消相关 P6 预约，不影响已经授权的普通来信回复。
- `curiosityDismissed` 是 `interests.json` 的可选数组 `{id: sha256(normalizedTopic).slice(0,24), topic: sanitizedTitleHead, at}`，上限 60 条、30 天过期；旧 schema:1 文件不需要迁移。`curiosityCandidates` 仍最多 60 条、14 天过期，且仅由原本可信的 `kind=watch`、合法 BV、质量标签入库。拒绝只读主题探索不会抹掉真实观看历史，也不会将拒绝写入人格或记忆。
- 管理页「鱼鱼最近喜欢什么」新增默认折叠的候选审阅：**排除**只作用于当前有效 BV 对应主题；**撤销排除**允许未来的新证据重新形成候选，绝不回放旧候选；**清空候选**不影响排除记录或长期兴趣。

## 失败、恢复与回滚

- P6 预约读取画像损坏／超限：拒绝新的延期；已领取意图记为取消，不尝试发送。既有即时回复继续通过原许可、额度与平台回执门禁；不把损坏存档中的内容注入模型。
- 好奇候选存档损坏／路径符号链接：API 返回错误、选片入口回退到原有核心兴趣/冷启动词；不在异常时悄悄写新文件覆盖旧档案。错误来源/不存在 BV 的排除请求失败，不允许通过 POST 新建未知主题。
- 升级：只升级 npm 版本为 `2.7.0-dev.4`；不会自动启用公开 P6、陌生人私信或兴趣写入。回滚到 dev.3 时，`curiosityDismissed` 作为未知可选字段保留，但 dev.3 的 `selectionInterests` **不理解排除**；如果必须回滚，请关闭自动选片并核查排除是否需要人工保留，不能宣称回滚后仍会执行 30 天排除。
- 本轮新增状态可能被旧版备份完整保存，但没有修改既有备份迁移协议；实际 Windows／B站读取、动态/私信平台回执与桌面 UI 点击需在用户环境验收。没有真实平台外发测试。

## 仍未完成

- 当前深度画像仍仅限有限、低敏、明确表达的交流方式与边界，**不是**对性格、情绪、私密经历的全面理解；更开放的、经人工确认的长期主题归纳未上线。
- 好奇探索仍只从真实入选视频的可信标题产生候选，不从任意陌生人文本或模型臆测主题生成；尚未提供模型自主提出新主题并经主人审核的独立探索流程。此限制防止隐式扩大读写权限或伪造兴趣。
