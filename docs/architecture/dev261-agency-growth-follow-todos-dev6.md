## 故障与安全边界

- **主 Session 的工作**不经过管理页提醒操作。该提醒只决定背景已接受的只读事项，不新增私信/评论/关注授权。
- 后端管理 HTTP `action=run` 已返回 403，避免前端隐藏后旧执行接口仍可被调用；显式主 Session 授权的任务执行工具保持原有可靠执行语义。
- 人格证据只从 `LifeMemoryGateway.reflectionEvidence` 的当前衰减副本读取；不能从历史备份补回。社会互动必须存在实际回复回执；弱观察不声称收到积极反馈。人格账本保存内容哈希、日期、带盐的 UID 哈希和权重，不保存聊天全文。
- 预估自动决策时刻属于下一次心跳可以考虑的最早候选时间，不等于平台行动时间。
- UI 中零关注可能意味着开关关闭、当日没有入选视频、鱼鱼不想关注、对象已关注或平台 API 拒绝；不能仅从零关注认定功能故障。
