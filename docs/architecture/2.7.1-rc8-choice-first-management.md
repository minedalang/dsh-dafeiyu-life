# 2.7.1-dev.7 · RC8 管理中心「整套方案优先」

## 用户问题与目标

普通用户不应学习一堆 `auto*`、私信额度、冷却和跨渠道术语后才能决定鱼鱼怎么生活。优先展示解释明确、可点选的场景方案卡；高级调整集中在 **自己设定**。保留当前「🐟 鱼鱼此刻」原有生活/记忆整体方案。

## 唯一状态与权限路径

| 用户场景 | 推荐方案 | 唯一原配置源 | 不在方案中修改 |
| --- | --- | --- | --- |
| 视频探索 → 自主互动 | 自由互动 / 适度互动 / 安静探索 / 自己决定 | `/api/bili-duty/config` 的 `autoComment`、`autoVideoLike`、`autoVideoCollect`、`agentFollowEnabled`、`autoFavoriteDelete`、`incomingImageRecognitionEnabled` | B站账号、视频报告私信、收藏夹可见性、额外关键词、每日硬额度、其他社交授权 |
| 后台私信 → 交流方式 | 自由交流 / 熟人优先 / 暂停交流 / 自己设定 | `dmWatch`、`dmStrangerAutonomyEnabled`、`dmApprovalEnabled`、`dmP6Enabled`；显式方案同时设 `dmStrangerOnce=false`，关闭旧一次性授权 | 好友名册、主人 Agent、拒联记录、私信额度、聊天历史、发送事务 |
| 社交互动 → 视频推荐 | 自主分享 / 只准备草稿 / 暂不分享 / 自己设定 | `socialOutreachEnabled`、`socialLifeIntentEnabled`、`socialAutoSend`、`socialVideoRecommendationsAuthorizedV2`、`socialOutreachDailyLimit` | 收件人白名单、关系画像、14 天冷却、Life 最终发送选择、真实平台回执 |

UI 方案是**视图层映射**，不创建新的配置表、迁移脚本或替代发送器。载入时只读取原配置并匹配：匹配不到任一方案就显示「自己决定」；不能只因为是旧版安装就自动重置为自由。新装默认值仍以服务端配置为准。

卡片点选仅在本地表单预览；点击各自原「保存」按钮才写配置。新增视频写入授权时统一弹出有样式的确认；开放陌生人多轮私信要求额外确认；启用视频推荐自动私信继续使用原明确确认流程。取消操作无请求，操作不确定时原发送事务冻结，**不自动重发**。方案无法突破总开关、身份/账号校验、额度、冷却、隐私、拒联、已取消回访或平台回执规则。

## 不采用方案卡的地方

账号绑定、主人高权限写入工具、模型 Provider/凭证、人生记忆恢复和不可逆数据删除不适合「自由/谨慎」一键授权；保留独立显式验证。图文卡包含键盘可聚焦 radio、选中状态、移动端两列布局、减少动效与角色提示；所有新增 input 必须有唯一 ID 或适当 `name`，不得重复定义原配置项。

## 集成与验收

- UI 入口：`lib/management-console.html` / `lib/management-console.js`，不改变生产 API。
- 原生命令/授权：`index.js` 原 Config、`/api/bili-duty/config`、原统一 Life Owner、`SocialPolicyGate` 和发送事务；本轮不扩大老用户原有权限。
- 防回归：`test/v271-rc8-choice-first-management.test.mjs`、现有 RC7 UI/社交测试，浏览器点击预览与真实保存校验。
- Windows RC：确认旧版自由/受限/混合配置均被正确回显，点击不写入，取消确认不写入，重启后值一致；真实平台验证执行安全门禁仍生效。本轮无 Windows + B站验收，不封 `rc.1`。
