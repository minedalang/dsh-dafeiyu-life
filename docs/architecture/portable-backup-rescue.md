# 便携备份隔离救援与恢复边界（dev.61）

现役 Life 主体只有一个。本批不新增 Life 调度、记忆账本或外发许可。完整业务便携包不是完整停机快照，未包含所有认证、运行环境及外部事务事实；不能作为完整历史状态激活。完整覆盖与跨设备迁移尚未开放。

## 日常在线恢复

- 明确选择的设置及两种可编辑规则文件沿原校验入口恢复；业务历史、数据库不进入在线文件覆盖路径。核验预览前后内容，不回退遗忘、授权、待办及外发事实。
- 独立记忆备份和业务备份沿原活体核验修复。缺失公开观看经历要求角色 UUID 和创建时间一致，原账号、原保留统计、撤销保护、容量和清晰度均通过；备份与现役共享档案的历史前缀须一致，且每条原始经历正文必须有可核验的原档案投影或内容指纹。
- 新公开观看原档案只追加原始可衰减经历的 SHA-256 指纹，不增加原始画面或私密材料。该指纹是本地一致性凭据，不是签名或跨设备独占证明。旧无指纹记录只可由现有原档案准确重建时修复；旧视觉笔记缺失或强化后内容变化可能无法核验。不会重写旧档案来制造证明。
- 深层附件修复沿原记忆锁及撤销核验，补回旧经历不是一次新观看，不重复成长或情绪变化。正常召回仍只读活体记忆，不读取永久档案。

## 严重损坏时的隔离救援（本机命令行）

先保留原备份和损坏数据，退出 DSH。以下命令在插件源码目录执行。使用实际绝对路径；输出目录必须尚不存在，与现役目录和原备份不重叠。不要使用同步共享目录。示例为 PowerShell 单行命令：

```powershell
node tools/portable-backup-rescue.mjs inspect --source 'D:\backups\dafeiyu-business.json.gz'
node tools/portable-backup-rescue.mjs extract --source 'D:\backups\dafeiyu-business.json.gz' --root 'D:\DSH\fish-data' --to 'D:\rescue\fish-2026-11-28' --confirm EXTRACT_PORTABLE_BACKUP_OFFLINE_ONLY
node tools/portable-backup-rescue.mjs verify --to 'D:\rescue\fish-2026-11-28'
```

先建立输出目录的父目录。`--root` 必须是实际现役数据根路径。工具只接受完整性清单可校验的 schema 2 便携包；旧无清单包请保留原件。检查报告不输出记忆正文。提取内容按 SHA-256 保存到 `objects/`，`manifest.json` 记录原逻辑文件名和对象哈希；SQLite 保留原便携 base64 数据而非可运行数据库。原完整性清单会被重新校验。工具不创建现役配置或角色文件，不复制到现役，不启动服务，失败留下隔离目录供核对，不自动删除。输出含原备份可恢复的隐私内容，未加密，应安全保存，不要上传或公开分享。

**禁止将救援目录配置为业务目录、删除 offline-rescue-only.json 或直接复制对象到现役。** 原启动门禁拒绝隔离标记；这不是自动恢复或完整历史回滚，也不能证明两台设备的 UUID 对应同一时间线。需要从原数据建立可核验的停机状态与外部事实保护后才可能开放激活。
