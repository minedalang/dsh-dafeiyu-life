## 本次修改

- `keep_alive:5m` 减少 Ollama 短间隔重新加载；温和缓存会占用更多内存，首次加载仍可能出现外部 runner 窗口。
- 视频只读后台工作状态进内存；脱敏 summary 文件不含 BV、账号明文、图片、模型回答和提示词。8 分钟超时仅指状态不再无限等待，底层仍运行时防重复启动。
- 行动树始终展示五类；真实选中动作/运行中调试才出现叶节点；调试与 Life 自主选择分开。完成与识图成功不再混淆。

## 未关闭事项

- **Windows 黑窗**：Ollama 自身派生进程是否仍可见需实机复测，插件不能保证控制外部服务的子进程窗口。
- **DSH 图片**：`headless_exit_unknown` 仍然未修复；需新一次的脱敏 Node 错误代码或本机 DSH 检查来确定原因。
- **本地 Ollama 模型**：真实超时/不兼容故障取决于你的 Ollama 版本和模型，需要本地验收。
