# dev.30 · 已核验 Life 行动进入同一可衰减记忆

**开发预览，未发布。** 当前源代码 `2.7.1-dev.30`，`releaseReady:false`；不得把离线测试当作 Windows／真实 B站／真实 GGUF 验收。

## 统一层归属

- **决策与执行**：原 `AutonomousPlanner`、视频 Agent、`social-intentions`、Life 意愿和平台适配器继续是唯一来源。想做、准备执行、结果不明不等于已做。
- **可信事实**：原 `life-video-action-bridge` 只在真实平台读回验证后产生写操作回执；原主动视频分享在成功发送且主账本确认后产生回执；Life Planner 只在已经通过本地机会/意愿/待办记录核验的读取操作上投影。
- **统一记忆**：`lib/life-action-memory.mjs` 将可信回执转成最小化 `kind: action` 事件，再由原 `life-memory-coordinator.mjs` → `LifeMemoryGateway` 处理去重、归档（脱敏）、可衰减情节副本，以及 `MemoryRetriever` 的词法＋可选本地 Embedding 候选。没有第二个“推荐历史记忆库”。
- **独立确认证据**：原视频分享账本仍是外发成功和收件人/BV 的原始证明；不能因为检索命中一条记忆就断言平台当前仍可见，或推断鱼鱼确实看完内容。标准视频 URL 仅由真实 BV 构造。

## 写入与读取的事实范围

| 来源 | 入记忆行动 | 证据要求 |
| --- | --- | --- |
| 自动视频分享 | `share_video` | 同一账号、收件人 UID、有效 BV/真实标题、成功发送索引 |
| 视频 Agent 写操作 | `video_like`, `video_collect`, `video_follow`, `video_unfollow`, `video_comment` | Life 逐动作许可、可信视频目标、独立平台读回核验 |
| 已确认私信/社交动作 | `dm_reply`, `comment_reply`, `friend_outreach`, `owner_care`, `followup`, `dynamic_post` 等 | 原 Life 可信完成回执，未知状态不得入记忆 |
| Life 自主只读探索 | `read_public_search`, `read_video_metadata`, `inspect_creator_space`, `inspect_public_person`, `review_public`, `todo_read` | 对应原意愿/机会/待办的真实成功回执，不把标题查询冒充视频观看 |

有标题的行动记录保留当时真实标题、BV 和发生时间；如为主动分享，另保留已核验收件人 UID 供来源核验（不公开显示原始 UID）。无私信正文、评论正文、密码、登录信息或模型推测内容。部分操作本来不产生 BV/标题，严禁补造。历史旧已确认分享以原发送账本、账号绑定、UID 和 `sent` 索引三重校验限量补录；不存在这些来源的历史动作不凭日志/语义近似“补齐”。

## 权限、衰减及召回

`LifeMemoryGateway` 先按当前账号、`main-session` 私有域、存活状态和请求种类过滤，才进入词法／Embedding。`kind: action` 仅在已授权主人上下文可召回，不能自动进入公开评论、普通好友或陌生人上下文。记忆由 clear → fuzzy → trace → forgotten 逐步衰减；一旦模糊会物理擦除精确 BV、收件人和动作字段，已遗忘的行动细节**不能从永久脱敏档案或旧分享账本绕回普通记忆**。

主人问「上次你给我推荐的那个 Deepseek 视频」，专门的收件人+账号成功分享证据可以提供当前仍可信的 BV 与标题；已遗忘的情节记忆不得因此自动恢复。对旧发送证据缺少账号、原始 BV 或发送成功证明的记录，不能编造链接。**应区分**“成功分享过”、“只读标题”、“实际浏览/观看”、“点赞/关注/评论完成”。

## 本地语义模型 UI

当已有模型正在本地运行时，「重新检查本地模型」仅 GET `/embedding/status` 并刷新，不触发 `/embedding/install` 和首次安装确认；模型/运行时已安装但未运行时可在用户点击后请求启动。`renderEmbeddingStatus` 在没有进行中安装/索引任务时隐藏进度容器，索引就绪只显示明确状态。没有自动下载，没装模型也有原有词法检索。

## 实际覆盖边界

这是本轮已接线的动作集合，**不承诺所有未来工具或无法核验的历史动作都会自动入记忆**。新增工具时必须增加最小化凭据、事件类型与测试，才能纳入可信记忆。模型是否在真实场景主动检索到相应经历、日志/回执是否可靠、GGUF 索引是否稳定，需要 Windows + B站 + 模型实机验证。
