# dev.51 · 当前可回忆全景与原主 Session 短暂停顿续接

## 设计事实与严格边界

### 三种独立交流机制

1. **一轮自然多气泡：** 原 `message-burst` 的 P6-A 接连 1～3 个独立气泡，聊天这一轮模型自己决定，不由此增加新的人格或其它 Session。
2. **短暂停顿续接：** 真实主人在已绑定的主 Session 发来新消息、原 Session 已发出 Assistant 消息并空闲，默认再过 **90 秒** 才独立调用 LifeWillingness 判断愿不愿续聊（可配置 60～180 秒）。Life `skip/defer` 则无需唤醒；`act` 经同一 original agent `followup()` 交给原 Session 决定实际措辞。旧用户新输入改变真实回合 ID，所有仍在思考中的旧机会停止。每个真实回合尝试至多一次；本地记录先预约，不明回执不重试。
3. **长期主动找主人：** 原 `owner-silence` 与自主联系候选由 Life 普通规划决定；安静时间、20/45/120 分钟长沉默、4 小时（自然相处）冷却与每天尝试上限**不应用于短暂停顿续接**。原规则和权限维持不变。

短暂停顿需绑定的 live main Session、masterEnabled、lifeAgentMode=active、原会话处于 idle、可信 account tag 和明确开关；本地 15 秒检查不新增 B站网络探测。`lifeWillingness.decide()` 使用 `kind=owner_care`，提供真实但不暴露聊天原文的来源和意愿机会。宿主 `agent.followup()` 确认入队不等于可见气泡或实际送达；没有独立 DSH Windows 宿主回执，不宣称已经向用户展示。可能需要宿主处理内部续聊提示与无内容响应的可靠接口，实机必须测试可选静默及不抢用户下一条输入。

### 神经回忆场

- 来源是现有可回忆的长记忆、反思/兴趣、关系和 Life 的可衰减证据；不扫描 `~/.dsh/sessions`，不读取已封存、删除或已进入遗忘阶段的内容，不另建记忆数据库。
- 新 `/main-session/memory/neural?limit=1000|2000|10000&q=...&kind=...` 最大 10000 个可回忆节点。默认启用「保留全部可回忆节点作背景」；非命中节点灰色暗显，命中节点按记忆类别着色，再按原记录 clear/fuzzy/trace 衰减阶段调整明暗；无阶段则中性。不把时间差当可靠的遗忘证据。
- 普通语义检索原每轮 1～12 条范围保持不变；神经图谱是**只读可视化列表**，不是每轮送给模型的 10000 条 prompt。搜索按关键词和已配置且本地就绪的 Embedding 只读相似结果命中，库不足或权限过滤时不会补造节点。已保存 Embedding 的真实文本向量才参与 PCA 投影，不调模型造向量；未命中向量使用结构布局且在界面明示。
- 可信兴趣／互动／共同来源连线仅在记忆记录显式共享真实来源 ID 时绘制；无证据边时开关显示 0 并说明原因。O(n) 有界建立星型证据边避免 n²；10k 节点 Canvas 绘图，<=400 则 SVG 保留键盘访问；详情仅展示限量结果卡片，图谱其它节点可点击查看原数据。
- 搜索命中后以 850ms 动画平滑移动视角并调整缩放，尊重系统 reduced-motion；旋转、滚轮缩放、全屏与重置继续可用。大密度图取舍性能而非完美保持所有高维关系，PCA 只是近似。
