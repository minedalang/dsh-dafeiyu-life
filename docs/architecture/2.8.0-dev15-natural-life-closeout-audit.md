# 2.8.0-dev.15 发布前审计：自然对话、私信视觉、Life 自由与双向成长

> 状态：**开发验收版，不准标记正式 2.8.0 或声称已通过 Windows / B站实机。**
>
> 基线：2.8.0-dev.14（已合并测试维护与私信最近会话隐私预览）。证据：用户导出的 `bili-duty-logs-20261113-105416-600.zip`；仓库代码；离线模拟和回归测试。
>
> 不导出或引用用户私信原文、联系人 UID、图片 URL、Cookie 或 token。日志中的账号范围、时间窗口与最终发送事实只能按导出记录的有效范围解读；SQLite 部分文件在导出时锁定，样本不完整。

## 1. 关键判断

- **自然多气泡不是“没接入”，但当前真实日志没有证明它生效得足够自然。** 最近一轮普通私信 `p6LastTurn` 为 `proposed=1 / planned=1 / confirmed=1`，原因 `model-chosen-count`；即模型本人仅选了一条。代码容许 1–3 条，不应为了制造热闹强迫输出 2–3 条。普通/主人私信按各自执行器逐条核验回执；P6 不是平台送达保证。dev.15 轻微调整双模式提示：有两个独立真实想法时可以自然分两条，不为了开关而凑数。
- **沉默续聊存在完整预约—到期—重新决定链，但可合理选择不发。** 导出 `social-continuity/intentions.json` 中仅 1 条 `silence-reconsideration`，状态 `skipped`；不能把它误判为“调度没触发”，也不能声称系统自动续聊成功。dev.15 增加最近一次 P6 决策的状态区分，不保存私信内容。
- **存在真实接入缺口：** 原普通私信的同轮图片观察只把最后一条消息的 `imageUrl` 传入视觉层，主人专属 DM Agent 没有直接调用视觉描述。dev.15 复用同一图片观察函数，最多 3 张经校验来源的图片；主人、普通会话权限不同但共享读取边界。
- **外部可靠性尚未过关。** 此次导出的近期 `duty.log` 和轮转 `duty.log.1` 中，`ENOTFOUND` 字符串分别出现 126 / 3438 次，`-509` 分别出现 40 / 280 次，`timeout` 或 `ETIMEDOUT` 等词也频繁出现。以上为**日志文本出现次数，非独立请求数**；它们与 B站读取限流、DNS / 上游不可用及模型服务失败共同导致间歇性不可用。技术异常必须归类 technical failure，绝不能算鱼鱼主动选择沉默。
- **Life 行为不能仅凭调用成功率衡量自然。** 样本里 59 份最近 Life 决策轨迹：56 finished、2 error、1 running；45 次 `model-choice` 包含 skip 14、inspect_exploration 11、consider_social 9、inspect_opportunity 3、begin_exploration 3、act 2、inspect_creator_space 2、browse_home 1。只是最近导出的可见轨迹，不是所有私信回复或完整全生命周期统计。选择分布说明保留了休息自由，**不能证明自然度足够高**。
- **真实成长因果尚未完成验收。** 轨迹中 53 条 `execution-result` 的 delivery 为 not-sent 32、not-proven 20、platform-confirmed 1。它们覆盖所有 Life 轨迹中的不同性质的动作，并非 53 次写入请求。记忆投影入队不等于已成功记住；模型拿到记忆摘要也不代表可验证地由记忆导致了某种选择。需要跨日、真实回执及独立成长账本复核。

## 3. 私信 P6 的端到端审计

### 3.1 能力

模型在 `interaction-batch.mjs` 同一 Life 语义决策中选 `reply/skip/close/defer`，`reply` 可选 `messages` 1–3 条，并可在话题仍开放时自愿加 `idleReconsiderMinutes`。`dm-autoreply.mjs` 接收决定后，按每条送达执行当前账号、拒联、额度、重复发送、新消息与平台回执检查。沉默续聊由 `social-continuity` 持久化，不允许同一延迟回合再次预约形成无限追问。

### 3.2 失败形态要明确区分

1. **模型只选一条**：`proposed=1`，不是多气泡实现故障；可观察真实模型对话风格后再讨论如何调校提示，但不能硬编码 2+。
2. **模型选多条但实际只发部分**：`proposed>confirmed`，检查每条独立平台回执、未读来信变化、当前权限、回执未知冻结、B站风控，不得自动补发。
3. **没提出续聊**：`not-requested`，正常自主行为。
4. **提出却未预约成功**：`not-scheduled`，检查话题结束、旧陌生人一次授权、账号及账本。
5. **到期仍沉默**：`model-chose-skip` 或 `model-chose-close`，与技术故障不同。
6. **调度/模型/读取失败**：保留原有有界重试与技术失败状态；不能把中间错误换算为“鱼鱼不愿意”。

### 3.3 仍需真实环境测试

设计 4 组互相独立的主动观察，不要求每组都出现多气泡：完整话题、共同经历、明确约定稍后联系、自然结束。每组检查本轮上下文、模型输出的 `action/messages/idleReconsiderMinutes`、Life 意愿凭据、各气泡平台 ID 和到期状态，并对照陌生人、好友、主人、撤权和断网。**通过条件是选择自主且执行正确，而不是发送得越多越好**。

## 4. Life 自由、自然与成长闭环审计

### 4.1 自由度（代码已具备）

- 统一模型意愿在真实工具权限之外独立选择行动、沉默、延期、结束；专业 Agent 不再通过自己的喜好再次否决已确立的意愿。
- 真实已核验的视频、社交来信、只读待办和生活契机可以进入统一机会协议；但不同场景的有效证据粒度仍需端到端验证。
- 写入前的账号/目标/配额/拒联/一次性意愿/三阶段回执属于**安全权限**，不是强行剥夺意愿。已选但不能执行必须记录系统阻断，而不是说模型拒绝了。
- 生活循环已经提供休息、无信息增量抑制及有限 Episode 续章。剩余风险是固定轮询与二次观察仍可能增加模型调用、缺少长期负载与真实效率对照。

### 4.2 自然度（证据不足、需持续观察）

- 45 次 Life 选择的分布有自主休息，也有大量观察/考虑；无法通过这些统计判断它在私信是否能表现出跨日主动关心、合理沉默、恰当多气泡与长期关注话题。
- 58 条 `model-input` 是决策轨迹中的事件数，不是实际 token；其中多次达到输入字符上限，表示有压缩成本与上下文质量的优化空间。应统计 **每次获得的新可信证据/有效行动** 对应的模型调用与输入字符，而不是只看每日总调用。
- 日志里存在 DNS、限流和超时，观察样本发生偏差；不应据此推定鱼鱼所有被跳过的交流都是主动跳过。

### 4.3 行动与人格/兴趣/记忆的双向影响

- **人格/兴趣/记忆 → 决策**：能证明决策请求中提供了哪类 Life Voice、公开兴趣证据、受限记忆引用；不能证明模型必然使用了它们。
- **真实行动 → 成长**：平台确认的行为进入经历/账本，独立跨日兴趣由兴趣账本形成证据，人格只按原反思和人格账本实际采纳的记录变化；匿名统计只作审计，不直接“+5 分”。
- **照片 → 记忆**：模型视觉描述标成“不确定”，按照主人/好友私密访问 ACL 保存可衰减观察，而不是保存照片原图；陌生人和敏感内容不形成私人长期事件。单次看图不等于形成稳定兴趣或人格变化。
- 需要跨日真实故事回放：某次兴趣/记忆如何被核验、后续模型是否读取、做何决定、执行回执如何、是否新形成独立成长证据；缺任何环节不能报告“因果闭环已验证”。

## 5. 安全、隐私及数据治理

| 门槛 | 当前状况 | 风险与未完成验收 |
| --- | --- | --- |
| 账号与目标绑定 | 原有 `accountBinding`、Life 证明及专业写入门禁保留 | Windows 实机切号/撤权竞态、网络未知结果回放需测 |
| 平台回执与防重 | 独立气泡消息 ID 与单次 Proof，未知结果冻结 | 多气泡平台回执与重启恢复的真实 B站验证缺失 |
| 图片 SSRF/类型 | 只允许 `https://iN.hdslb.com/bfs/...`，禁重定向、无 Cookie、限制体积及文件魔数 | 真实 CDN 图片、多图场景与视觉模型不可用时回退需测 |
| 私信隐私 | 管理中心最近会话不把正文插入 DOM；账号隔离；图片私密内容只读 | 日志接口仍可访问原始信息，展示遮罩不等于 API 加密 |
| 记忆最小化 | 近期上下文是受限条数和时间；只存已审核私密低敏感事件 | 长期回忆准确率、亲密关系与私密遗忘策略不能仅用模拟证明 |
| 性格与兴趣 | 证据账本与反思分离，成长看板不直接加权 | 缺跨日真实前后对照，不能宣传“人格成长已经被行为证实” |
| 安全测试 | 核心回归保留不可绕过的回执与身份测试 | `full` 仍存在历史和有效断言失败，正式发布阻断 |

## 7. 审计优先级

- **P0：** 真实平台送达身份/回执、防重复、撤权、账号切换、跨场景授权的未完成全量测试；任何一次重复外发或私密串号立即禁止正式版。
- **P1：** DNS/HTTP `-509`/模型超时导致的体验间歇失败；P6 真实发送量与模型自主选择区分；长期记忆跨日正确率。
- **P2：** Life 输入成本、重复观察与探索收益、UI 状态可解释性；只归档确证过时的旧版本快照，不删生产安全测试。
