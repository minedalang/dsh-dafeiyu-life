# dev.16 私信片段 AI 经历提炼

**输入**：已核验、按账号和 UID 隔离的双向私信；只有平台确认的发言回执可作为鱼鱼的外发事实。陌生人及非可信消息不进入私密关系记忆。

**临时处理**：本地先收集所有合法文本，而非用关键词猜测重要性。每个缓冲片段采用原顺序与去重消息指纹，原文临时保存在 `life-memory/private-conversation-buffer.json`（文件权限 0600，不属于普通数据备份目录白名单），最长保留 48 小时。错误退避，拒绝在后台日志和接口泄露文本。

**触发**：20 分钟无新消息、原会话模型明确选择 `close` 或回复时将话题标为 `settled`，或片段达到 14 条消息／6500 字；每 60 秒最多对一段片段尝试 AI 提炼。单段最多返回两条有源证据 ID 的短摘要。空结果代表正常无记忆价值；无效或模型错误不能等同空结果。

**模型与成本**：如果已经启用独立记忆检索模型，可用它作批量整理；否则复用互动模型。额外调用发生在成段而非每条消息；不改变现有反思模型或每日模型额度规则。深度反思仍由原独立反思调度器完成。

**产出**：仅摘要经私密内容安全检查和证据归属核验后进入原 `private-social` 可衰减经历 → 原 Life Reflection 候选 → 受限 privateInsights。原始聊天不直接生成长期事实，不因此授予公开引用或发言权限。

**失败边界**：成功清空短期原文；失败保留并重试；超过 48 小时按隐私原则丢弃并上报聚合计数。历史未保存的对话不主动重抓，不能声称可补录。存储容量及多进程竞争是可观测的技术限制，不覆盖其他授权层。

**上传源码适配说明**：普通私信在每条平台确认气泡之后记录临时经历，但不回退 `postSendStage` 与 P6 状态。主人私信在已确认回复后也尊重原模型 `settled` 状态，避免仅靠安静期才归纳。旧版补丁与本版不能叠加。
