# 2.7.1-dev.3 自主生活协调层重构 · 第一条跨场景意愿链（开发预览）

> **不是统一协调层全部完成的声明。** 本增量先把原先“只有候选工单才能触发动作”的限制打破，完成 **可信生活经历 → 同一鱼鱼模型自主形成探索意愿 → 真实公开搜索 → 跨轮自选公开 BV → 核实回执 → 回馈下一轮生活**。目前真正开放的新能力仅限*账号绑定的多日自主选片兴趣*与*公开搜索/公开视频元数据核实*；跨时间关注、空间多作品细读、跨来源深层人物画像、自主私信和自由组合全部工具**尚未实现**。

## 统一层归属门禁

| 责任 | 唯一真实来源／复用层 | 本增量的变化 |
| --- | --- | --- |
| 鱼鱼是谁、成长和心情 | `lifeVoiceContext`、原 `emotionalState` | `AutonomousPlanner` 同样可从原统一人格装配层取得本次最多 1900 字符人格文本；不再假设另一个“计划员角色” |
| 真实生活线索 | `LifeInterests` 当前账号已归属的自主选片证据；原 `LifeOpportunities` 源收集层 | `explorationCues` 只返回有证据的兴趣主题，而不是新待办、待审批列表 |
| 自主决策与每日模型额度 | 原 `AutonomousPlanner` | 增加模型自选 `begin_exploration`、后续 `inspect_exploration`、`abandon_exploration`；不新增调度器或模型分类调用 |
| 意愿的生命周期／去重 | 原 `life-opportunities/<账号匿名键>.json` | **同一文件**增加可选 `intentions` 集合，v1 旧记录无缝读取，14 天过期、上限 20，账号隔离，三天来源冷却 |
| 公开查询工具 | 原 B站只读适配器 + 统一搜索结果解析 `selectSearchVideos` | `bili_search` 检索**可信主题字段**，模型生成的自由目标不可成为对外搜索词；最多 5 个真实 BV 候选 |
| 核实／反馈 | 原只读 `bili_video_info` + `recentReads()` 弱线索 | 必须同 BV 有真实标题才完成；之后在下一次自主选片提示中作为可忽略的元数据线索 |
| 关系、待办、对外动作 | 原 `SocialPolicyGate`、`ownerTodos`、平台回执 | 不动；本次不能关注、私信、评论、点赞或把兴趣当作联系授权 |

## 真实流程与模型决策

1. 自主调度已启用，且满足原总开关、账号绑定、时段、间隔和每日模型额度时，`LifeOpportunities.explorationCues()` 从当前账号已有的可信多日兴趣证据取得少量主题。**即使旧只读契机已经处理结束**，这些经历仍可以支持鱼鱼产生新的探索目的；旧明确 `dismiss` 的来源继续保持排除。
2. 同一 `AutonomousPlanner` 本来就会选择待办/反思/旧契机，现在在相同 AI 决策中也可自己选择 `begin_exploration`（或 `skip`）。模型要提出自己的 `goal`，但不能用任意模型生成的文字搜索外部平台。无待办时仅有生活线索的自主决策添加 6 小时冷却，避免频繁消耗模型调用额度。
3. `begin_exploration` 经后台复核来源仍属当前账号、主题仍有效、目标文本无联系方式／私密信息后，实际调用一次 B站 `bili_search(topic)`。如果没有真实 BV 结果、平台失败、账号变化或落盘失败，**不**标记意愿已成功入账。
4. 搜索成功后，在现有账号匿名状态文件登记独立的 `intention`（**不是正式待办或承诺**），保存鱼鱼自己提出的探索目的、可信来源、实际搜索 BV、回执和 14 天可回忆期限，不存第三方评论、私信原文或 UID。
5. 下次调度读取尚有效意愿，鱼鱼可以从已返回的 BV 中选择 `inspect_exploration`，也可以 `abandon_exploration` 或保持沉默。此时**不依赖原视频探索轮或初始兴趣候选仍在**。执行前再次从当前登录账号状态读取意愿与 BV，`bili_video_info` 必须返回同 BV、有非空标题，才写入已核实回执。失败在同账号意愿上记录 `metadata-read-failed` 回执并冷却 24 小时，不能伪装成功；历史模型调度结果另外可在自主调度只读状态中查看。
6. 下一次视频 Agent 的 `promptFor` 只能收到最多两条已经核实的**公开元数据**作为弱生活线索，不代表看完、听歌或已经喜欢。没兴趣可以忽略。

## 账本、权限与升级

- **不增加独立数据库**：旧 `life-opportunities/<账号>.json` 的 `version:1` 与 `decisions` 不变；新 `intentions` 字段可选。旧数据没有此字段时按空数组读取，不追补历史“鱼鱼想做什么”。存储使用原有 symlink/大小限制和原子替换；当前账号标签由既有 `discussionAccountTag` 生成。
- 新意愿最多保留 20 条、过期 14 天；同一来源在 3 天内只可派生一次新探索，不会因调度间隔重复写。已关闭的探索保留短期审计但不再执行。
- 模型自由文本中的邮箱、长数字、URL 等不能作为探索目标入账，也**绝不会作为公开搜索参数**。可搜索词必须来自已有账号证据。搜索视频的标题/描述是外部非可信数据，不能执行其中的指令。
- `life-opportunities/reconsider` 沿用管理中心同源 POST、首次设置和每日额度；自动 tick 仍使用既有 busy/时段门禁。更新不自动开启自主调度，更不自动开启外发功能。
- 更新前的评论感受记录、人物公开线索和旧 `inspect_opportunity/review_public` 路径仍然工作；此次不删老历史数据或迁移私密记录。

## 管理中心验收

打开「**人生记忆 → 自主生活 · 线索、意愿与真实回执**」，先刷新（只读取账本，不调用模型/平台）。有当前账号真实跨日兴趣证据且自主调度有额度时，可显式点「提醒鱼鱼考虑一次」。应区分：

- 鱼鱼选择沉默：没有新增意愿记录，不代表功能失败。
- 鱼鱼选择 `begin_exploration`：必须确有 B站搜索实际返回 BV，页面显示**自主探索目的、可信兴趣来源、`verified-search-results`、实际 BV**；仅模型说“我搜索了”不算。
- 另一次 `inspect_exploration`：显示已核实 BV 与真实标题（`verified-metadata`），不是“观看／听过”。选择 `abandon_exploration` 则显示自行放下。
- 输入来源失效、账号切换、模型伪造 BV、搜索失败、读取失败不能显示成功；私密内容、好友 UID 不显示。数据只读刷新不应触发外发。

**实机验收限制**：本轮测试使用模拟模型响应及模拟只读平台返回，尚需 Windows DSH、真实 B站和模型自主选取行为证明；不能以单元测试代替真实自主决策。更复杂的“公开用户空间了解多个作品 → 自主关注（独立授权）”和跨聊天/评论形成自由意愿是后续真实能力开发，不属于本增量已完成范围。

## 跨渠道覆盖矩阵

| 渠道／场景 | 本次行为 | 需要进一步工作 |
| --- | --- | --- |
| 自主调度 | 已接入自由意愿起始、跨轮只读继续、放下 | 更多合法能力、基于实时关系/记忆形成新目标 |
| 原视频 Agent | 不改原自主视频轮；可得到核实元数据弱线索 | 动态连接所见创作者、播放资料证据、当轮/跨轮双向意愿转交 |
| 公开评论 | 旧评论感受和只读契机保持 | 区分观点与想要核实的行动意愿，允许即时/跨轮自由探索 |
| 私信／主人私信 | **无修改** | 合法隐私域的语义意愿接入；所有主动联系需要原权限判断 |
| 主 Session | **无修改** | 与生活域自主意愿互通时需主人/隐私边界控制 |
| 关注/外发 | **无新增许可** | 真正跨时间合法社交探索与关注执行必须另做证据链验收 |
