# 2.7.1-dev.3 自主生活协调层重构 · 第一条跨场景意愿链（开发预览）

> **不是统一协调层全部完成的声明。** 本增量先把原先“只有候选工单才能触发动作”的限制打破，完成 **可信生活经历 → 同一鱼鱼模型自主形成探索意愿 → 真实公开搜索 → 跨轮自选公开 BV → 核实回执 → 回馈下一轮生活**。当前接入*账号绑定的多日自主选片兴趣*和*同 BV 真实评论阅读后的自主好奇/存疑*；可执行公开搜索、视频元数据核实，以及基于真实 BV 核实作者身份后的公开投稿列表读取与进一步选 BV 核实。**跨时间关注、私信、私人共同经历自主读取、全部工具自由组合仍未实现**。


## 本轮补充：评论起点与跨能力公开探索（同一 dev.3）

- `LifeOpportunities.explorationCues` 同时可提供有真实非空评论阅读回执、鱼鱼随后自主保存 `curious/skeptical` 且附明确疑问的**评论来源**。它只是可选的经历线索；没有疑问的 `amused/neutral` 不会强行触发新探索。仍由同一 Life Voice 模型选择 `begin_exploration`，也可以沉默。
- 评论来源的 `begin_exploration` **只会重新核实原 BV 的公开元数据**，不会把评论文本或模型编写的疑问转成对外搜索词；成功核实同 BV 才写入 `verified-metadata` 的短期自主意愿。兴趣来源依旧使用已验证公开主题执行现有搜索流程。
- 对已有真实核实的 BV，模型可在以后自主轮选择 `inspect_creator_space`，由 `bili_creator_relation_status` 取得**同 BV、当前账号**可核验的作者 UID，然后只以该身份调用 `bili_user_videos`。返回 UID 与请求对象必须一致，保存最多五条实际公开 BV。模型提交的任何 UID 均不参与平台调用；这个执行适配器不接收外发写操作。
- 查看作者投稿之后，同一意愿仍能通过 `inspect_exploration` 选择真实返回的另一条 BV，由 `bili_video_info` 核实后才关闭这一轮探索。平台查询失败记 `creator-read-failed`，冷却一天；作者／账号／BV 对不上，拒绝保存成功回执。未发生新观察、不感兴趣时可自行选择放下。
- 这些行为沿用**一个** `AutonomousPlanner`、一个账号匿名 `life-opportunities` 状态文件、一份每日模型额度，不新造待办或人物档案。跨异步工具往返写入前比较账号作用域；提示词和管理中心不包含作者 UID、私信原文或任何外发授权。三步只读并不表示真的浏览完作品、理解画面或决定关注。

**实机验收：** 管理中心「人生记忆 → 自主生活 · 线索、意愿与真实回执」能查看评论来源自主意愿、核实的原 BV、真实公开作者投稿 BV、后续选择与失败回执；需在真实登录 B站、实际模型自主选择、跨轮重启下进一步验证。尚未把私密聊天或共同经历直接转成公开检索素材，也不支持自动关注或主动私信。

## 统一层归属门禁

| 责任 | 唯一真实来源／复用层 | 本增量的变化 |
| --- | --- | --- |
| 鱼鱼是谁、成长和心情 | `lifeVoiceContext`、原 `emotionalState` | `AutonomousPlanner` 同样可从原统一人格装配层取得本次最多 1900 字符人格文本；不再假设另一个“计划员角色” |
| 真实生活线索 | `LifeInterests` 当前账号已归属的自主选片证据；原 `LifeOpportunities` 源收集层 | `explorationCues` 提供账号属实的兴趣与评论主观疑问；只是线索，不是待办或审批单 |
| 自主决策与每日模型额度 | 原 `AutonomousPlanner` | 模型自选 `begin_exploration`、`inspect_exploration`、`inspect_creator_space`、`abandon_exploration`；不新增调度器或分类模型 |
| 意愿的生命周期／去重 | 原 `life-opportunities/<账号匿名键>.json` | **同一文件**增加可选 `intentions` 集合，v1 旧记录无缝读取，14 天过期、上限 20，账号隔离，三天来源冷却 |
| 公开查询工具 | 原 B站只读适配器 + 统一搜索结果解析 `selectSearchVideos` | `bili_search` 只检索可信兴趣主题；评论只核实同 BV；进一步探索使用 `bili_creator_relation_status` 与 `bili_user_videos` 读取公开作品；模型自由目标不能成为对外搜索参数 |
| 核实／反馈 | 原只读 `bili_video_info` + `recentReads()` 弱线索 | 必须同 BV 有真实标题、同账号有作者身份与同作者作品列表，才可跨步继续；核实元数据仍只是下一次自主选片的弱线索 |
| 关系、待办、对外动作 | 原 `SocialPolicyGate`、`ownerTodos`、平台回执 | 不动；本次不能关注、私信、评论、点赞或把兴趣当作联系授权 |

## 真实流程与模型决策

1. 自主调度已启用，且满足原总开关、账号绑定、时段、间隔和每日模型额度时，`LifeOpportunities.explorationCues()` 从可信多日兴趣或同 BV 真实评论观察后的自主疑问获得少量线索。**即使旧只读契机已经处理结束**，这些经历仍可以支持鱼鱼产生新的探索目的；旧明确 `dismiss` 的来源继续保持排除。
2. 同一 `AutonomousPlanner` 本来就会选择待办/反思/旧契机，现在在相同 AI 决策中也可自己选择 `begin_exploration`（或 `skip`）。模型要提出自己的 `goal`，但不能用任意模型生成的文字搜索外部平台。无待办时仅有生活线索的自主决策添加 6 小时冷却，避免频繁消耗模型调用额度。
3. `begin_exploration` 经后台复核来源仍属当前账号、主题仍有效、目标文本无联系方式／私密信息后，对兴趣来源调用一次 B站 `bili_search(topic)`，对评论来源只调用 `bili_video_info(原BV)`。如果没有真实结果、平台失败、账号变化或落盘失败，**不**标记意愿已成功入账。
4. 搜索成功后，在现有账号匿名状态文件登记独立的 `intention`（**不是正式待办或承诺**），保存鱼鱼自己提出的探索目的、可信来源、实际搜索 BV、回执和 14 天可回忆期限，不存第三方评论、私信原文或 UID。
5. 下次调度读取尚有效意愿，鱼鱼可以从已返回的 BV 中选择 `inspect_exploration`，核实视频后也可以选择 `inspect_creator_space` 查看对应 UP 主的公开投稿，再挑另一部作品核实；也可以 `abandon_exploration` 或保持沉默。此时**不依赖原视频探索轮或初始兴趣候选仍在**。执行前再次从当前登录账号状态读取意愿与 BV，`bili_video_info` 必须返回同 BV、有非空标题，才写入已核实回执。失败在同账号意愿上记录 `metadata-read-failed` 回执并冷却 24 小时，不能伪装成功；历史模型调度结果另外可在自主调度只读状态中查看。
6. 下一次视频 Agent 的 `promptFor` 只能收到最多两条已经核实的**公开元数据**作为弱生活线索，不代表看完、听歌或已经喜欢。没兴趣可以忽略。

## 账本、权限与升级

- **不增加独立数据库**：旧 `life-opportunities/<账号>.json` 的 `version:1` 与 `decisions` 不变；新 `intentions` 字段可选。旧数据没有此字段时按空数组读取，不追补历史“鱼鱼想做什么”。存储使用原有 symlink/大小限制和原子替换；当前账号标签由既有 `discussionAccountTag` 生成。
- 新意愿最多保留 20 条、过期 14 天；同一来源在 3 天内只可派生一次新探索，不会因调度间隔重复写。已关闭的探索保留短期审计但不再执行。
- 模型自由文本中的邮箱、长数字、URL 等不能作为探索目标入账，也**绝不会作为公开搜索参数**。可搜索词必须来自已有账号证据。搜索视频的标题/描述是外部非可信数据，不能执行其中的指令。
- `life-opportunities/reconsider` 沿用管理中心同源 POST、首次设置和每日额度；自动 tick 仍使用既有 busy/时段门禁。更新不自动开启自主调度，更不自动开启外发功能。
- 更新前的评论感受记录、人物公开线索和旧 `inspect_opportunity/review_public` 路径仍然工作；此次不删老历史数据或迁移私密记录。

## 管理中心验收

打开「**人生记忆 → 自主生活 · 线索、意愿与真实回执**」，先刷新（只读取账本，不调用模型/平台）。有当前账号真实跨日兴趣证据或有真实评论阅读并自愿保存疑问，且自主调度有额度时，可显式点「提醒鱼鱼考虑一次」。应区分：

- 鱼鱼选择沉默：没有新增意愿记录，不代表功能失败。
- 鱼鱼选择 `begin_exploration`：兴趣来源必须有 B站搜索实际返回 BV（`verified-search-results`）；评论来源必须有同 BV 元数据核实（`verified-metadata`）。页面显示目的、来源和真实 BV；仅模型说“我搜索了”不算。
- 另一次 `inspect_exploration`：显示已核实 BV 与真实标题（`verified-metadata`），不是“观看／听过”。选择 `abandon_exploration` 则显示自行放下。
- 输入来源失效、账号切换、模型伪造 BV、搜索失败、读取失败不能显示成功；私密内容、好友 UID 不显示。数据只读刷新不应触发外发。

**实机验收限制**：本轮测试使用模拟模型响应及模拟只读平台返回，尚需 Windows DSH、真实 B站和模型自主选取行为证明；不能以单元测试代替真实自主决策。已接入“原 BV → 公开作者投稿列表 → 自选另一 BV 元数据核实”的只读链；真正观看／理解其他作品、跨日自主关注（独立授权）、从私信/共同经历产生私人意愿仍需要后续开发，不属于此增量。

## 跨渠道覆盖矩阵

| 渠道／场景 | 本次行为 | 需要进一步工作 |
| --- | --- | --- |
| 自主调度 | 可选评论或兴趣来源，跨轮核实视频、公开作者投稿与其他 BV、放下 | 更多可组合的授权能力、实时关系/记忆形成的新目标 |
| 原视频 Agent | 不改原自主视频轮；可得到核实元数据弱线索 | 动态连接所见创作者、播放资料证据、当轮/跨轮双向意愿转交 |
| 公开评论 | 同 BV 真实评论阅读且已保存好奇/存疑，可自主发起原视频只读探索 | 更丰富的公开话题理解和即时/跨轮语义意愿 |
| 私信／主人私信 | **无修改** | 合法隐私域的语义意愿接入；所有主动联系需要原权限判断 |
| 主 Session | **无修改** | 与生活域自主意愿互通时需主人/隐私边界控制 |
| 关注/外发 | **无新增许可** | 真正跨时间合法社交探索与关注执行必须另做证据链验收 |
