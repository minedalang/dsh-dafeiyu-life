# 2.7.1 · RC 准入前十三项自然行为审计（基线 `2.7.1-dev.7`）

> **结论：暂不准入 RC，`releaseReady:false`。** 本页审查的是交付的 dev.7 源码，不代表已在用户的 Windows/DSH/B站账户真实运行。状态分为「部分具备」「尚无长期因果证明」「需使用者走查」；**没有一项因为存在模型 Prompt 或服务模块就视为完全验收**。本轮文档／UI 小修复不改变生产 Life 社交所有权、不新增平台写权限、不删除用户历史数据。对应[当前与目标图](./diagrams/2.7.1-rc-preflight-boundaries.mmd)。

## RC 必须阻断的问题（优先级及验收证据）

**P0 · 发布前必修：**

1. **社交真正单 owner。** `socialDecisionOwnership.route()` 现在只接受 `legacy`；`consider_social` 只读。应让统一 Life 决定 `ignore/defer/reply`，并由原渠道执行器遵守已有权限、已核验 UID、跨进程发送事务、回复边界；先 DM、再评论/@，再盘点主人专属回复、回访、兴趣分享和 Python 外发。每渠道必须先排空再切换；未知发送必须人工核实，不能重发。
2. **可信成长因果。** 对兴趣、记忆、人格、关系各拿至少一条真实执行回执、对应的当前可回忆证据和**之后不同日期的实际选择**，而非仅有模型反事实或特质计数。社交投影与反思必须可遗忘、可纠错、可撤回。
3. **生产环境。** Windows `run-tests.bat`，真实 DSH 模型调用和受控 B站权限验证；两账号切换、停止/撤权、未知发送、恢复/回滚、静默时段以及至少 72 小时连续运行。**7 天扩展观察建议作为实际自然节律验证证据**。必须由有实际平台许可的维护者/用户操作。
4. **不误导的功能开关。** `lifeAgentMode='active'` 目前不是“接管一切社交”；不可因开启 Life 自动启用任何外发。README、管理中心和新 RC 页面明确这一事实。

**P1 · 体验验收（RC 前做，必要时阻断发布说明）：**

- 主人自然关怀：决定是否恢复 `emotionRecall.paused` 的一部分功能，先明确定义沉默、安静时段、可撤回授权与接收人场景，不能直接将 `paused` 改成 `false`。
- 普通社交自然度：为私信/评论建立真实事件→选择→等待→发送结果与对方反应的**匿名统计**，评估打扰率、重复频率、疲劳时休息和停联；无需长期保存私信原文。
- UI/README：首次配置和权限是否直观由真实使用者走查；专家功能仍折叠，不为普通用户添加高级开关。

| 门禁 | 最低要求 | 当前 |

| 兴趣/关系/人格成长 | 跨日至少一条完整、可遗忘且可反证的因果链，实际决策出现可解释差异 | **未达成** |

## 验收操作建议（真实操作不应由离线沙盒替代）

1. **先备份与只读检查。** 备份 `$DSH_HOME/bili-duty/`，在「🌿 鱼鱼的自主生活 → 开发者：系统迁移与验收诊断」读取十三项结论；查看旧社交排空／发送未知结果。所有未核验记录停止重试。
2. **只读场景。** 用真实账号和模型、在许可的公开视频上触发兴趣探索、提议接受/延期和生命记忆召回，分别记录原业务回执、Life 决策和反思证据。不要把模拟或内容元数据当作视频体验。
3. **受控社交场景。** 仅在用户独立批准目标与范围后测试真实私信、评论/@；验证低频、拒绝联系、停止生活、关权限、重复事件、网络中断、未知结果和账号切换。自动私信不是默认权限。
4. **跨日回归。** 连续 72 小时并尽量扩展至 7 天；记录匿名化的候选/决定/实际动作/回执及后续选择，再按第 8、9 项逐证据链核对。没有足够样本时只能写「未证实」。
5. **发布核查。** 所有 P0 都有代码和实机证据后，再申请升级至 `2.7.1-rc.1`；在此之前保持 `2.7.1-dev.7`，不创建 RC Tag、不向 npm 发布。

**不能通过的推理**：提示词含有「好奇」≠主动探索；可查询人格状态≠长期人格成长；有发送冷却≠自然聊天；知道一个 UID ≠允许联系；模型建议回复≠已经回复；视频进程退出 ≠已观看音画。历史被截断的评论及已经遗忘的内容不可凭本轮日志恢复。
