# 2.7.1-dev.40 同版本维护修复 · Life 管理页清理旧开发选项

## 目标

普通使用者进入「Life 自主生活」时，只看到真实生活设置、真实运行状态和确实可用的操作，不再需要穿过旧的开发者折叠区，也不会把模拟演示、影子对照或迁移演练误认为日常功能。

## UI 调整

- 删除 Life 页两层「开发者诊断／旧配置」折叠区及其中的旧配置预览、影子对照、模型输出对比、旧匿名调度时间线和开发状态项。
- 删除 Life 设置区内的迁移验收清单、私信／评论交接演练入口、离线假 Agent 演示入口。
- 移除可见的影子观察模式选择；保留隐藏的历史 `shadow` 值，仅用于兼容已经保存的旧配置，不再作为普通用户可选模式。
- 保留「真实运行状态」、零模型调用状态刷新和「手动触发一轮真实视频 Agent」。原站内二次确认、原 API、原视频 Agent 能力委派、账号／Life／首页推荐／忙碌／冷却／额度门禁不变。
- 将 `commentPublicProfileReadEnabled` 只读权限从旧开发区移至「最近评论 → 后台评论互动设置」。仍默认关闭；首次开启必须使用原服务端确认令牌；只允许读取当前已核验评论者的公开投稿标题与 BV，不授予关注、私信或跨评论串回复权限。
- 回访设置按钮改名为「保存回访设置」；待办回访的手动重新考虑入口改用普通用户措辞，保留原二次确认和门禁，不再把正常操作标成 DEBUG。

## 保留与兼容

- 本轮只清理管理 UI，不更改 Life Planner、Episode、权限账本、平台执行器或记忆系统，**架构接线未变**。
- 历史配置字段、只读迁移审计 API、交接演练 API、离线模拟 API 和模型对照实现暂时保留，供旧配置兼容与自动化回归使用；它们不再作为普通 Life 管理页选项展示。没有重置用户配置或扩大任何读取／写入权限。
- 完整决策步骤仍在「运行诊断 → 鱼鱼的决策全过程」查看；真实生活时间线仍在「大肥鱼的一天」查看。

## 验证边界

- 新增 UI 回归，检查旧开发者控件不再渲染、真实视频 Agent 手动入口仍连接原 API，以及评论者公开投稿授权已移动到评论设置并继续受服务端确认保护。
- 这轮不构成 Windows Desktop 或真实 B站实机验收。`releaseReady:false`；不合并主干、不创建 Tag、不正式发布。
