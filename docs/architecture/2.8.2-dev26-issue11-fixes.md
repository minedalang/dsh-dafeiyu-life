# 2.8.2-dev.26 · Issue #11 安装与 Life 状态可靠性修复

## 范围

本批以用户上传的 `2.8.2-dev.25` 源码为基线，只处理 Issue #11 的三类反馈：

1. faster-whisper 依赖安装慢、缺少可见项目/安装包入口；
2. 快速设置保存触发 `limit is not defined`；
3. Life 决策次数读取被 `Life Episode account scope unavailable` 连带阻断。

本批不实施多候选自主视频探索，不改变 2.8.2 视频感知策略。

## 统一层归属检查

| 项目 | 主体与事实源 | 账号/权限边界 | 失败与恢复 |
|---|---|---|---|
| 本地 ASR 安装 | 用户明确点击的现有安装器；PyPI 包和 Hugging Face 模型是两个独立下载阶段 | 仅本机同源安装路由；不自动开启转写、不触发视频观看 | 网络无进展时终止当前安装进程并切换 HTTPS 镜像；模型下载失败仍显示未就绪 |
| 分享快速保存 | 现有 quick setup / social config 方案 | 不新增每日硬上限，不增加发送许可 | 只校验 `paused` / `autonomous` 方案值，沿用预览、确认、保存与回读 |
| Life 决策状态 | `autonomousPlanner.status()` 是决策计数与心跳事实源；Episode 是可选账号作用域诊断 | Episode 只有当前账号 tag 合法且账号未阻断时才可读取；原 `scope()` 严格校验保持不变 | Episode 不可读时只降级附加诊断，核心调度状态仍返回；不读旧账号文件 |

## 实现

- 新增 `lib/asr-install.mjs`：构建 HTTPS 镜像列表并执行有界的 uv/pip 安装尝试。uv 超时不再在同一镜像上重复等待 pip，而是直接进入下一个镜像；普通 uv 错误仍保留 pip 备用入口。
- `spawnTo()` 增加可选无输出与总时限；仅 ASR 包安装和模型下载传入超时，不改变其他安装调用。
- ASR 包安装中 uv 使用官方支持的 `UV_HTTP_TIMEOUT=20`、`UV_HTTP_CONNECT_TIMEOUT=10`、`UV_HTTP_RETRIES=1`；pip 使用20秒网络超时和1次重试。两者均使用180秒无输出超时和15分钟单进程总时限；模型权重下载使用10分钟无输出和90分钟总时限。
- 管理中心在首次设置和 AI 模型页展示 faster-whisper 官方 GitHub、PyPI 包与 Systran 模型权重入口，并解释依赖与模型是两个阶段。
- 新增 `lib/life-planner-status.mjs`，将核心调度状态之外的 Episode/社交附加诊断逐项隔离。无合法账号作用域时不调用 Episode `list()` / `health()`；存储异常不会再让整个调度 API 返回500。
- 管理中心明确区分“调度次数可用”和“Episode 附加诊断暂不可读”。

## 数据与架构兼容

- 不修改 Episode JSON schema、哈希方式、账号 tag 来源或 `scope()`。
- 不增加第二套调度器、额度账本、账号状态或外发授权。
- 不修改社交发送事务、分享实际执行门禁或平台回执。
- 无需数据迁移；没有写入旧账号 Episode，也不恢复旧数据。
- **架构接线未变**：仅改善现有管理状态接口的可选诊断组合方式。

## 验收

新增 `test/issue11-fixes.test.mjs` 覆盖：
- 自主分享保存不再引用未定义 `limit`；
- faster-whisper/PyPI/模型入口可见；
- 镜像 HTTPS 校验与去重；
- uv 镜像无进展后跳过当前镜像并切换；
- 无账号作用域时 Episode 不会被读取；
- 合法账号读取与 Episode 损坏降级；
- 调度核心状态先于可选诊断返回；
- 管理中心显示账号未就绪说明。

Windows 普通/管理员 PowerShell 全量、真实国内网络 PyPI 镜像回退、Hugging Face 模型下载和 DSH 管理中心实机仍需维护者验收。
