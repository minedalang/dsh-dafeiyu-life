# Life Memory 分域反思与隐私继承（dev.4 增量）

本文件是架构和实现边界说明，不表示所有原始聊天都会被归档或反思。README 的简图仅解释层级；[实现映射图](life-memory-private-reflection-implementation-v2.6.0-dev.4.mmd)用于审计实际调用路线。

## 数据层与来源

| 来源 | 进入条件 | 受控事实档案 | 可衰减经历 | 反思域 |
|---|---|---|---|---|
| 公开视频探索、公开评论和 @（含陌生人） | 真实 BV/通知证据、统一事件协调器 | 原有公开事件账本 | 现有 `watch/comment/social` | 公开，按原有反思门槛和权限运行 |
| 主人主 Session | 在认证选定的主 Session 中，`dafeiyu_remember` 的语义事实通过校验并成功写入 | 仅保留脱敏事件索引元数据 | `private-social`、`owner-private` | 主人私密 |
| 主人 B站私信 | 已认证主人 UID，且交流表达出明确偏好、边界、感谢或交流方式 | 不保存 DM 原话 | `private-social`、`owner-private` | 主人私密 |
| 白名单好友 B站私信 | 好友 UID 经 `friendDirectory` 确认，且内容符合安全筛选 | 不保存 DM 原话 | `private-social`、`friend-private` 与 UID | 仅该好友私密 |
| 陌生人 B站私信 | 不建立可识别个人的私密人生经历 | 无 | 无；仍可走独立的匿名安全主题线索 | 不以个人 DM 建立长期私密反思 |

**特别说明**：主 Session 一般闲聊并非逐条自动进入 Life Memory；只有成功保存、有足够依据的长期语义事实触发本次私密经历接线。B站私信也只有命中明确安全规则的交流能产生候选。敏感信息、凭证、联系方式等直接拒绝，不能通过重述绕开。私密经历的存档文件只包含来源键、匿名化主体哈希、时间与权限，不包含 DM 正文或私密证据摘要；摘要仅在受限可衰减副本中出现。

## 统一协调与反思

1. `LifePrivatePolicy` 根据经过认证的来源角色，确定 `owner-private` 或 `friend-private`，生成有限且无直接引用的交流经验摘要；陌生人 DM 不进入个人经历。
2. 主 Session 通过现有长期语义记忆工具的成功回执；主人私信通过受限 OwnerDM Agent；普通好友私信通过原有 SocialInteractionCoordinator。这些路径最终汇入 **LifeMemoryCoordinator**，复用逐 sink 幂等与重启补偿。
3. `LifeMemoryGateway` 保存受控归档元数据和独立可衰减经历。清晰、模糊、痕迹、遗忘沿用原有生命周期；永久档案无模型读取接口。
4. `LifeReflection` 仍是唯一反思候选调度器。公开、主人私密与每位好友私密按来源域分组，**一次模型调用绝不混入另一域或另一位好友**；证据只从当前未遗忘的副本取得。
5. 公开反思沿用现有长期记忆/人格/情绪的校验出口。**私密反思不写入全局身份级长期认识或公共情绪投影**，私密领悟仍只写入受限的 `life-memory/private-insights.json`；但可在主人明确开启成长人格时，将确定性筛选、严格校验的低敏经历转为少量匿名特质方向证据。已遗忘或已撤回的证据不能被 AI 重新构造。
6. 私密见解由 `MemoryRetriever`（主人主 Session）或 `SocialContextAssembler`（认证主人 DM、同 UID 好友 DM）按使用场景读取；公开评论、动态、陌生人和其他好友都不可读取。

## 访问控制矩阵

| 读取位置 | 公开视频/公开认识 | 主人私有经历与认识 | 特定好友的私有经历与认识 |
|---|---|---|---|
| 主人主 Session | 允许 | 允许 | 默认不允许 |
| 已认证主人 B站私信 | 允许的公开视图 | 允许 | 默认不允许 |
| 已认证好友本人 B站私信 | 允许的公开视图 | 不允许 | 仅该 UID 允许 |
| 陌生人 B站私信 | 已公开许可的安全视图 | 不允许 | 不允许 |
| 公开视频评论/动态 | 允许 | **不允许** | **不允许** |
| 永久事实档案 | 仅管理端明确备份/审计 | 运行时不允许回读 | 运行时不允许回读 |

`SocialPolicyGate` 根据实际认证的 UID 判断角色；不能从昵称、对话内容或模型生成的“我是主人”重新推断权限。私密反思继承源事件的可见域，**不能自动将私密总结降级成公开认识**。私密认识也不能自动授权任何 B站外发动作。

## 数据恢复边界

- 普通业务便携备份剔除私密 `private-social` 事件、私密反思候选、`private-insights.json` 和私密 outbox 事件；恢复不会因此恢复已遗忘的私人详情。
- 在本机恢复普通备份时保留原有未遗忘的私密经历和待补偿的私密事件，不从永久档案回填已衰减细节。
- 明确授权的独立人生记忆备份可以包含私密数据，必须按敏感资料妥善保管，**不可公开上传**。
- 本次不新增单独的管理端「按 UID 彻底清除所有派生记录」入口。管理员删除、好友撤销信任与完整数据擦除需要单独验收与后续实现；目前撤销好友身份会即时阻止其私密记忆被 DM 读取。
- 仅在成长人格已主动开启时，允许私密经历对抽象人格提供**低权重匿名证据**：明确要求减少联系可形成“学习尊重边界”证据；明确希望轻松交流可形成“学习调整交流节奏”证据。不是鱼鱼已执行相应行为的证明；不允许据此形成更愿意结交陌生人的结论。
- 私密模型输出不得包含任何对方原话、UID 或个人细节；本地只采纳白名单特质、固定摘要类别、正向方向和最低置信度合格的候选。特质形成稳定趋势仍须多次、跨日期且有独立主体支持；同一位好友反复陈述也不足以形成公开稳定人格；公开提示词只拿到抽象特质短句，不带证据描述、来源与主体。普通便携备份剔除私密人格证据；完整记忆备份才保留。

## 质量与测试

相关测试在 `test/dev4-life-private-reflection.test.mjs` 和 `test/dev4-life-private-backup.test.mjs`。覆盖来自不同 UID 的隔离、陌生私信过滤、原始 DM 文本不落盘、私密反思不写入公开长期记忆、外发作用域隔离、outbox 失败重试、普通备份脱敏与恢复。

真实 DSH Desktop、B站收件箱并发及文件系统强制断电下的行为仍需要部署验收。文件模块的存在和单元测试通过，不等价于已经在用户真实会话中观察到反思模型的执行。

## 人格候选与反思故障诊断（dev.4 追加）

- 在成长人格已开启、且**公开或合格的低敏私密**经历反思时，反思模型的严格 JSON 模板明确允许 `trait_proposals`。没有足够依据时可返回空数组，不能为了让面板有变化虚构证据。
- 每次反思只报告经过隐私域筛选的类型（公开／主人私有／好友私有），不在运行摘要中记录好友 UID 或私信正文。私密批次只能形成经严格校验的匿名人格倾向，无法输出具体私密认识。
- 对公开批次区分“模型提出的人格候选数”和“本地证据实际采纳数”；二者可能都为零，也可能候选被本地真实性规则拒绝。长期记忆沉淀数量与人格证据数量是**不同指标**。
- 最近技术失败由反思调度器的有界运行历史显示；即使之后手动运行成功而清掉 `lastError`，仍能看到最近一次失败原因。历史容量限制 120 批，不是无限日志。
- 修复不自动重试已遗忘经历、不放宽 UID/证据约束、不更改既有候选状态，也不增加每次日常聊天的模型调用。真实 DSH headless 失败应根据最近失败信息单独定位，不能以模拟测试通过代替实机成功。
