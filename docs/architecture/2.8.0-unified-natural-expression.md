# 2.8.0 · 统一自然表达与偶发自主续想

## 统一内容协议，不做本地假气泡

主 Session、主人私信和普通私信共享 `lib/message-burst.mjs` 中的模型表达契约。首次模型调用内部按三阶段完成：

1. **自然生成表达**：先根据真实对话、已核实经历、关系和人格选择回应内容；无需生成对外可见的推理过程。
2. **自然组织气泡**：把不同且能独立成立的语义点整理成有承接关系的 1–3 条。信息较丰富时优先 2–3 条；简短、已经结束或不想说话时仍允许一条或沉默，不必凑数。
3. **结构化返回**：由模型写出 `messages` 数组；程序不能按标点、固定长度或时间自行拆分文本。

程序仍核验发送授权、账号、正文、额度、去重及平台回执。`dafeiyu_chat_burst` 是主 Session 的真实多消息呈现工具，不是另一套意愿模型。**宿主兼容限制**：主 Session 虽由模型一次拟定多条正文，但 DSH 为了在界面中生成各条真实 assistant 消息，需要走内部 steer/followup 续步，可能产生额外模型调用；不能把它算作严格的一次模型推理或保证额外成本为零。

## 偶发续想不是每条回复都调用两次模型

`lib/natural-expression-opportunity.mjs` 提供统一的**额外模型思考机会**，不产生新的发言意愿裁决器，也不改变权限。第一轮回复可以是单条或多条；完成且确认后，少数符合资格的轮次有机会再调用一次模型，自主决定补一句或沉默。默认仅有四分之一的**合格**回复得到续想机会；这不是补发概率，沉默完全正常。

| 已核实关系阶段 | 最小额外思考冷却 |
| --- | --- |
| 主人（含主 Session） | 2 分钟 |
| 亲密朋友（经过双向持续互动建立的 `friend` 阶段） | 5 分钟 |
| 熟悉朋友（`familiar`） | 10 分钟 |
| 其他人（含仅见过几次的 `known`） | 30 分钟 |

**没有每日额外思考次数上限**。冷却在尝试第二次模型调用前持久化保留：即使模型沉默、超时，仍消耗一次机会；重启不会清零。不同账号与收件人隔离，白名单不自动等于亲密。平台本身的授权与发送额度保持独立，不能因冷却完成绕过拒联或反骚扰边界。

- **普通私信**：初次表达由模型独立组织 1–3 条；B站确认回执后，如果有余额、当前授权和冷却许可且没有新来信，可以尝试一次续想；第二次仍允许停止。
- **主人私信**：同样复用冷却与气泡协议；当前轮次若包含必须等主人回答的问题，不抢着追问；并保留原有工具操作及事实校验。
- **主 Session**：在真实非空 `assistant/message` 之后通过 DSH 内部 follow-up 请求额外一次模型思考；新主人消息会取消等待续想。当前宿主事件无法证明用户已经阅读消息，且空轮次在各 DSH 客户端中的呈现、内部续步的工具限制仍需 Windows 实机确认。在此之前不能把主 Session 对话续想视为正式安全验收完成。

同一次发言最多一次额外续想，绝不能递归生成续想。新用户来信属于独立对话轮次，不属于“自主续想”。

## 验收

1. 信息量足够时，模型能自愿输出多个独立语义气泡，不是本地机械拆句。
2. 第二次思考只在真实确认后、有权限、有冷却、概率选中且没有新消息的情况下出现，不预先猜测思考意愿。
3. 按四档关系分别冷却，未到冷却期不得调用模型；连续数日多次合法调用不受每日额外次数上限限制。
4. 模型沉默、新主人消息、撤权、账号切换、未知回执不能造成重复外发。
5. 主 Session 在 Windows DSH 中实际观察每条可见消息、空轮次的表现及取消链路；不能仅凭模拟测试宣称完成实机验收。
