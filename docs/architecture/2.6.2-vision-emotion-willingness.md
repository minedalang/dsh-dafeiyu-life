# 2.6.2 · 视觉证据、情绪状态与评论意愿排查

## 本轮确认

- `sociality` 是模拟状态评分，不是公开评论回复的概率，也不是平台权限。好友评论先由 `DualContextAgency` 判断，再由批量回复模型决定回复或 `SKIP`；陌生人/部分评论没有相同本地意愿环节。回复还受开关、评论归属、额度、冷却与发送回执限制。
- 旧情绪引擎为事件线性加分后钳制 100；相近的正面事件连续触发会把社交意愿、活力、好奇心、正向度逐步挤到上界。现在同事件按目标状态渐进更新，没有随机噪声，历史快照不重新改写；旧贴顶状态会在后续事件和时间衰减中自然回落。
- 视频 Agent：有真实字幕/转写时，按视觉问题必要性决定是否使用低清帧；没有可用字幕/转写时，在主人已开启预览识图且本轮/每日预算未用尽时优先调用一次视觉工具。超过每轮两条 BV 上限的其他候选不借文字冒充看过画面。
- 主 Session / 自主待办只读查看：独立 DSH 视觉模式能在字幕结果出来后按需自动调用；复用视频模型要求模型本身通过 MCP 接收图片帧，不把宿主侧调用当作已看图。禁用开关或无预算时不调用。

## 验收边界

- 评论是否不回复的**确切原因**仍须用户提供该条 `@/回复处理诊断` 与相关设置；只凭评论截图和 99/100 的社交意愿无法归因。
- `SKIP` 表示本轮模型未给出回复，不是情绪不足的证据；诊断现在区分本地意愿阶段和模型选择阶段，但不会编造模型未输出的理由。
- 低清图片帧与字幕只为内容证据，无法证明观看完整视频或听过音轨；模型或平台不可用时保守跳过。
- 真实账号、模型图像桥、独立视觉配额与 Windows DSH Desktop 仍须端到端实测，自动化不能替代。
