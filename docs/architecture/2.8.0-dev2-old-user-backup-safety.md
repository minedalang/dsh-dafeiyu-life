# 2.8.0-dev.2 · 老用户备份兼容与双重恢复安全审计

## 现象与根因

管理中心的「备份全部业务数据」和「单独备份完整人生记忆」都会报：
`兴趣档案备份无效：兴趣历史不合法`。

根因是 `lib/life-interests.mjs` 的正式写入路径 `stageOf()` 允许 `legacy-unverified`：旧视频选取记录没有可信账号归属时，保留只读历史，但不能据此推断鱼鱼兴趣或自主发言权限。`recordInterestEvents()` 也可能在历史 `insufficient → legacy-unverified` 时把此阶段写进成长 `history`，之后形成新证据时 `from` 可能为 `legacy-unverified`。此前 `lib/data-backup.mjs` 的 `validateBackup()` 枚举没有纳入这一阶段，导致**自身生产代码可写、同版本备份代码却拒绝**。

修复：`data-backup.mjs` 在 `history.from` 与 `history.to` 中增加已存在的 `legacy-unverified`；仍只接受显式合法阶段，绝不通过抹除历史、跳过 JSON/哈希/路径校验来绕过错误。该阶段只有只读回顾作用，**不因导出或导入变成账号专属证据或社交发送授权**。

## 两种管理页面备份与一种完整停机快照

| 入口 | 实际范围 | 能否还原全部老用户数据 | 要求 |
| --- | --- | --- | --- |
| 管理中心「备份全部业务数据」 | 允许清单内的业务 JSON 和部分 SQLite，独立保留配置，不含 Cookie、密钥与私密运行日志 | **不能**；仅便携备份 | SHA-256 与结构校验；跨鱼身份禁止覆盖；还原前生成当前备份；SQLite/文件/配置失败尝试回滚 |
| 「单独备份完整人生记忆」 | 允许清单内的记忆、兴趣、私密反思、长期认识与永久档案，不改设置／凭证 | **不能**；仅记忆域 | SHA-256、结构校验、恢复前专项快照；不复活已遗忘内容到模型上下文 |
| `tools/dev4-cold-state-backup.mjs` | **停机后整个 `$DSH_HOME/bili-duty/` 原始目录**：旧版未知文件、账号账本、凭证、数据库和记忆 | **代码支持完整文件保留**，需在实际设备核验 | 停机确认、独立目标、禁止符号链接与路径穿越、逐文件 SHA-256、原子目录替换、恢复前旧目录旁路留存、恢复后锁定外发直至同 UID 复核 |

> 完整离线快照**包含登录凭证与私密数据且不加密**。严禁发往聊天、公开工单或网盘分享；选择可靠的本机受限位置。冷快照工具属于离线命令行工具，不应在仍运行的 DSH 内启动，以免数据库写入使文件不一致。

### Windows 停机备份与还原（请先正确填写自己电脑的数据目录）

在源码根目录、安装 Node 22+ 后，先**彻底退出 DSH**，执行：

```powershell
node .\tools\dev4-cold-state-backup.mjs backup --root "D:\\DSH_HOME\\bili-duty" --to "E:\\fish-backup-20261112" --stopped
node .\tools\dev4-cold-state-backup.mjs verify --snapshot "E:\\fish-backup-20261112"
```

仅在确需恢复、已经完整停止 DSH 时：

```powershell
node .\tools\dev4-cold-state-backup.mjs restore --snapshot "E:\\fish-backup-20261112" --root "D:\\DSH_HOME\\bili-duty" --stopped --confirm RESTORE_FULL_DSH_STATE
```

上面的盘符只是占位示例，实际 `$DSH_HOME` 因用户安装方式而不同。恢复完成后，工具返回 `safeguardPath`，旧目录仍保留在旁路；DSH 会要求核实同一 UID 才能恢复外部发送。**不要误删除旁路目录或解除恢复冻结**。完整快照包含密钥，请仅在本机受控环境恢复。

## 统一层归属

`管理中心普通业务导出/导入` / `人生记忆专项导出/导入` → `lib/data-backup.mjs` 的同一结构校验 → 唯一来源 `life-memory/interests.json`（由 `lib/life-interests.mjs` 维护）。离线完整快照由 `lib/cold-state-snapshot.mjs` 处理原始目录，**不参与 Life 模型、账号关系、发送或人格事实判断**；新增的兼容字段不会打开被拒绝的外部行为。

## 离线验收

- 旧样本内含 `history: insufficient → legacy-unverified → emerging`，业务导出/导入仍逐字节保留兴趣文件。
- 人生记忆专项备份能保存并还原同一兴趣历史、长期档案与永久档案路径。
- 真正生产 `recordInterestEvents()` 生成 `legacy-unverified` 后，两个入口仍通过。
- 篡改兴趣阶段为伪造授权值，即使重算 SHA-256 也被结构验证拒绝，恢复前无业务数据写入。
- 停机冷快照可连同未知账号私密二进制文件逐字节恢复；恢复后有权限冻结文件，旧目录保留。
- 现有跨身份恢复、越界路径和防遗忘回归继续运行。

**未验证**：特定用户的真实历史数据、Windows 平台上的全部旧版本组合、B站实际授权与 72 小时连续运行。因此离线补丁不改变 `releaseReady:false`，也不能承诺历史上任意损坏或外部修改的文件都可恢复。真正恢复前务必建立并校验冷快照。
