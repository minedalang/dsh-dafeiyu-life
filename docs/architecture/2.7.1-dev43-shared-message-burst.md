# 2.7.1-dev.43 · 统一自然多气泡输出

## 目标

把原 P6-A 的自然多气泡协议抽象为公共能力，供普通 B站私信、主人 B站私信和主 Session 复用。避免每个 Agent 各自复制模型输出格式、消息归一化和发送状态机。

## 公共模块

`lib/message-burst.mjs` 提供四类能力：

1. `normalizeMessageBurst()`：统一清洗、去空、限制 1～3 条和每条长度。
2. `messageBurstInstruction()`：统一模型侧协议，明确条数是上限，不得为了凑数拆句。
3. `deliverMessageBurst()`：顺序发送、逐条 preflight、逐条确认、逐条持久化；未知发送结果不重试，本地确认写入失败立即停止后续发送。
4. `createSessionMessageBurstController()`：把同一逻辑回复的 2～3 条消息接入原主 Session。

平台适配器仍负责各自独立的账号、收件人、权限、额度、评论 root/rpid 和平台回执，不把这些平台差异塞进公共 helper。

## 复用范围

| 场景 | 公共能力 | 场景专属部分 |
|---|---|---|
| 普通 B站私信 | 统一 messages 归一化、顺序发送 helper | UID、陌生人/白名单授权、私信额度、收件箱复核、DM 回执 |
| 主人 B站私信 | 同一 messages 协议、顺序发送 helper | 主人 UID、主人 Agent 授权、每气泡 eventId 和 B站发送回执 |
| B站评论互动 | 同一 messages 归一化 | 评论目标、root/rpid、楼中楼和评论权限 |
| DSH 主 Session | 同一 1～3 条消息契约、同一 P6-A 配置上限 | DSH Agent 的 steer/followup、Turn 生命周期和 Chat 可见性 |

主人私信直接复用 `dmP6Enabled` / `dmP6MaxBubbles`，没有新增第二套主人私信多气泡配置。主 Session 也读取同一设置；关闭或上限为 1 时只使用普通单条回复。

## 主 Session 为什么使用连续续步 Turn

DSH Chat 紧凑视图按每个技术 Turn 的最终 Assistant 答复显示。若把多条消息都塞在同一技术 Turn 的多个 Assistant step 中，前面的答复可能被折叠进过程区，只显示最后一条。

因此模型在需要多条独立表达时调用 `dafeiyu_chat_burst(messages)`：

- 第一条通过当前 Turn 的 `agent.steer()` 作为该 Turn 的最终 Assistant 回复。
- 第二、第三条由 `agent.turn-stopping` 根据剩余队列使用原 Agent 的 `followup()` 形成紧接的续步 Turn。
- 每个续步 Turn 只要求输出一条消息，因此 Chat 可以分别显示每个 Assistant 答复。
- 续步提示使用 `source.kind=plugin:dsh-dafeiyu-life`，在 Chat 中作为折叠的插件上下文，而不是伪造主人消息或手工追加 Assistant 事件。
- 新主人消息到达时，删除未领取的续步；若旧续步已运行，则 `cancel(..., {keepInbox:true})` 中断旧生成并保留新主人输入。
- 模型可以选择只说一条，不会强制凑满三条；若续步生成空内容或只有工具调用，则停止剩余气泡。

因此这里的“一轮”是**一个逻辑回复批次**，不是单个 DSH 技术 Turn。后续气泡是同一 Session 中连续的技术 Turn，以保证真实 UI 可见。

## 主人私信 P6-A

主人私信 Agent 仍保留原有决策和工具权限，只把回复契约从单条 `text` 扩展为兼容 `text` 的 `messages[]`。

每条消息独立发送，使用不同 eventId；每次发送前复核主人 Agent 开关、主人 UID 和 P6-A 配置。每条确认成功后立即写入对应助手历史与回执。若后续气泡结果未知，则记录 `uncertain`，保留已确认数量，不自动重放同一入站消息。

## 诊断与验收

管理页现有 P6-A 开关与最大气泡数已明确覆盖普通私信、主人私信和主 Session，不新增风格卡片。主人私信状态显示 `confirmed/proposed` 气泡数量；不会记录或展示私信正文作为诊断。

专项测试：

- 共享归一化、空消息去除、最大条数。
- 逐条发送、逐条持久化、未知回执停止。
- 主人私信 3 条消息逐条发送、独立 eventId 和回执。
- 主人私信中途未知结果不重发、不发送第三条。
- P6-A 关闭时主人私信退回单条。
- 主 Session 2～3 条连续续步、每条成为独立可见 Turn。
- 新主人消息取消未发送续步；工具调用/空输出不继续发送。

尚需真实 DSH Desktop/Windows Chat UI 和真实 B站账号验收，专项离线测试不能替代平台实测。`releaseReady:false`。
