# 2.7.1-dev.8 · 快速设置内嵌卡片（UI V4，未发布）

## 目标与唯一归属

旧 UI V3 将快速设置做成导航入口，不符合首次安装时直接选方案的需求。V4 让用户在同一页面配置 Life 的自主生活开关和节奏、跨 Session 记忆与反思、后台私信和主动视频分享；高复杂度的 Provider / 模型身份、联系人名册和高级字段仍经原页签调整。

**统一层归属检查：** `管理中心快速设置 → /onboarding/quick/options & /onboarding/quick/save → 原 lifeSettingsV2/planLifeSettingsV2、现有 config.json / persistCfg → 原 Life Agent / 主 Session 记忆 / 社交发送门禁`。本轮没有新数据文件、独立生活主体、新定时器、单独模型、社交发信器、隐私记忆读取路径。`lib/quick-setup-options.mjs` 仅校验固定预设的键、取值、同源快照版本和允许变更范围，不持久化状态。具体操作仍经过 Life 设置契约及现有 DSH 配置同步。

## 操作契约

| 首次设置卡片 | 保存内容 | 明确不改变 |
|---|---|---|
| 自主生活 | `lifeAgentMode`、原生活预算/频率；显式开启时可申请 `masterEnabled` | B站社交写权限、视频 Agent 独立门禁 |
| 记忆与反思 | 记忆召回/衰减、反思候选与间隔、两项显式开关 | 已存记忆正文、遗忘记录、账号、生活节奏 |
| 后台私信 | `dmWatch`、`dmStrangerAutonomyEnabled`，不保留旧人工暗号审批 | 白名单、其他渠道或人物关系 |
| 主动视频分享 | 暂停，或在明确确认后开启真实自主分享；每日额度仅允许 50～1000 | 逐条人工审稿/代发、白名单收件授权、冷却、去重 |
| AI 模型 | 仅导航至模型配置和实际验证 | 不复制 API Key 或后台模型配置 |

全部卡片：**读取当前配置 → UI 选择（不自动保存）→ 服务端预览差异 → 主人确认变更配置（不是审核鱼鱼社交内容）→ 原配置写源保存 → 配置回读**。对旧用户，无法精确匹配预设时使用「自定义／保留旧值」，不因显示页面而覆盖。记忆选择 `custom` 仅修改显式开关；生活自定义保留原值，需在生活页补齐高级预算。启用分享或自由私信需先有 B站与 Headless 必需项验证；初次安装未验收时只能保存记忆与关闭类方案。

`QUICK_SETUP_REVISION=3` 仅控制本版首次展示；与 `firstStart.isReady` 独立，不重置已完成老用户的运行权，旧用户确认查看后继续正常使用，新用户仍受原强制启动门禁约束。

## 可验收入口与限制

- 入口：管理中心 `?tab=firststart`，默认升级首次展示，顶部横向导航不变。
- 查看：上方实时当前配置、选中卡片及「具体参数」折叠栏；并可回原设置页看到同一保存值。
- 失败：配置版本过期、未完成必需验证、配置不支持、重复提交或宿主同步失败均给出提示，不声称已发社交消息。
- 隐私与成本：接口仅返回配置键与预算，无对话正文、UID、凭据、平台 API 调用或模型调用。真实平台外发继续依赖原 SocialPolicyGate、账号门禁和实际回执。
- 未覆盖：Windows Desktop 实机、B站真实账号、老用户大规模迁移、跨进程候选调度/RC、真正生活连续性。此 UI 迭代不能作为正式发布验收。
