# 2.7.1-dev.3 · 分节点真实验收（未封版）

> 本指南基于「跨语言预约 + 待办事务 + 顺路热评」后的增量。保持版本 `2.7.1-dev.3`，只有下述节点通过后才能逐步宣布相应能力已验收；**不能把离线测试说成真实 B站联调**。

## 验收节点 A · 本地安全与部署（更新后立刻可以执行）

1. 完整重启 DSH Desktop，并在「运行诊断 → Python MCP 安全版本检查」核对 `mcp_server.py` 与 `read_action_gate.py`。发现不一致先通过管理中心备份并修复，再重启。
2. 「运行诊断 → 自主行动基础能力 · 离线验收」点击「运行本地模拟验收」。必须出现 **5/5**，逐项为评论/楼中楼动作身份、同账号互斥、技术回执、跨账号隔离、待办旧回执拦截。它不会访问网络、消费 AI 额度或改真实待办。
3. 电脑 PowerShell 进入插件源码根目录：

```powershell
node tools/dev3-acceptance.mjs --all
```

此命令额外在**独立 Node/Python 子进程**间检查同一个评论列表或楼中楼读取是否会被另一方拦截，以及并发待办是否丢失；还执行跨轮生活意愿、关系边界和顺路热评等模拟场景测试；使用虚拟账号和临时目录，不需要真实登录。若 Windows Python 未在 PATH，应先修复环境，不可将跳过当作通过。

**若失败**：提交失败项名称、Node/Python 版本和 Python MCP 安全检查状态即可；不需要附带凭证或真实私信。

## 验收节点 B · 真实视频阅读与生活线索

1. 在原视频自主探索界面「现在跑一轮」，模型可以自主看或不看评论。
2. 到「运行诊断 → 评论区只读探索」，核对真实 BV 的 `comment_list_read` 成功。若选择深入楼中楼应有 `comment_thread_read` 真回执；没选择楼中楼不算异常。
3. 到「运行诊断 → 平台读取预约与中断核查」看评论列表、楼中楼、弹幕或字幕技术回执（`bili_comments`/`bili_comment_thread`/`bili_danmaku`/`bili_subtitle`）；不要把工具返回直接说成鱼鱼有感受或看过视频。
4. 如果鱼鱼确实提交了临时感受，再到「人生记忆 → 自主生活」检查是否形成合格意愿和跨轮探索回执；无感受就不强制造假。**上述所有行为仍要真实模型/B站验收。**

## 验收节点 C · 承诺与真实互动安全

1. 在「运行诊断 → 待办账本并发与恢复」检查事务健康；不能为了测试故意在真实账号上制造中断锁。跨进程并发由节点 A 的离线 CLI 测试，不涉及真实任务。
2. 到「最近评论 → 后台评论互动设置」确认普通回复已单独授权，按需开启「回复别人后，顺路看看同视频其他热门评论」。这是**独立许可，默认关闭**，不恢复全视频巡扫。
3. 用可信真实评论通知观察：鱼鱼成功回复原通知后，是否出现同 BV 的热评候选；下轮她可以自主选择回复或沉默。关闭许可、回复失败、超额度都不应外发；后台记录真实已发送的 rpid 和平台回执。
4. P6 的用户界面称「自然续聊」；允许自然分条或延期考虑补充，不等于自动启动主动私信或公开回复许可。

## 未通过时如何解释

- 节点 A 5/5 不通过：优先排查插件源码/部署，**不要再跑 B站**。
- 节点 A 通过，但节点 B 没有评论读取：先看模型是否实际调用了工具、账号和权限是否就绪；不能直接判断共享锁故障。
- 出现“预约阻塞”：先确认是否有仍在运行的读取或崩溃未知结果；**绝不重复发起相同动作来碰运气**。
- 节点 C 未见顺路热评：依次核对独立许可、真实回复通知、原评论发送回执、当前轮额度、同 BV 热评候选、模型自主沉默。

### 字幕 → 视觉回退证据分级（dev.3 小步加固）

- 字幕轨为空、仅有署名文字或不存在时：返回 `subtitle_evidence=none`，**不**再将空字幕缓存成已经取得的正文。`auto_vision_on_missing=false` 或视觉关闭时，明确返回 `visual_fallback=not_attempted`，不会发起图片/模型调用。
- 视觉回退后：只有真正返回图像内容块时为 `frames_returned / low_resolution_frames`；独立视觉模型确实返回非空描述时为 `model_description_returned / unverified_low_resolution_description`；额度不足、配置失败、结果缺证据时分别是 `blocked` 或 `failed`。所有状态的 `can_claim_full_video_watched`、`can_claim_audio_listened` **始终为 false**。
- `frames_returned` 只说明 MCP 返回过低清图片，不保证接收端模型已读懂图片；模型描述仍为待核实观察，不是完整视频、音轨或真实发表经历的证明。现有视觉授权、模型配额及白名单未变化；视觉工具仍不能直接套一般共享只读锁，否则独立 DSH 视觉子流程可能出现嵌套预约阻塞。
- 快速离线验收：`python -m unittest discover -s test -p test_v271_subtitle_visual_evidence.py -v`。Windows `run-tests.ps1` 会在耗时的全量测试前先执行该专项。真正的低清图、B站字幕、DSH 图像交付和视觉额度需 Windows 实机验收，不能用 Linux 单测代替。
