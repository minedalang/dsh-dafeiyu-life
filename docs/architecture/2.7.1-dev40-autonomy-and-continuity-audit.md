# DSH 2.7.1-dev.40 · 专业 Agent 行为自由／Episode 持续性真实自查

> 开发预览，未发布；从 `2.7.1-dev.39` 升级。**“同一主体共享经历”不等于“任意工具自由可用”。** 审计区分真实模型候选、工具执行闭环、跨轮续行与真实平台验收。

## 本轮新增的可验证能力

1. **专业行为菜单**：`lib/life-subagent-continuity.mjs` 的 `subagentActionMenu` 只依据当前 Agent 及宿主实际提供的读工具、MCP 白名单、独立授权写工具或现有 `nextActions` 输出候选，`acceptedSubagentReadKinds` 在每一步复核候选。不会因为 Episode 中出现某个动作，就动态授予该工具的执行权。视频 MCP 菜单来自 `index.js` 的原白名单，主人私信工具来自本轮真实开关，TODO 和社交来自原 Life 决策目标。
2. **私信／评论多步观察**：`lib/interaction-batch.mjs` 精简模式的第一次模型回答可自主提出 `contextRequests`；每次只允许本 UID、当前渠道、当前账号已明确提供的上下文种类，最多两次，去重且逐次读取。真实结果回到同一模型继续判断；不允许在任何中间请求外发半成品。记忆仍依原 ACL 和逐日遗忘。隐私敏感问法不触发记忆／公开人物读取。
3. **同 BV 跨 Agent 公开因果**：经原 `LifeActionAttribution.verified` 的视频 Agent 和评论互动 Agent 真实成功回执可用逐条 `publicAlias` 哈希关联；评论 Agent 由原真实 B站评论的 BV 读取 `publicVideoState`。只返回 action/channel/outcome，不含 UID、私信、评论正文、平台回执明文；不能把同一 Episode 另一 BV 的事件误归给当前视频，也不重复计算平台成功数。
4. **评论者公开投稿可选只读**：管理页面单独确认启用 `commentPublicProfileReadEnabled`，默认 `false`。只有目前有效的真实公开评论源（BV+原 rpid+当前 UID）、登录态和 Life 主开关允许时，评论 Agent 才会看到 `read_public_person`；调用真实 `bili_user_videos` 前后检查当前账号，输出最多四项合法 BV 与脱敏标题。模型不能自造 UID，结果不会授权关注、私信、跨评论回复或保存私密人物画像。
5. **其余入口候选接线**：主人私信在原四步内展示授权只读/写工具并严格验证选择；TODO 后续子任务在原三次决策里展示执行、延期、放弃；自主社交显示当轮实际 social 菜单；公开反思显示只读认识的可选边界，且历史只取公开反思 Episode。

## 尚需实现/实测，禁止宣传为已完成

- **无法确保所有现实社交行为都可执行。** 当前不能在回复任意 A 时自由跨串回复 B，也不能从任意陌生评论扩展到主动私信，写操作也不能从一次只读了解自动升级为授权；这些缺少可靠平台来源及独立授权执行器。
- 视频子 Agent 有单轮 MCP 多步，但跨天还未直接恢复原视频工具会话及所有未完成好奇；普通私信／评论的扩展是最多两次证据读取，不是任意深度外部行动循环。
- 跨 Agent **已核验公开视频动作索引**不是完整意愿事务总线；还缺通用的意愿转交／承接／撤销、跨天预算恢复、所有任务共同的取消/补偿协议。
- 原 Universal Life Episode 单段最多五个已核验步骤；此上限不是生活永久上限，仍需独立的跨段意愿延续设计。
- `releaseReady:false`，未合并 main、未建立 Tag；Windows、真实 GGUF、B站关注及评论实际回执、账号切换、72 小时真实生活未验收。

## 核心安全回归

- 同一次视频会话含 BV1 和 BV2，BV1 的评论 Agent **只**得到逐条对应 BV1 的动作；账号切换后为空。
- 没有明确开启评论者公开投稿读取时，模型就算提出 UID / `public_person` 也无法调用；登录变化、UID 不一致或者查询失败停下，不返回私人资料。
- 两次只读取证若模型仍要求第三次、重新要求相同上下文、或请求非当前菜单能力，不允许发送中间回复。
- 原账号授权、UID 隔离、Life 意愿复核、平台原回执、遗忘、外部写额度、未知发送冻结保持不变。

完整 Node/Python 及补丁可应用验证见本次交付 `DSH-2.7.1-dev40-TEST-RESULTS.md`。如无真实实机验证，不能宣称鱼鱼已经达到所有 Life Agent 的完整自由行动。
