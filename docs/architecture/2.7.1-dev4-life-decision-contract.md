## 当前执行流程

模型看到的是当前能选择的列表，`skip` 永远保留以容许自主休息。只有合格只读任务才提供 `execute_read`，只在本轮有真实 `lifeEvents + videoEligible` 时提供视频专业能力；社交事件只提供只读关注，不授权回复/发送。`inspect_exploration` 的 BV 必须属于相应 `id`。提示中的候选不是能力票据，执行前仍从账本中重新取证。

解析不从任意文字里“猜出一个 JSON”；多对象、代码块外说明或超长输出仍标记 `model-json-invalid`。单独代码围栏属于有限的格式兼容，不会跳过 `validatePlannerDecision` 或对扩展动作的目标核验。一次错误保持原每日模型调用计数，不自动发起第二次修复调用；模型自己明确返回 `skip` 才记为 `voluntary-rest`。

## 验收与未覆盖

在生活页选择非暂停模式并保存，确保有可信待办或其他有效活动后，点击“现在让鱼鱼考虑一次”。可能得到：已执行的只读回执、明确主动休息、无可信候选（不调用模型）、模型不合规（消耗本轮额度但不执行）。高级诊断只给固定类别，不记录模型原文、目标 ID 或私人会话内容。无效输出反复出现时仍要实测具体模型兼容性。

本次**没有完成** Life Agent 真实社交决策的唯一接管、Phase 7 全域成长因果证明、Phase 8 Windows／B站与发布验收。
