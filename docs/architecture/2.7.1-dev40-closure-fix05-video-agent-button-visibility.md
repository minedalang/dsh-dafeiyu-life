# dev.40 同版本维护修复 · 真实视频 Agent 手动入口可见性

## 问题

`life-agent/video-agent-test-run` 的真实启动接口、站内二次确认和管理页面事件处理已经存在，但「手动触发一轮真实视频 Agent」按钮被放在两层折叠的「开发者诊断」区域中。普通使用者进入「Life 自主生活」时看不到它，与需求指定的「真实运行状态」入口不符。

## 修复

- 将整个 `life-real-acceptance` 状态卡移入「Life 自主生活 → 鱼鱼的生活」常规设置面板，紧跟生活设置状态展示。
- 状态卡标题调整为「真实运行状态」，明确说明手动入口只启动原视频 Agent，由 Agent 自主决定探索、继续或结束。
- 明确显示“不强迫选片、发表评论或点赞”；所有写操作继续使用原有 Life 意愿审批、账号/隐私/平台门禁、额度、冷却及真实回执。
- 保留原按钮 ID、原 JS 二次确认、原 API、原能力委派及所有后端门禁；没有新增启动旁路、权限、模型调用或定时器。
- 原离线模拟按钮与真实状态刷新按钮一并移到可见状态卡，仍分别保持纯模拟和零模型调用语义。

## 使用路径

管理中心 → **Life 自主生活** → **鱼鱼的生活** → **真实运行状态** →「手动触发一轮真实视频 Agent」。点击后还需在站内确认对话框中再次确认。

真实启动仍要求 Life 处于 `active`、主开关和自主调度开启、首页推荐开启、首次设置与当前账号核验通过，并遵守视频 Agent 原有忙碌、冷却、平台额度和执行权限。启动成功只证明原 Agent 进程已启动，不证明已经观看、选片、评论或点赞。

## 验证边界

新增 DOM 位置回归测试，防止该入口再次被放入开发者折叠区；并验证原按钮仍绑定原 API 与单轮确认常量。源码测试不替代 Windows Desktop 和真实 B站实机验收。`releaseReady:false`，不合并主干、不创建 Tag、不发布。
