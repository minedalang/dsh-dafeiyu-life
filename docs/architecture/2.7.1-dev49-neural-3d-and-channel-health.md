# DSH 2.7.1-dev.49：三维记忆空间与后台监听状态

> `releaseReady:false`，唯一补丁基线 dev.48 完整源码。仅管理端可视化与只读状态投影，不增加 B站请求、外部行为或 Life 动作权限。

## 神经回忆的真实数据流

1. `GET /main-session/memory/neural` 仍由原有同源/来源约束保护。记忆节点出自 `memoryGardenSnapshot` 与当前可回忆 Episode，已删除、已遗忘、封存记录不复活。
2. 计算稳定匿名节点 ID（`neuralProjectionKey`），通过 `memory:` / `episode:` 等**仅后端可见**的内部键连接 `embeddingIndex.projectPoints()`；该函数仅读取现有索引，没有 embedding API 请求，也不改动索引。
3. 投影采用中心化余弦归一向量的 PCA 三维坐标，保留语义上邻近记录通常较近的空间结构。PCA 是近似可视化，不保证所有高维距离保持准确，也不构成因果或情绪证据。仅当前索引中文本哈希一致的节点加入投影，结果只返回匿名坐标。至少 3 个匹配向量且主方向有效才显示“本地 Embedding · PCA”。
4. 没有可用模型、索引缺失、条目不匹配或数据不足时，界面使用**稳定结构布局**；未进入索引的节点亦走备用布局，清楚标注匹配数。结构布局不是“语义聚类”。
5. 颜色区分类别：蓝-经历、粉-人物、绿-后天兴趣、金-长期认识、紫-当时情绪；这些不是模型推断的人格。关系连线只允许共享真实来源事件，不会因 embedding 接近而添加“有关系”的线。
6. 图中三维点经透视投影到 SVG，支持拖动旋转、鼠标滚轮缩放、键盘方向键与 +/-、视角重置、浏览器原生全屏（不支持时使用布局全屏）。点击图节点或列表卡片都更新同一个详情元素，并滚动右侧列表到对应项。支持减少动态效果的系统偏好。

## 运行状态栏

- 删除“🐟 生活播报”页面顶端 12 秒活动流轮询，只保留有真正用途的“鱼鱼此刻”页运行查看。
- 原顶部深色悬浮告警替换为头部下方的轻量状态区。`systemHealthSnapshot` 只读取 `interactionScheduler.status().networkBackoff`、共享读取预算、Life 模型退避及发送事务，并增加 `channels:[{id,label,reason,streak,retryAt}]`。
- 三种真实轮询渠道 `dm`、`replies`、`mentions` 分别映射到“后台私信、评论回复、被 @ 提及”；平台 -509 分类“B站限流”，DNS/超时等“网络请求失败”。渠道标注的是“计划重试”，不能证明已恢复网络；没有通道退避也不能宣称 B站正常。
- 为防隐私泄露，不记录原网络错误堆栈、UID、私信正文、密钥/凭证。错误细节仍可以去原诊断页查阅；本次界面变更不自动重试未知发送结果。
