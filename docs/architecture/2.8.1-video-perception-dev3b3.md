# 2.8.1-dev.3b.3｜视频感知依赖可见性与模型页统一管理

> 开发增量：从已完成 dev.3b.2 的源码继续。仅代表实现与离线回归；Windows 实机、winget 安装、真实 B站、Whisper 转写须另行验收。

## 安装入口与主依赖归属（本轮追加）

- **管理中心 → 快速设置 → 运行依赖 · 一站安装**：唯一安装操作入口。主依赖安装／修复保留原有 `runInstall()`，负责 Python venv、B站读取、MCP、二维码包；原 DSH 插件设置页的主依赖按钮已退役，仅展示只读状态和跳转。新老用户都可以进入该页面检查和修复，不会重置登录。
- **视频增强组件（默认均未勾选）**：同一首次设置卡片中按需选择 FFmpeg 与 Whisper，点击「安装勾选的视频组件」后弹出确认，分别复用 `openFFmpegInstaller()`（Windows winget 可见窗口）和 `runAsrInstall()`（专用 Python 转写环境、依赖和已保存的模型）。安装请求和真实完成分离，只有状态回读 / 实测才算就绪；安装不能自动开启 `transcribe`，也不能强制鱼鱼观看。
- **AI 模型页负责配置与验收，不提供另一套安装按钮**：将原「无字幕时尝试转写视频语音（需转写依赖）」改名为「视频语音识别模型（推荐开启）」；保留唯一开关、Whisper 型号保存、FFmpeg 真实解码自测、Whisper 最近调用状态及前往快速设置的跳转。默认值不变，已有安装和已保存设置不清除。
- **安全**：在首次设置未通过时，允许通过已存在的管理 API 安装主依赖、通过显式开放的安装 API 启动可选视频组件。Whisper/FFmpeg 安装端点仍校验同源、回环客户端，不允许互联网远程请求触发；所有开关与下载选择由用户操作，不由 Life 决策层控制。

## 体积与许可证评估（面向分发者）

| 组件 | 典型体积和作用 | 当前分发方式与许可证 |
|---|---|---|
| FFmpeg | Windows essentials 压缩包通常几十至约百 MB；真实体积随构建变化 | 本插件只启动 Windows winget 安装，不包含 FFmpeg 二进制；FFmpeg 主要是 LGPL，带可选 GPL 组件的构建受 GPL 约束，参阅 [FFmpeg legal](https://ffmpeg.org/legal.html) |
| faster-whisper | 本地 Python 包以及转写依赖；安装体积随平台变化 | 上游 [faster-whisper MIT](https://github.com/SYSTRAN/faster-whisper/blob/master/LICENSE)；`pip` 下载第三方运行依赖时，各包仍需遵守自身许可证 |
| Whisper 权重 | Systran `faster-whisper-small` 模型权重约 484 MB；base 小一些，medium / large-v3 更大 | 原模型/权重和上游转换模型采用 MIT；运行时从上游/用户设定的镜像下载，**不打包入 npm**；参阅 [模型卡](https://huggingface.co/Systran/faster-whisper-small) |

**不是法律意见。** 使用开源程序或提供一键安装不自动构成侵权，但也不意味着无需遵守许可证。若以后决定把 FFmpeg 二进制直接打包进 npm，应先逐个确认实际构建的 LGPL/GPL、源码提供、版权通知及再分发条件；本轮避免捆绑以减少授权和分发风险。安装组件前明确披露来源、容量与选择，不自动下载大权重。

## 使用者的入口

- **AI 模型 → 视频感知依赖与辅助能力**：集中设置「无官方字幕时允许本地 Whisper 按需转写」、Whisper 型号 tiny/base/small/medium/large-v3、梗图开关和调试开关。保存按钮独立于其他模型配置。视频探索页保留明确跳转，移除重复输入框。
- FFmpeg 卡片：读取本机 `ffmpeg -version`，另有「实际解码自测」使用 FFmpeg 本地生成黑色测试帧（不读取用户视频或访问网络），及跳转至「快速设置」的 Windows 安装入口。用户在快速设置**勾选并再次确认**后，在可见 PowerShell 中执行固定的 `winget install --id Gyan.FFmpeg.Essentials --exact --source winget`。没有自带 FFmpeg，不静默执行/安装，不安装其他程序、不改变全局 PATH 或代理。安装完可能需要重启 DSH 再检测。非 Windows / 缺 winget 时清晰提示手动安装。
- Whisper 卡片同时显示**设置开关**、**独立 Python 环境**、**选中模型实际缓存文件**、**最近真实转写**。模型缓存需要所选 `Systran/faster-whisper-{model}` 的快照至少包含 `model.bin` 与 `config.json`；不存在时不得显示就绪。安装仍沿用原有 `install-asr` 流程，过程可查看本地进度日志；模型首次下载会消耗网络及磁盘空间。
- 最近实际转写回执由 `bili_transcribe_safe` 调用时产生，仅写 `at/outcome/model/segments/reason` 至本地 `asr-last-run.json`；**不写 BV、文字、音频、账号或 Provider**。未发生过实际转写时显示「暂无可信回执」。安装成功不能冒充真实转写成功；最近一次记录不是完整历史。

## 实际调用链修复

过去管理中心 `asrModel` 的保存值没有传到实际 MCP 安全转写工具中，导致常使用默认 small。现在主 MCP 与独立视频 Agent 环境提供 `BILI_ASR_MODEL`，安全工具仅允许既有型号白名单并实际向 `asr.py --json --model <model>` 传参；`mcpKeyNow` 包含所选模型，避免模型更改后复用旧的环境。保留已有转写开关及无官方字幕时的请求条件，不绕过鱼鱼的自主观看选择。

## 不变的事实边界

- FFmpeg 不是 Whisper 的安装结果；「检测到 ffmpeg」不等于成功解码，因此提供单独解码自测。无 FFmpeg 时使用现有低清预览回退，按来源记录。
- Whisper 状态与安装成功也不意味着模型正在运行或理解了视频；真实转写需要进入视频观察、满足用户启用与工具授权、无可用官方字幕，并完成回执验证。
- 保留原有 12/24/48 帧预算、受控公开源、24MiB 单段限制、自主是否观看/观看深度；不扩大外发权限。机器 ASR/OCR 时间相邻不等于语义互证。
- 新增 `lib/video-dependencies.mjs` 为原生 Node 模块；没有捆绑 FFmpeg/Tesseract 二进制或 Whisper 权重。GitHub/npm 2.8.0 已发布资源不在本增量内修改。

## 验收建议（Windows DSH）

1. 进入「快速设置 → 运行依赖」，主依赖未就绪就点击安装，查看日志与就绪状态；FFmpeg 可勾选安装并在 PowerShell 观察结果。安装后重启 DSH，再到「AI 模型」进行重新检测与实际解码自测。
2. 在「AI 模型」选择 Whisper 型号和“视频语音识别模型（推荐开启）”开关并保存；再回「快速设置」勾选安装 Whisper，等待所选型号的环境及缓存文件就绪。
3. 未实际转写时应显示「暂无可信回执」；使用一条**没有官方字幕**且鱼鱼决定了解的视频，在允许 ASR 的条件下运行后再刷新查看最近运行时间、实际型号与分段数。不应出现转写正文或 BV。
4. 切换 Whisper 型号并保存，确认模型缓存状态变化；再次实测确认转写调用使用新型号，而不是沿用旧 MCP 环境。
5. 在视频探索页确认只剩跳转；在原 DSH 设置页确认只能跳到管理中心安装，没有独立的第二套安装入口；检查既有视觉模式、模型验收、分镜与 Life 意愿不受影响。
