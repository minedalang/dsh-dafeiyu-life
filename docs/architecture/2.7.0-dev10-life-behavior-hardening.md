## 真实生产调用过程

参见可编辑 Mermaid：[2.7.0-dev10-life-behavior-live.mmd](./diagrams/2.7.0-dev10-life-behavior-live.mmd)。**DM 退订事实不是模型写入**；只有当前登录账号已验真的私信发件人能提出 stop/resume。返回同意不能自动扩大发送权限。模型只对未被边界否决的当前消息决定如何说。

隐私反例：把他人的私人聊天、主人的系统提示或任何账号凭据展示给陌生人。先清除模型上下文中的私密记忆/好友画像/旧私信，再允许同一 Life Voice 生成安全拒绝或沉默；模型回复还需过保守出站检测。安全策略可拒发，但不能伪造一句看似属于鱼鱼的固定回复。拒绝语义的多样性无法通过词法完全判断，不得用这套门禁宣称绝对可靠。

待办反例：只入账 A 却声称 B 或两件都入账；逐项核对源中明确的作品标题/BV 与原账本回执，冲突交原模型修订或停止发送。规则无法覆盖任意自由语序与同义表达，发版前应在真实模型试验多版本中文自然回复。

## 兴趣真成长：当前实际实现与诚实限制

1. **被动看到、主人推荐、不等于愿意探索。** `mergeWatchedRows` 现在将历史的 `picked` 展示/判重标签与独立的 `autonomousSelected` 分开；真正选中（明确状态或日报项）才作为自主经历证据。
2. **自主选看不是喜欢。** `LifeInterests` 将可核验的 B站 BV/标题记录为后天选看线索；陌生主题形成14天有限的好奇候选，同一主题在不同日期再次被选中称为“再次探索”。并不能推断鱼鱼确实看完、听完、喜欢作品或永久愿意追随创作者。
3. **允许变化和遗忘。** 历史 90 天滚动、好奇候选14天过期，主人可30天暂时排除主题并恢复。核心兴趣仍是主人设定的起始约束，不与短期好奇混为一谈。
4. **尚未真正实现的：** 对一次作品的真实欣赏评价、来源可审计的自主喜好/不喜欢语义、跨月的反思型兴趣转变，以及跨场景强实证一致性。`interests.json` 旧数据没有来源标记，**无法可靠回溯**此前把「值得看」错误算入的证据，故保留原始文件并在管理页标为「来源待核验」；这些证据不进入模型兴趣记忆、后天兴趣选择或 Python 表情包排序，旧无来源好奇候选也不再投放。未来需要可审阅的来源重核验，不能凭空清洗出一个“真实经历”。后续需设计可见的来源重核验与人工纠错，不能凭空清洗出一个“真实经历”。
5. **不偷改延期项：** 旧给主人推荐的「值得看/不值得看」逻辑本身仍保留，整套旧推荐重构及「生活行动契机协调层」按计划留在 2.7.1 或后续明确审定版本。
