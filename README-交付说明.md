# 大肥鱼 .22 交付说明

本版基于 `.21`，仅新增「鱼鱼的生活」的独立每日活动时段 UI 与后端配置契约；继承 `.20/.21` 的视觉执行路由、实时 Life 调度快照和 Windows 中文路径编码修复。

交付包包含完整 `source/`、npm TGZ、`.19→.22` 与 `.21→.22` UTF-8 Patch、`APPLY.md`、`TEST-RESULTS.md`、`COMMIT_MESSAGE.txt` 和 SHA-256 清单。优先使用与实际运行源码基线一致的 Patch。

注意：用户此前视觉错误发生于实际运行 `.19`；它不能证明 `.21/.22` 仍然失败。升级并完全重启后再验收。新时段控件使用原有持久化配置键，不会自动改动账号、记忆、发送授权或轮询预算。
